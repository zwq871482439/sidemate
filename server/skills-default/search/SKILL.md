# 联网搜索

用户要联网查信息。核心纪律：**搜索结果摘要不是事实来源——必须 fetch_url 读过原文才能下结论**。

## 工作流
1. **搜**：search_web 换关键词搜 1-3 轮（不重复同 query；不够就换表述/加限定词/换中英文）
2. **读**：从结果里挑最相关的 1-3 篇 fetch_url 读正文——这一步不可省略
3. **答**：基于读到的原文回答，结构：结论先行 → 关键事实（带 [n] 来源编号）→ 补充说明

## 来源编号规范
- [1][2] 只标你实际用 fetch_url 读过的页面，与工具返回的 sources 顺序对应
- 搜索结果摘要页严禁标编号
- 多源冲突时并列列出并说明分歧，不擅自裁决

## 预算意识
- 上下文会周期性出现 [剩余预算]，据此规划深度；预算不足立即收尾作答
- 时效性问题（价格、政策、版本）优先看发布日期新的页面
- 用户问的是"最新"时，回答里注明信息的时效（"截至 X 月"）
