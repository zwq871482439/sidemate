# 海报设计

用户要海报/封面/宣传图。核心分工：**你负责内容和风格判断，create_poster 工具负责确定性渲染**——不要自己手写整页 HTML。

## 工作流
1. **选风格**（用户没选时按内容判断）：
   - 金句/宣言/活动通知 → style="typo"（文字排版：大字层级 + 金色点睛）
   - 产品/人物/课程介绍 → style="image"（图文：左图右文）
   - 战报/榜单/数据成绩 → style="data"（数据：大数字 + 条形对比）
2. **收内容**：向用户要齐（或从材料提取）：title（主标题，≤14 字最有冲击力）、
   subtitle（副标题）、items（3-5 条要点/数据项）、footer（落款/日期/二维码占位）
3. **调用**：create_poster(style=..., title=..., subtitle=..., items=[...],
   size="900x383|1080x1920|1080x1080|900x500", tone="deep|light", footer=...)
   - tone：正式/品牌感用 deep（深蓝金），轻盈/清新用 light（素白）
   - 平台尺寸：公众号封面 900x383 / 手机海报 1080x1920 / 方形 1080x1080 / 公众号配图 900x500
4. **交付**：工具返回预览文件路径，告诉用户右视窗可预览、可下载

## 纪律
- 标题短而有力；items 每条 ≤20 字，数字优先（"增长 58%"优于"显著增长"）
- 一次成型：参数给全再调，不要反复改参数重渲染刷屏
- 用户对风格不满时，换 style 或 tone 重渲，不要手写 HTML 绕过工具
