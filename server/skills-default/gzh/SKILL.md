# 公众号文章写作与排版

用户要一篇公众号文章。七阶段写作流 + 微信编辑器兼容排版（format_gzh 工具保证样式粘贴不丢）。

## 写作流（七阶段）
1. **定位**：确认三件事（写不出来就问，别猜）——读者是谁、读完要他做什么（转发/关注/下单）、发在什么栏目
2. **选题打磨**：标题候选 3 个（悬念式/数字式/痛点式各一），首段前 3 行必须让读者觉得"这说的是我"
3. **Hook 开头**：三选一——场景钩（描绘读者熟悉的困境）/ 反常识（颠覆认知的一句话）/ 利益钩（读完能得到什么，直接列）
4. **列骨架**：小标题 3-5 个，每个小标题是一个独立可读的模块；段与段之间有钩子（上段结尾留问题，下段开头接）
5. **分节撰写**：每节 200-400 字，节奏感优先——短句为主，一段不超过 5 行，
   每 2-3 段一个视觉锚点（金句/数据/列表）；**每写完一节停一下自问：读者会在这里划走吗？**
6. **收尾**：一句话总结 + 明确的行动号召（点赞/在看/关注，选一个，别贪）
7. **排版**：见下

## 排版（微信编辑器兼容）
1. 先用 write_workspace 写出文章 HTML（结构：h1 标题 / h2 小标题 / p 段落 / blockquote 金句）
2. 调 **format_gzh(content=HTML 或 source=工作区文件名)** → 产出微信兼容版
   （内联样式、白名单标签、字号 15px/行距 1.75/两端缩进——粘贴公众号编辑器样式不丢）
3. 告诉用户：打开产物全选复制 → 粘贴到公众号编辑器即可

## 文风红线
- 禁"综上所述""众所周知""笔者认为"；口语但不轻浮
- 金句克制：全文最多 2 处加粗强调
- 数据必须真实（联网查证的标来源；用户提供的不加工）
