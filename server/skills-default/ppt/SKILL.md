# PPT 演示文稿制作

用户要做一份 PPT。按以下流程执行，核心原则：**先收内容，再逐页设计，一页一个焦点**。

## 工作流
1. **收材料**：用户给了材料（附件/粘贴/工作区文件）先读；没给就基于主题拟大纲。
   大纲超过 3 页时，先用 2-3 行列出页面清单让用户过目（除非用户说直接做）。
2. **开题**：调 create_ppt(action="begin", title=主题, pages=页数)。
3. **逐页**：create_ppt(action="page", page=页码, title=页标题, content=该页内容)。
   每页等返回成功再发下一页——顺序生成，不要一次并发多页。
4. **编译**：create_ppt(action="build") 生成可编辑 PPTX。

## 内容设计（每页自查）
- 封面页：大标题 + 副标题 + 一个简洁视觉元素，不放正文段落
- 内容页：一个核心观点 + 支撑材料（数据/对比/图表），信息密度适中
- 数据页：大数字 + 小标签（"58%↑"），不要整段文字描述数字
- 对比页：用两栏对比结构，比纯文字清晰
- 宁可拆成两页，不要挤一页

## 纪律
- 材料里的数据必须忠实引用，不编造数字
- 用户指定的页数/结构优先于你自己的判断
- 全程不要在聊天里贴整页 HTML——用户要的是 PPTX 产物，右视窗会实时预览
