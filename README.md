# 桌伴 Sidemate

桌伴是 Windows 桌面上的一个小帮手：把几份材料拖给它，它照你给的范本写一份文件，并在 Word 批注里标出处。

## 现在的状态

- 新版从 0.2 起在这里发布，安装包放在 [Releases](https://github.com/zwq871482439/sidemate/releases)。
- 0.11 及更早的旧版已停止更新，不再提供下载。

官网：[deskware.cn](https://deskware.cn)

---

Sidemate is a small helper on the Windows desktop: drop a few files on it, and it writes a document that follows your template, with sources noted as Word comments.

New releases start from 0.2 and will be published here. Version 0.11 and earlier are discontinued.
