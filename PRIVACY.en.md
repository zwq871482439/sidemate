# Sidemate (sidemate) privacy and terms of use

1. **What this product is.** Sidemate (the "software") is a writing assistant that is installed and runs on your own local computer. The software itself does not provide any AI model or generative service, and it does not offer any relay, proxy or payment-on-behalf of model calls.
2. **Third-party model services.** To use the software you pick a third-party model service yourself and configure its API key yourself. When you use a third-party model service you must follow that provider's own terms of service and privacy policy; the fees, service availability and data handling that come with it are agreed and borne by you and that provider.
3. **Data handling.** The software needs no account. Your key, your drafts and your other material stay on your local computer, and the key is stored in encrypted form. When you start a task, the relevant content is sent by the software directly to the third-party model service you chose; it does not pass through the developer's server. The developer does not collect, store or process that content. When the web search or page-reading feature is used, the software visits the relevant web pages as the task requires.
4. **Generated content.** The output of the software is generated by the third-party model you chose. It may contain errors, omissions or things that do not match the facts; it does not represent the developer's views. Please check and verify it before you use it, and take responsibility for how you use it. You must not use the software to produce or spread content that breaks the law.
5. **Open source notice.** The software is built on the open-source project DeepSeek Harness and is used under its licence. This is an independently developed unofficial product; there is no affiliation, cooperation, authorisation or endorsement with the rights holders of that project. The full licence texts are in the `LICENSE` and `THIRD-PARTY-NOTICES.txt` files in the source repository, and a copy of `THIRD-PARTY-NOTICES.txt` is also in the installation folder.

## How your data is handled

The section above is the notice itself. This section is what actually happens in this version: where the data sits, when it leaves your computer, and who it goes to. In 0.2.0 the software talks to DeepSeek's API, so this section names DeepSeek directly (the "third-party model service" in the notice above is DeepSeek in this version). The Chinese version of this file is [PRIVACY.md](PRIVACY.md).

### In one sentence

Sidemate runs only on your own computer. **There are no accounts and no server of ours**: no usage statistics, no telemetry, no crash reporting, and nothing reaches the developer. The only things that leave your computer are the task content you asked Sidemate to send to DeepSeek, and the one-line "test it" request you trigger yourself.

### Where the data is kept on your computer

- `~/桌伴/` (the "Sidemate" folder in your home directory): Sidemate's working root.
  - `~/桌伴/任务/`: one workspace per task, under `~/桌伴/任务/<date>-<your request>/`. Sidemate copies your originals in before working; your originals are never touched.
  - `~/桌伴/随手/`: the scratch workspace used when you start without naming a task.
  - `~/桌伴/技能/`: skills you add yourself (optional).
  - `~/桌伴/key.bin`: your DeepSeek API key, **stored encrypted** (see below).
- Finished files: the "Sidemate Output" folder. When you drop in files, that folder is inside the task workspace; when you drop in a whole folder, it is inside that folder (your originals stay where they are).
- `%APPDATA%\sidemate\`: the program's own records.
  - `task.log`: task run log.
  - `pet.log`: log of the island (the small floating window).
  - `recent.json`: recently used folders.
  - `usage.json`: token usage for this month and for the last 10 tasks. These numbers are only kept on this computer.
  - `pet-place.json`: the island's position and its "keep in front" setting.
- `%USERPROFILE%\AppData\LocalLow\桌伴\`: the background program (dsh) runtime directory: logs, temporary files, runtime cache.

All of these paths are on your own computer. There is no account system, so there is no sign-up, no login and no cloud profile.

### How your key is stored

The DeepSeek API key you paste into the settings is encrypted with Electron's system encryption and written to `~/桌伴/key.bin`:

- On Windows this is DPAPI under the hood: the key is held by Windows itself, so other users and other programs cannot read it.
- Decryption happens only inside the program. It is never shown in the interface and never written to a log.
- It is placed into the background process's environment (`DEEPSEEK_API_KEY`) only when a task starts; when the task ends the process exits and the value is gone. It is never written to disk and never logged.

### When the system key store is not available: the save is refused, never downgraded to plain text

If the system encryption is not available on this computer (`safeStorage.isEncryptionAvailable()` returns false), saving the key **fails outright**: the interface says the key cannot be stored on this computer. The software does not fall back to a plain-text file, and it does not "keep it in plain text for now". Before saving, it also checks whether the encrypted result happens to contain the original text; if it does, the save is refused the same way. Better no key than a key anyone can read.

### When it goes online, and to whom

Sidemate itself listens on no port and exposes no service. Only these things reach the network:

1. **While working**: Sidemate sends what you asked for (the sentence you typed), the template and the material, together with your API key, to the DeepSeek endpoint you chose (by default `https://api.deepseek.com/anthropic`). Only put in material you are willing to hand to DeepSeek.
2. **Web search**: when the task needs to look something up, the background program dsh searches through DeepSeek's search service.
3. **Fetching a page**: dsh fetches that page directly and takes the text out of it.
4. **Clicking "Test it"**: it sends one very short probe request (`hi`, at most 5 tokens) to DeepSeek to check whether your key works. This uses a very small amount of quota.

There is no other outbound traffic.

### No automatic updates, no telemetry, no crash reporting

- **No automatic update check**: there is no update mechanism in the software (it does not check for updates, does not download an installer and does not show an update prompt). To get a new version, download and install it yourself from the release page.
- **No telemetry**: the telemetry built into the background program dsh is **switched off**; it is always started with `DSH_TELEMETRY_MODE=DISABLED` and `DSH_TELEMETRY_DISABLED=1`. Sidemate does not report usage statistics either.
- **No crash reporting**: the software neither collects nor uploads crash information. If something goes wrong, the log stays on this computer (`task.log`, `pet.log`), where you can read it; nothing is sent anywhere.

### "No key yet? See the official docs" in the settings

That line in the settings is a link button. Clicking it opens DeepSeek's official documentation page (`https://api-docs.deepseek.com/zh-cn/`) in **your computer's default browser**, and that is all it does: nothing is collected or reported about what you do on that page, and the program does not even know whether you clicked.

### Usage is only kept on this machine

The "how many tokens this month" and "how many for the last 10 tasks" numbers in the settings are worked out from a local `usage.json` file that records the usage of each task (token counts only; no unit prices, no money maths). That record is never uploaded, never synced and not tied to any account. Delete it and it never happened.

### Your originals

Before working, Sidemate **copies** your files into its own workspace and only edits the copies. Finished files go to the "Sidemate Output" folder; your originals are left exactly as they were. The program that does the work also cannot change anything outside the workspace at the system level.

### Uninstalling

The uninstaller asks whether your data should be deleted as well. The default is to **keep** it. Choosing to delete removes `~/桌伴/` (tasks, output, key) and `%APPDATA%\sidemate\` (recent records, logs).
