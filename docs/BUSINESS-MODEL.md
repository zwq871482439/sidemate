## 三、0.9.8「开箱即用 API」定义（用户视角）

### 用户故事
> 我想用 Sidemate 的在线模式，但要自己注册 OpenAI / DeepSeek 账号、自己拿 API key、自己付费——太麻烦。我想要**在 Sidemate 里点一下就能用，包月/包量**。

### 现状 vs 0.9.8

| 阶段 | 用户操作 |
|------|---------|
| **0.9.6 现状** | 1. 用户注册 OpenAI 账号<br>2. 拿 API key<br>3. 充值 / 绑信用卡<br>4. 复制 key 到 Sidemate 配置<br>5. 开始用 |
| **0.9.8 计划** | 1. 用户在 Sidemate 点"开箱即用"<br>2. 选套餐（包月/包量）<br>3. 支付（微信/支付宝）<br>4. 直接用 |

### 本质
**API 转售 + 充值平台**——类 One API / New API / OpenRouter / POE / 硅基流动 / 火山引擎方舟

**不"造模型"**——集成现有模型 API（OpenAI / DeepSeek / 通义千问 / 智谱），赚**批发-零售差价 + 便利费**。

### 与"本地优先"VP 的兼容性
- 用户**选择权**：
  - 想要绝对隐私 → 用本地模式（数据 0 传出）
  - 想要便利 → 用开箱即用 API（数据经你代理）
- 类比：iPhone 自带隐私，Android 给你选择
- Sidemate 给你选择

### 0.9.8 定价建议（草稿，0.9.8 前定稿）

| Tier | 内容 | 价格 | 目标用户 |
|------|------|------|---------|
| **免费** | 100 次/天（≈ 0.5 美分成本）| 0 | 试用 / 引流 |
| **个人包月** | 1 万次/月 | ¥29 | 学生 / 个人 |
| **个人包年** | 15 万次/年 | ¥199（省 ¥149）| 重度个人用户 |
| **团队包月** | 5 万次/月 + 5 席位 | ¥199 | 小团队 |
| **企业联系** | 不限量 + SLA + 私有化 | 联系销售 | 企业 |

### 0.9.8 协议设计（重要）

| 部分 | 协议 | 理由 |
|------|------|------|
| 核心 Sidemate 代码 | **Apache-2.0** | 开源获客 |
| 开箱即用后端（充值系统 / 渠道账号 / 账本）| **商业许可** | 你的"独家护城河"，不开源 |
| 第三方依赖 | THIRD-PARTY-NOTICES | 保持现状 |

**类比**：GitLab 开源 + GitLab.com 不开源 + 企业版不开源

## 四、3 阶段路线

### 阶段 1：0.9.6-0.9.7（0-3 个月）——「建渠道」

- 核心动作：开源获客
- 收入：0（**投资期，不是收割期**）
- 关键指标：
  - GitHub stars（**目标 100+**）
  - 试用客户 → 真实用户转化（**目标 20+**）
  - Issues / PR 数量（**证明社区活跃**）
- 工作：
  - 0.9.7 切 Apache-2.0（ROADMAP P7-4d）
  - 写 README / CONTRIBUTING / CODE_OF_CONDUCT
  - 公众号 / V2EX / 即刻 / 少数派 1-2 篇发布文
  - 答 GitHub Issues（**最重要的运营动作**）

### 阶段 2：0.9.8-0.10（3-6 个月）——「建产品」

- 核心动作：开箱即用 API 上线
- 收入：**小几千-几万**
- 关键指标：
  - 付费用户数（**目标 10+**）
  - API 调用量（**目标 100 万+/月**）
  - 月留存率（**目标 80%+**）

### 阶段 3：0.10+（6-12 个月）——「建生态」

- 核心动作：扩展包市场 / 大企业合作
- 收入：**几万-几十万**（看付费转化）
- 可选方向：
  - 私有化部署（中大企业）
  - 行业定制（法律 / 教育 / 医疗）
  - 二次开发商渠道

### Tier 设计

| Tier | 服务内容 | 价格 |
|------|---------|------|
| **免费** | GitHub Issues + 文档 | 0 |
| **基础** | Issues 优先回复 + 微信群 | ¥99/年 |

- 验证用户付费意愿（比 A 早 3 个月）
- 给大企业客户打基础（先 C 后 D）

## 七、关键认知：副业做开源产品的"反常识"

| 误区 | 真相 |
|------|------|
| "开源 = 白嫖" | 开源 = **降低获客成本**，大客户还是付费 |
| "开源 = 没人付费" | GitLab / Mattermost / Sentry 都是开源**且**赚大钱 |
| "开源 = 必须做全套治理" | 早期不必，**先有人用**，再谈治理 |
| "副业做开源 = 浪费时间" | 副业最大成本是**获客**，开源 = 降低获客成本 |
| "要等做完美再开源" | **永远做不完美**，"还行"就开源，让用户帮你完善 |
