# 桌伴 Sidemate 隐私声明

> 本文档适用于 **桌伴 Sidemate v0.9.5** 及以上版本。
> 最后更新：2026-06-20

---

## 一、数据存储位置

桌伴是一款 **本地优先（local-first）** 的 AI 办公助手。所有用户数据 **100% 存储在您的本地计算机**，默认路径为：

```
Windows: %LOCALAPPDATA%\Sidemate\data\
```

该目录包含：

- **对话历史**（`data/chats/`）：您与 AI 的所有对话记录
- **文库文档**（`data/kb/`）：您上传的知识库文档及检索索引
- **会议纪要**（`data/minutes/`）：录音文件及转写文本
- **生成文档**（`data/docs/`）：AI 生成的 Word/PDF 等文档
- **程序设置**（`data/config.json`）：您的个性化配置

程序 **不会** 在此目录之外创建任何隐藏的数据存储。

---

## 二、数据收集承诺

我们郑重承诺：

- **不收集** 任何个人身份信息（PII）
- **不上传** 您的对话内容、文档、录音到我们的服务器
- **不跟踪** 您的使用行为，不植入分析 SDK
- **不联网验证** 许可证，离线可完整使用

桌伴本身 **不包含任何云端后端服务**。程序运行所需的一切（AI 模型、嵌入模型、重排序模型）均可在本地离线运行。

---

## 三、外部通信场景

程序 **仅在以下明确由您主动触发的场景** 与外部网络通信：

### 3.1 在线模式（云端 AI）

当您在设置中主动启用 **「云端 AI 模型」** 时：

- 您的 **对话内容** 会发送到您配置的云端 API（如 OpenAI、Anthropic、DeepSeek 等）
- 通信直接发生在 **您的电脑与该 API 服务商之间**，不经过桌伴的任何中间服务器
- 您可在设置中随时关闭云端模式，回到完全离线的本地 AI

### 3.2 网页搜索

当您在对话中主动触发 **「网页搜索」** 功能时：

- 您的 **查询词** 会发送到 Bing 搜索引擎
- 搜索结果由 Bing 返回并展示给您

### 3.3 升级检查

程序启动时可能发送一次 **版本号查询**（GET 请求）：

- 仅发送当前程序版本号，**不含任何用户数据**
- 用于检查是否有新版本可用

## 四、知识库隐私保护

当您使用文库功能时，文档内容受到 **令牌授权系统** 的分级保护：

| 权限级别 | 说明 | 适用场景 |
|---------|------|---------|
| `full` | 文档全文可发送给云端 API | 您信任的文档 |
| `search` | 仅检索摘要可发送，全文不上网 | 默认级别 |
| `none` | 文档完全不上网，仅本地检索 | 敏感文档 |

您可在设置 → 文库权限中为每篇文档单独配置。**默认级别为 `search`**，即文档全文永远不会在您不知情的情况下发送到云端。

## 五、第三方组件

桌伴基于多个开源组件构建，各组件遵循其原始开源许可证。完整的第三方许可声明请参见程序安装目录下的 `THIRD-PARTY-NOTICES.txt`。

主要组件包括：

- **Ollama**（MIT）：本地大语言模型运行时
- **BGE-M3**（MIT）：多语言嵌入与检索模型
- **Faster-Whisper**（MIT）：语音识别引擎
- **FastAPI**（MIT）：后端 Web 框架
- **highlight.js / marked.js / KaTeX**（BSD/MIT）：前端渲染组件

## 六、用户权利

### 6.1 数据导出

您可随时在 **设置 → 备份** 中导出所有数据为 ZIP 压缩包，包含全部对话、文档和设置。

### 6.2 数据删除

- **删除单条数据**：在对话/文库界面直接删除对应条目
- **清除全部数据**：删除安装目录下的 `data/` 文件夹，所有数据随之清除
- **彻底卸载**：删除整个安装目录，程序及所有数据将完全移除

### 6.3 隐私控制

- 您可在设置中 **随时关闭** 云端模式、网页搜索等联网功能
- 关闭后程序将完全离线运行，不产生任何网络请求（除升级检查外）
