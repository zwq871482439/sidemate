# v0.4.5 变更记录 (2026-04-30)

## 里程碑：小册子系统 — 让 AI "记住你"

### 新增
- `pet_notebook.py` — 小册子管理器（六个板块）
  - 身份卡 ~200 token
  - 用户画像 ~300 token（对话中自然采集，非硬编码）
  - 关键事实 ~500 token（动态采集，千人千面）
  - 术语库 ~400 token（私有概念词典）
  - 技能清单 ~200 token
  - 近期摘要 ~500 token
- System prompt 注入：小册子内容自动拼接为 system prompt 前缀
- `extract_and_update()`：对话中自动检测用户名/城市/项目等实体，写入小册子
- 术语库管理 API：手动添加/删除 + 批量导入（术语=解释格式）
- 小册子 UI：🦐个性 Tab 提供用户画像/关键事实/术语库编辑入口

### Bug 修复（7 项）
| # | Bug | 修复 |
|---|-----|------|
| 1 | session 切换后选择框不显示当前 session | 正确更新 Dropdown value |
| 2 | 选图片后无法输入文字 | 允许同时输入文字和图片 |
| 3 | 空白消息可发送 | 添加空消息检查 |
| 4 | 多余发送按钮 | 只保留一个 |
| 5 | 停止按钮不彻底 | 可靠中断模型生成 |
| 6 | 小册子内容过长撑爆上下文 | 总计 ~1700 token 限制 |
| 7 | 术语注入格式不规范 | 标准化为 `术语 = 解释` |

### 设计决策
- 用户画像**完全动态采集**，不预设默认信息
- 小册子 = JSON 文件，存在工作空间目录
- 六板块总计 ~1700 token，1.5B 模型也可承受
