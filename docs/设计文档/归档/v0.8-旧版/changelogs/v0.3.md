# v0.3 变更记录 (2026-04-30)

## 里程碑：UI 优化 + 思维链分离 + 体验打磨

### 新增
- `chat_stream()` 结构化输出：yield `(phase, content)` 元组，phase: raw/fold/text
- 思维链分离：前端 `<details>` 折叠显示思考过程 + 正文流式输出
- 统计信息 tag 化：`model` `X字` `Xs` `X字/s` 内联标签样式
- 模型选择联动：Dropdown 动态读取 `get_loaded_llms()`
- 设置选项卡：模型加载/卸载 + 环境信息（替代旧"状态"Tab）
- 启发式思维链检测 `_looks_like_thinking()` + `_split_think_response()`
- 历史清洗 `_clean_history_for_model()`：移除统计标签/HTML/限制6轮/按字符截断6000
- 异常检测 `_check_stall()`：速度<4字/s 或 重复率>60% → 自动中断重试
- 动态模型选择：优先级列表自动选 DEFAULT_LLM，不再硬编码

### 踩坑（共 3 轮修复）

#### 第一轮：无标签思维链泄露
- **问题**：DeepSeek 1.5B 不用 `<think...>` 标签，直接输出英文推理 "Okay, so..."
- **修复**：新增启发式检测，18 条正则匹配推理语言模式
- **局限**：启发式不 100% 准确，可能误判英文正文

#### 第二轮：对话历史污染
- **问题**：上轮回复的统计标签（`deepseek-1.5b` `15字`）被当历史传给模型
- **现象**：模型开始重复统计标签、引用上轮内容
- **修复**：`_clean_history_for_model()` 移除标签和 `<details>` 块

#### 第三轮：启发式检测不足
- 新增覆盖 30 条模式（英文 + 中文推理语言）
- 最终扩展到 48 条，11 个测试用例全部通过
- 中文模式：用户说/问/发、首先、接下来、综合来看、所以、我觉得...

### 关键文件
- `models.py` — chat_stream yield 元组、get_loaded_llms()、启发式检测、历史清洗、异常检测
- `server.py` — 思维链分离、tag 统计、模型联动、设置 Tab
