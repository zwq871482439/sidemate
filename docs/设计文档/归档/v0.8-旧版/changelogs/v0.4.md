# v0.4 变更记录 (2026-04-30)

## 里程碑：对话体验完善 + 滑动窗口

### 新增
- OCR Tab 优化，支持拖拽上传图片
- 对话历史持久化：保存到本地 JSON（`chats/` 目录，按天编号）
- 多轮对话上下文正确传递
- 滑动窗口：保留最近 N 轮原文，超出硬截断，防止上下文爆炸
- 错误处理美化：友好提示代替报错文本
- 模型历史清洗增强：`<details>` 标签彻底清理 + 轮次限制

### 踩坑
1. **上下文爆炸** — 多轮对话后 token 数超过模型上下文长度
   - 修复：滑动窗口硬截断，保留最近 6 轮
   - 后续：v0.4.5 引入小册子系统做长期记忆
2. **历史标签套娃** — 上轮的统计标签被模型当成输入，开始"复读"
   - 修复：`_clean_history_for_model()` 正则清理
3. **Gradio Tab 渲染死锁** — MutationObserver 冲突导致页面卡死
   - 这是 Gradio 6 的 bug，无法在代码层面修复
   - 最终导致 v0.5 彻底去掉 Gradio

### 关键文件
- `models.py` — 滑动窗口、历史清洗增强
- `server.py` — 对话持久化、OCR Tab、错误处理
