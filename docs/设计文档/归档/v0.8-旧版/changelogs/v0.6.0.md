## 一、智能任务分类器（核心功能）

> 新增 `task_classifier.py`，加权关键词评分，纯函数无依赖，微秒级延迟。从 v1(~80%) 迭代到 v3(100%, 156 用例)。

### 分类算法

| 版本 | 准确率 | 测试用例 | 关键改进 |
|------|--------|---------|---------|
| v1 | ~80% | 14 | 基础加权关键词 |
| v2 | ~84% | 64 | 移除泛词，新增覆盖 |
| v3 | 100% | 156 | 强信号正则优先锁定，CODE>MATH>TEXT 顺序 |

### 三档思考控制策略

| 任务类型 | 思考控制 | temperature | 效果 |
|----------|----------|-------------|------|
| reasoning | 不限制（full think） | 0.6 | 保持原有行为 |
| code | `/no_think` | 0.5 | 代码质量更优 |
| text | `/no_think` | 0.4 | 速度 +78% |

### 集成点

- `models.py` `_build_prompt()`：分类 -> 注入思考指令 -> 微调 temperature
- `server.py` SSE：新增 `task_type` 事件透传给前端
- `index.html` 状态栏：展示当前任务类型标签（reasoning=蓝、code=绿、text=橙）

## 二、Session 互锁

> 生成期间禁止 Session 切换/新建/删除操作，防止上下文污染。

### 实现

- `switchSession()` / `newSession()` / `deleteSession()` 入口加 `if (generating) return`
- 发送消息时禁用 session 操作按钮（disabled + CSS 灰显）
- 停止按钮恢复时解锁

---

## 三、话题漂移检测

> 检测对话话题变化，建议用户新建 Session，避免上下文污染。

### 触发条件

| 条件 | 阈值 | 说明 |
|------|------|------|
| 话题漂移 | 关键词重叠度 < 30% | 当前消息与最近 3 条消息的关键词集合重合率低 |
| Session 膨胀 | 消息数 > max_rounds * 2 | 动态跟随模型 profile |
| 时间间隔 | > 30 分钟 | 辅助信号，不单独触发 |

### 前端交互

- 非侵入式提示条：`检测到新话题，建议新建对话 [新建对话] [继续当前]`
- 不阻断输入，用户可直接忽略继续打字
- 关键词提取：中文按字符 bigram / 英文空格分词，无额外依赖

## 十一、设计决策

| 决策 | 理由 |
|------|------|
| 不走微服务 | 本地单用户应用，模块化单进程足够，微服务通信开销是负收益 |
| 过滤器只标注不修改 | 小模型输出上下文敏感，自动修复可能引入更多问题 |
| 分类器纯函数 | 无类、无外部依赖、微秒级延迟 |
| 8B 模型 code 类型用 /no_think | 8B 短思考反而降低代码质量 |
| 版本跟着模块走 | 更新模块时版本号就在那个文件里，不需要去 server.py 同步 |
