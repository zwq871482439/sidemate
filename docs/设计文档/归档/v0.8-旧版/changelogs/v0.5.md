# v0.5 变更记录 (2026-04-30)

## 里程碑：纯 HTML 前端重写 — 彻底去掉 Gradio

### 背景
Gradio 6 的 Tab 组件存在**渲染死锁 bug**（MutationObserver 冲突、Dropdown 校验崩溃），无法修复。
纯 HTML 不存在虚拟 DOM 冲突，彻底解决页面卡死。

### 架构变更
- **去掉**：Gradio 依赖（~600 行 UI 代码全部删除）
- **新增**：`index.html`（纯 HTML + fetch API + SSE，单页应用）
- 四 Tab：💬对话 / 🦐个性 / 🔍OCR / ⚙️设置
- 服务：FastAPI + 纯 HTML/JS，端口 8976

### 新增
| # | 功能 | 说明 |
|---|------|------|
| 1 | 对话管理 REST API | 新建/切换/删除/列表 对话，`chats/` 目录存储 |
| 2 | 小册子 REST API | 用户画像/关键事实/术语库 CRUD（含删除） |
| 3 | SSE 流式对话 | `POST /api/chat/stream`，前端 ReadableStream 消费 |
| 4 | 模型加载 loading | 全局 spinner 遮罩 + 按钮状态切换 |
| 5 | 小册子 UI 优化 | 用户画像表格化、关键事实/术语库可逐条删除 |
| 6 | Markdown 渲染 | 代码块未闭合兜底、列表/引用/标题正确渲染 |
| 7 | 统计数据修复 | 速度 = (正文+思考)/总时间，显示思考字数 |
| 8 | SSE 渲染节流 | 80ms 节流避免每个 token 都操作 DOM |
| 9 | 第二次发送 bug | assistant 消息补全所有字段，renderMsg 加 null check |

### 踩坑
1. **SSE 渲染抖动** — 每个 token 都操作 DOM 导致卡顿
   - 修复：80ms 节流，requestAnimationFrame 批量更新
2. **代码块未闭合** — 模型输出 ``` 但没写 ``` 就停了，Markdown 渲染崩溃
   - 修复：渲染前检测，自动补全闭合标记
3. **第二次发送崩溃** — renderMsg 遇到缺少字段的 assistant 消息报错
   - 修复：所有字段默认值兜底

### 关键文件
- `server.py` — 大幅重构，删除 Gradio 代码，新增 REST API + SSE
- `index.html` — 全新纯 HTML/JS 前端（~800 行）
- `models.py` — 未改动（模型管理逻辑不变）

### 设计决策
- 无模型下载器，用户手动放模型到 `models/`
- 环境检测只做提示不阻断
- 服务：FastAPI + 纯 HTML/JS，端口 8976
