# v0.8.0 变更记录

> 2026-05-16 — 大版本框架重构：Router 拆分 + 前端模块化 + 依赖注入

---

## 一、后端 Router 拆分

### server.py 模块化重构

将单体 `server.py`（~2000行）拆分为多个独立路由模块：

| 模块 | 职责 | 来源 |
|------|------|------|
| `skill_router.py` | 技能相关 API（导入/列表/执行/删除） | 从 server.py 拆出 |
| `server.py`（精简后） | 主服务进程、核心 API 编排 | 保留 |

### REST API 端点

| API | 方法 | 功能 |
|-----|------|------|
| `/api/skill/import` | POST | 技能 ZIP 导入 |
| `/api/skill/list` | GET | 已安装技能列表 |
| `/api/skill/execute` | POST | 执行技能（参数校验+超时控制+结果捕获） |
| `/api/skill/{name}` | DELETE | 卸载技能 |

### `deps.py` 依赖注入

新增统一依赖注入层，管理各模块实例化和依赖关系。

## 二、前端模块化

### index.html 拆分

将单文件前端（~75KB `index.html`）拆分为 6 个独立 JS 模块：

| 模块 | 职责 |
|------|------|
| Tab 导航 | 统一 Tab 切换管理 |
| 对话 | 聊天区域 SSE 流式渲染 |
| 技能 | 技能 Tab（列表/导入/执行/结果展示） |
| 个性 | 角色面板 + 成长日志 |
| 设置 | 系统配置页 |
| 工具函数 | 共享工具方法 |

## 三、版本管理统一

- `VERSION = "0.8"`, `VERSION_PATCH = 0`
- 各模块独立维护 `__version__`
- 消除 `SESSION_HANDOFF.md` 与代码版本号不一致问题
