# 桌伴 · 部署指南

## 浏览器兼容性要求

桌伴的网页界面依赖以下现代浏览器 API，请确保浏览器版本支持：

- **ES2020+**：界面代码使用了 `Promise.allSettled`、可选链（`?.`）等 ES2020 特性
- **MediaRecorder API**：录音纪要功能需要浏览器支持 MediaRecorder（用于录制音频）
- **EventSource API**：对话流式输出和模块安装进度通过 SSE（Server-Sent Events）推送，依赖 EventSource

推荐使用 Chrome 或 Edge 最新版本。不支持 IE 及旧版浏览器。

## 启动步骤

### 1. 启动后端服务

双击项目目录下的 `start.bat`，脚本会自动：
- 激活 Python 虚拟环境
- 启动后端服务

启动成功后，命令行窗口会显示：

```
聊天窗: http://127.0.0.1:8976
API:    http://127.0.0.1:8976/api/status
```

### 2. 访问网页界面

在浏览器地址栏输入 `http://localhost:8976`，即可打开桌伴主页。

### 端口修改

默认端口为 **8976**。如需修改，可在命令行设置环境变量后启动：

```
set LOCAL_AI_PORT=8399
start.bat
```

或在 `server.py` 第 71 行修改 `PORT` 的默认值。

## 首次加载注意事项

### 首次启动（无模型）

首次启动时，项目没有任何 AI 模型，界面会显示**三步欢迎引导页**：
1. 安装模型扩展包
2. 选择推理设备（NPU/GPU/CPU）
3. 加载模型

按照引导页的提示逐步完成即可。

### 已有模型再次启动

如果之前已经加载过模型，再次启动时会显示**模型锁定遮罩**（对话区覆盖"对话功能需要模型支持"提示）。此时需要：
- 等待模型自动加载完成（状态标签从"加载中"变为模型名称）
- 或前往设置 Tab 手动触发加载

### 模型加载时间

- **首次编译到 NPU**：约需 3-5 分钟（NPU 需要将模型编译为设备专用格式）
- **GPU/CPU 模式**：加载速度较快，通常在 1 分钟内完成
- **后续启动**：已编译模型加载速度更快

加载过程中，前端会通过 SSE 显示实时进度条。

## Vendor 依赖说明

桌伴使用两个开源前端库来增强显示效果，两个库均已内置在项目中，**完全离线加载，不依赖任何外部 CDN**。

### KaTeX - LaTeX 数学公式渲染

| 文件 | 作用 |
|------|------|
| `/static/vendor/katex.min.css` | 公式样式 |
| `/static/vendor/katex.min.js` | 公式渲染引擎 |

- 自动检测消息中的 `$...$` 和 `$$...$$` 公式语法
- 渲染失败时**自动降级为源码显示**，不影响阅读

### highlight.js - 代码语法高亮

| 文件 | 作用 |
|------|------|
| `/static/vendor/highlight.min.js` | 代码高亮引擎 |
| `/static/vendor/highlight.min.css` | 亮色主题样式 |
| `/static/vendor/highlight-dark.min.css` | 暗色主题样式 |

- 自动识别代码块语言并应用语法高亮
- **暗色模式切换时**，自动替换为 `highlight-dark.min.css` 深色主题，无需手动操作

## 注意事项

- **仅支持桌面端**：网页界面针对桌面浏览器设计，暂不支持移动端访问
- **数据全本地存储**：所有聊天记录、文库文档、录音文件均存储在项目 `data/` 目录中
- **纯离线部署**：整个项目完全离线运行，不访问任何外部网络，无需 GPU 云服务
