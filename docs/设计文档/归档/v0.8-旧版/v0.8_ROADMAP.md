## Patch 6 — 本地知识库 + 录音纪要

**核心产品形态**：问答 Tab 演变为**本地知识库**

### 知识库功能

| 功能 | 说明 |
|------|------|
| 文件导入 | 支持 PDF、Word、Excel、TXT、Markdown 等格式导入 |
| 异步处理 | 导入后后台异步解析（分块、向量化），前端显示处理进度 |
| 进度提示 | 处理中倒计时 + 进度条，预估剩余时间 |
| 问答交互 | 处理完成后，基于知识库内容进行问答 |
| 来源标注 | 回答时标注来源文件和段落（patch 5 #14 的基础） |

### 录音纪要功能

| 功能 | 说明 |
|------|------|
| 浏览器录音 | MediaRecorder API，原生实现，不依赖外部服务 |
| 分块缓冲 | 每 10-30 秒切一块，投入 Whisper 处理队列 |
| 准实时预览 | 前端滚动显示转录文字（有几秒延迟） |
| 文字稿下载 | 停止录音后可下载完整文字稿 |
| AI 总结 | 录音完成后可交给 AI 生成会议纪要 |

### PDF 读取

| 功能 | 说明 |
|------|------|
| 文字提取 | PyPDF2 / pdfplumber 提取文字和表格 |
| 知识库集成 | PDF 作为知识库的重要文件来源 |

## Patch 7 — 在线补课 + 自审压缩

> 统一使用 8B 模型，不考虑 1.5B 降级逻辑

### 在线补课（会话复盘）

| 功能 | 说明 |
|------|------|
| 切换检测 | 用户从离线切换到在线时触发 |
| 复盘提示 | 弹窗："检测到 N 条踩反馈 + M 轮对话，是否启动云端补课？" |
| 云端分析 | 云端教师读踩反馈 + 未压缩 session，输出"典型错误模式"清单 |
| 写入记忆 | 分析结果写入 memory（source=在线补课） |

### 本地自审压缩

| 功能 | 说明 |
|------|------|
| 自审 prompt | 压缩 prompt 升级为结构化自审（8B 模型专用，不降级） |
| 自审内容 | 对每个问题评估处理质量 1-5 分，识别问题，提炼改进建议 |
| 写入记忆 | 自审结论（2-3 条最值得记住的）写入 memory |

## 架构原则（全版本通用）

1. **离线优先**：核心功能不依赖网络
2. **数据不出本机**：所有用户数据仅存本地
3. **8B 模型**：统一使用 8B 参数模型，不考虑小模型降级
4. **Skill 框架**：新增功能优先走 Skill 框架（权限+审计）
5. **增量迭代**：每个 patch 独立可交付，不跨 patch 耦合
