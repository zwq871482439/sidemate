# KB Prompt 调优记录

> 日期：2026-05-20 | 模型：Qwen3-8B (OpenVINO NPU) | 场景：知识库问答

---

## 背景

8B 小模型在 KB 问答模式下存在三个核心问题：
1. **风格失控**：加"综上所述""备注""参考文献"等套话
2. **引用泛滥**：弱相关资料也被引用（如 feedback.py）
3. **格式混乱**：用缩进伪标题（`    标题：`）制造空白

---

## 迭代历程

### v1 → v2 → v3：纯规则驱动（已到天花板）

| 版本 | 规则数 | 关键改动 | Q1对比题 | Q2简单题 | Q3 RAG题 |
|------|--------|----------|----------|----------|----------|
| v1 | 3条 | 反幻觉3约束 | 4/10 | 7/10 | 2/10 |
| v2 | 5条 | +概念映射 +禁止套话 | 5/10 | 8/10 | 8/10 |
| v3 | 5条 | 否定→正面指令 | 5/10 | 8.5/10 | 9/10 |

**结论**：概念映射（规则2）是 v1→v2 的关键跃迁（RAG 2→8）。但规则4/5（禁止收尾套话+只列相关引用）三版都没起效，8B 模型对抽象风格规则的理解到天花板了。

### v4：Few-shot 示例（对话 turns）

**策略**：在 user/assistant turns 里放 2-3 个示例，教模型模仿简洁风格。

| 版本 | 改动 | Q1对比题 | Q2简单题 | Q3 RAG题 |
|------|------|----------|----------|----------|
| v4 | 2个Few-shot turns | - | - | - |
| v4.1 | 3个Few-shot（+对比示例） | 3/10 | 4/10 | - |

**致命问题（P0）**：Few-shot 放在对话 turns 里，当用户问题和示例完全相同时，模型混淆了示例与真实对话，把其他示例的答案也吐出来。Q2"系统能联网吗"和示例1一模一样，模型把示例2"参考资料中未提及语音输入"也输出了。

**结论**：user/assistant turns 方式的 Few-shot 对 8B 模型有泄漏风险，不可用。

### v5：System-embedded 格式引导

**策略**：把格式引导从对话 turns 移到 system prompt 内，用抽象格式描述代替具体示例。

```
/no_think
基于资料回答。只答事实，不编造。答完即停。
格式：
简单问题→一句话回答，引用标[序号]
对比问题→用 - 项目：说明 的列表
资料不足→说明资料中未提及
```

| 版本 | Q1对比题 | Q2简单题 | Q3 RAG题 |
|------|----------|----------|----------|
| v5 | **7/10** ↑ | **9/10** ↑ | 7/10 ↓ |

**改善**：Q1 格式改善（终于用列表而非伪标题），Q2 泄漏彻底修复。
**退化**：Q3 变保守 — v5 丢掉了概念映射规则，模型不敢把 Doc/QA 关联到 RAG。

### v5.1：补回概念映射（当前版本）

```
/no_think
基于资料回答。只答事实，不编造。答完即停。
用户用词和资料描述若指同一概念，识别并关联。
格式：
简单问题→一句话回答，引用标[序号]
对比问题→用 - 项目：说明 的列表
资料不足→说明资料中未提及
```

预期效果：保持 v5 的格式改善和零泄漏，恢复 Q3 的概念映射能力。

## 配套修复：md() 伪标题渲染

8B 模型常输出 `    默认行为不同：` 这种缩进伪标题，md() 原来不识别，导致大片空白。

**修复**：识别 2+空格开头的非列表短行（<40字）→ `<strong>` 加粗，并清理与列表间的多余 `<br>`。

文件：`index.html` md() 函数

## 关键经验

| 经验 | 说明 |
|------|------|
| 规则数 ≤3 | 8B 模型规则超3条就记不住，精简到3条核心规则 |
| 概念映射是关键 | "用户用词和资料描述若指同一概念，识别并关联" — 这一条的效果>其他所有规则之和 |
| 正面>负面 | "答完即停"比"不要加总结套话"有效 |
| 格式引导>内容规则 | "用 - 项目：说明 的列表"比"不要用缩进伪标题"有效 |
| Few-shot 要防泄漏 | 具体示例不能放在对话 turns 里，会泄漏；用 system prompt 内的抽象格式描述更安全 |
| Prompt 能力天花板 | 风格控制（不加套话）和引用精度（只列相关）已到 8B 模型 prompt-only 方式的极限 |
