## 一、录音纪要核心（P6-9）

### 新增 `recorder.py`

录音会话管理器，核心能力：

| 能力 | 实现 | 决策编号 |
|------|------|----------|
| 录音会话 CRUD | start/finish/append_chunk/delete | — |
| 实时音频块落盘 | chunk_001.webm... chunk_N.webm | D36 崩溃恢复 |
| 处理队列控制 | 暂停/恢复/取消 | D27 |
| 崩溃恢复 | 启动扫描 sessions.json，恢复未完成 session | D36 |
| 录音独立额度 | 最多20个session，不占知识库20文档额度 | D39 |

### 两阶段转写流水线（P6-13）

```
音频 → [CPU: Whisper粗稿] → 粗稿文本 → [NPU: 8B纠错润色] → 最终稿
```

- Whisper 在 CPU 上转写，8B 在 NPU 上纠错（D19 硬件分配）
- 8B 按 500-1000 字/批次纠错（D37）
- 转写期间对话 Tab 锁定（D22 资源保护）
- 纠错失败回退用粗稿

### 会议纪要生成（P6-15）

8B 模型将转写稿整理为结构化纪要（主题+要点+待办+决策）。

### 转写稿入库（P6-14）

一键导入知识库，调用 `kb.import_text()`，独立检索索引（D39）。

## 二、Whisper 扩展包管理（P6-10）

### 扩展包 API

| API | 方法 | 功能 |
|-----|------|------|
| `/api/extensions/upload` | POST | 上传 ZIP 安装扩展 |
| `/api/extensions/list` | GET | 已安装扩展列表 |
| `/api/extensions/{name}` | DELETE | 卸载扩展 |

### 安装流程

ZIP → 解压 → 读 manifest.json → 检查冲突 → 复制到 extensions/whisper/ → 安装 wheels → 完成

## 三、Whisper 加载/释放（P6-11）

### API 端点

| API | 方法 | 功能 |
|-----|------|------|
| `/api/recorder/whisper/status` | GET | 三阶段状态查询 |
| `/api/recorder/whisper/load` | POST | 加载到 CPU 内存 |
| `/api/recorder/whisper/unload` | POST | 释放内存（D18 退出机制） |

### 模型生命周期

```
[未安装] → 安装ZIP → [已安装未加载] → 加载 → [就绪] → 释放 → [已安装未加载]
```

- 加载后常驻内存，切 Tab 不释放（D15）
- 释放通过底部按钮主动操作（D18）
- 内存占用用 psutil RSS 实测

## 五、前端纪要 Tab（P6-12）

### Tab 栏变更

```
旧: 对话 | 问答 | 记忆 | 技能 | 设置
新: 对话 | 问答 | 纪要 | 记忆 | 技能 | 设置
```

### 三阶段状态视图

| 状态 | 视图 | 功能 |
|------|------|------|
| 未安装 | 安装引导 | 版本选择(small/medium)+ZIP上传 |
| 已安装未加载 | 激活页 | 加载引擎+历史列表+扩展管理 |
| 就绪 | 完整功能 | 录音/导入/处理队列/历史/查看/编辑/纪要/入库 |

### 功能特性

- MediaRecorder 录音 + 每10秒 chunk 上传（D25）
- 录音暂停/恢复（D43）
- 转写稿查看+编辑（D38）
- 原始粗稿折叠对比（D23）
- AI会议纪要生成
- 一键入库知识库
- 历史录音管理+删除（D34）
- 空间占用统计
