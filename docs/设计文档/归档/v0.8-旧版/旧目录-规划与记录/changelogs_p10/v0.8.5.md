# v0.8.5 变更记录

> 2026-05-18 — 训练管理 + 离线压缩 + Prompt 工程修复 + 代码审查 V4 修复

---

## 一、训练管理

### `training.py`（新增）

| 功能 | 实现 |
|------|------|
| 训练记录 | 时间 / 模型 / 参数（lr / epochs / batch_size）/ 数据量 / 耗时 / 效果评分 |
| 参数模板 | 不同模型可存不同参数模板 |
| 导入导出 | JSON / CSV 格式 |

### 训练管理 API

| API | 方法 | 功能 |
|-----|------|------|
| `/api/training/record` | POST | 创建训练记录 |
| `/api/training/history` | GET | 训练历史列表 |
| `/api/training/export` | GET | 导出训练数据 |
| `/api/training/import` | POST | 导入训练数据 |

### 前端训练管理

合并到个性 Tab "高级"折叠区：
- 训练历史列表
- 参数模板管理
- 训练数据导入/导出

## 二、离线压缩增强

### `context_compressor.py` 升级

| 改动 | 说明 |
|------|------|
| 压缩方式 | 调用 `chat_stream` 做摘要，提取关键信息写入小册子 |
| 自审模板（预留） | 压缩 prompt 预留结构化自审扩展点（8B 模型专用） |
| 压缩触发 | 8 轮对话 or 上下文达 70% 容量，取先到者 |

## 三、Prompt 工程修复

### `prompts.py` v3.0 -> v3.1

| 改动 | 说明 |
|------|------|
| THINK_CONTROL 改写 | "允许 think + 正文必须结构化输出"（解决 8B 训练行为 vs 指令冲突） |
| 条件规则池 | `TASK_PROMPT_ENHANCEMENTS` 按任务类型注入不同增强规则 |
| 信号路由 | `get_task_enhancements()` 提取 is_math / is_writing / is_logic / is_summary 子信号 |

### `models.py` v1.6 -> v1.7

| 改动 | 说明 |
|------|------|
| signals 参数 | `_build_prompt` 新增 signals 参数，支持条件规则注入 |
| 信号集成 | `generate_stream` 集成 `get_classify_signals` |
| 推理检测增强 | `_looks_like_reasoning` v2 信号词扩展至 21 个 + 结构检测 |
| body 二次检查 | 修复推理内容泄漏到正文 |

### `server.py` patch4 -> patch5

| 改动 | 说明 |
|------|------|
| 续写分支 | reasoning -> 结构化引导，其他 -> /no_think |
| 007.json bug 修复 | 推理内容泄漏到正文 |
| THINK_CONTROL 矛盾修复 | 8B 训练行为 vs 指令冲突 |

## 四、代码审查 V4 修复

### 稳定性修复

| 问题 | 修复 |
|------|------|
| `_gen_lock` 死锁风险 | 增加强制释放逻辑（NPU 卡死时兜底） |
| `device_limits.json` 并发读写 | 增加 `_device_limits_lock` 线程锁 |
| `_build_prompt` 截断效率 | 改为二分法 + 预计算 token 数 |
| `_is_output_incomplete` rfind 误匹配 | 改用 `m2.end()` 精确位置 |

### Bug 修复（代码审查 V1-V3 遗留）

| 问题 | 修复 |
|------|------|
| `response_filter.py` 缩进错误 | v1.3 修复，过滤功能恢复 |
| `context_compressor.py` `% 2 == 2` | 改为 `% 2 == 0`，注释剥离逻辑生效 |
| `_stats` / `_stats_lock` 未初始化 | 移至 `__init__` 正确初始化 |
| `device_limits.json` 缓存策略 | 只降不升策略，增加文档注释 |
| ZIP 导入一次性读入内存 | 改为 1MB 分块写入 |
| NPU 续写历史过长 | NPU 模式清空 history |
| `_save_settings` 并发写入 | 增加 `_settings_save_lock` |
