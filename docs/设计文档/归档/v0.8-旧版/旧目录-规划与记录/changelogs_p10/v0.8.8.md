## 一、Bug 修复（11 个）

### P0 修复

| Bug | 问题 | 修复 |
|-----|------|------|
| Bug 1 | 结束录音失败 NetworkError — `onstop` 在最后一个 chunk 上传前触发 | 引入 `_lastChunkPromise` 追踪最后一个 chunk 上传完成后再调 finish |
| Bug 4 | 播放器时间显示 `Infinity:NaN` — webm 格式 `audio.duration` 为 Infinity | `formatTime()` 增加 `isFinite()` 检查，`progress.max` 处理 Infinity |
| Bug 5 | 生成纪要提示"加载模型"（模型已加载） — 检查了不存在的 `modelData.models` 字段 | 改为 `modelData.loaded && modelData.loaded.length > 0` |
| Bug 6 | 纠错润色提示"加载模型" — 同 Bug 5 根因 | 同 Bug 5 修复 |
| Bug 8 | 模型队列 30s 无响应 — `_generate` 线程等队列时主线程 `q.get(timeout=30)` 先超时 | 队列票据获取后通知主线程，分离队列等待和推理超时 |
| Bug 9 | 停止按钮无效 — 前端 abort 后未等后端 stop 完成 | `stopGeneration()` 改为 `await` 后端 `/api/stop` 完成后再恢复 UI |

### P1 修复

| Bug | 问题 | 修复 |
|-----|------|------|
| Bug 2 | 转写卡在 0% — Whisper 阻塞调用无中间进度 | 后端进入 Whisper 前设置 `progress=0.05`；前端 `progress<0.1` 时不显示百分比，改用动态提示 |

| Bug 11 | 摘要无法完成 — LOW 优先级被 HIGH 抢占后重试次数不足 | 增加重试次数（3→5），显示"摘要生成中（后台重试中）"状态，添加"手动重新生成摘要"按钮 |
