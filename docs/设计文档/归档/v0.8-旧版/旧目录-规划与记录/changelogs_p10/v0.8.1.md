# v0.8.1 变更记录

> 2026-05-17 — 知识库增强：KB 问答检索优化 + chunk 分块策略 + PDF 解析升级

---

## 一、知识库问答增强

### 语义检索升级

| 改动 | 说明 |
|------|------|
| 嵌入模型集成 | `bge-small-zh-v1.5`（~90MB，512维），语义检索优于关键词匹配 |
| 双引擎策略 | bge 优先 -> TF-IDF 降级（模型不可用时回退） |
| 向量存储 | numpy 矩阵存储，500 chunk x 512 维 ~1MB |
| 检索方式 | 余弦相似度排序，top-k 返回 |

### 知识库问答流程

```
用户提问 -> query 嵌入 -> 余弦相似度排序 -> Top-k chunk 拼接 context -> 构造 prompt -> LLM 生成回答（含来源标注）
```

来源标注格式：`[来源: 文档名 §段落标题]`

## 二、文档分块优化

### `chunker.py`（新增）

| 策略 | 适用场景 | 参数 |
|------|----------|------|
| 章节分块 | 有标题结构的长文档 | 按标题层级切分 |
| 段落分块 | 普通文档 | 按段落边界对齐 |
| 固定分块 | 无结构文档 | 2500字/块，200字 overlap |

中文句子边界对齐，避免在句子中间切断。

### `chunking_orchestrator.py`（新增）

MapReduce 混合编排引擎，4 种处理模式：

| 模式 | 用途 |
|------|------|
| extract | 信息提取 |
| qa | 问答分析 |
| summarize | 文档摘要 |
| analyze | 深度分析 |

SSE 事件流推送进度。

## 三、PDF 解析升级

| 改动 | 说明 |
|------|------|
| 解析器升级 | `pdfplumber` 优先 -> `pypdf` 回退 |
| 表格提取 | `page.extract_tables()` -> 文本格式输出 |
| 知识库上传 | 100 页上限 |
| 问答 Tab 上传 | 50 页上限 |

## 四、大文档处理

支持 300-500 页长文档：
- 分块数量上限放宽到 1000
- 嵌入向量化分批处理：每批 50 个 chunk
- 完全异步，前端轮询进度
