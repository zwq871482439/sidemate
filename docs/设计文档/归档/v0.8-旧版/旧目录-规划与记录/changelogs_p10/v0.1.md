# v0.1 变更记录 (2026-04-29)

## 里程碑：最小可用原型

### 新增
- `server.py` — FastAPI 服务 + Gradio 6 聊天界面，端口 8976
- `models.py` — 模型管理器（单例、线程安全），统一管理 OCR + LLM
- `mcp_server.py` — MCP Server（stdio），外部 AI 工具可调用本地能力
- `install.py` — 一键安装依赖脚本
- OCR 集成（RapidOCR-openvino，CPU 推理，~1s/页）
- NPU 加速推理（OpenVINO GenAI，INT4 量化）
- 三方协作验证通过：slow ↔ 小虾(云端) → MCP → 本地助手(NPU)

### 踩坑
1. `SyntaxWarning: \_` — docstring 中 Windows 路径 `\_` 被视为转义，改为 `\\`
2. `NameError: gr not defined` — import 在函数内部，mount 在外部，移到顶部
3. Gradio 6.13 Chatbot 不接受 `type="messages"` — 6.x 默认就是 messages 格式，移除参数
4. Gradio 6.13 要求 chat_fn 返回 messages 格式 — 返回完整列表而非字符串
5. Windows GBK 不支持 emoji — MCP 子进程全部改用纯 ASCII
