# v0.5.2 变更记录 (2026-04-30)

## 改动

### 自动续写机制
- `_is_output_incomplete()` 启发式检测：未闭合代码块/未闭合括号/截断标记结尾
- 检测到不完整 → 先闭合代码块 → 追加"继续输出"提示 → 再生成一次
- 续写最多一次（不递归）

### 前端 7 项修复
1. 离线模式标签移到状态栏首位
2. 未加载设备标签显示"--"
3. 删除 session 后自动切到最近的
4. 等待思考时显示脉动动画
5. 思考内容灰色斜体+可折叠
6. 新消息自动滚到底部
7. 续写时代码块衔接（闭合+分隔+续写内容）
