# v0.8 patch10 变更记录

> 2026-05-23 — Patch 10：扩展中心 + Agent 改进 + 深色模式 + Bug 修复

---

## 一、P0 Bug 修复

| Bug | 修复 | 文件 |
|-----|------|------|
| `stream=True` 参数错误 | `chunking_orchestrator.py` 移除不支持的 `stream=True` 参数，修复长文本 QA 崩溃 | `chunking_orchestrator.py` |
| `_stop_generation` 竞态条件 | 统一为 `stop_requested` property，所有读写通过 `@property` + `@setter` 加锁保护 | `models.py`, `routers/chat.py` |
| `max_tokens=None` 未处理 | `chat_stream` 开头增加 `max_tokens = max_tokens or 1500` 回退 | `models.py` |

## 二、深色模式

### CSS 变量

`main.css` 新增 21 个 CSS 变量，定义完整颜色系统：

```css
:root {
  --color-primary: #4f46e5;
  --color-bg: #ffffff;
  --color-text: #1f2937;
  /* ... */
}

[data-theme="dark"] {
  --color-primary: #818cf8;
  --color-bg: #0f172a;
  --color-text: #e2e8f0;
  /* ... */
}
```

### 切换方式

设置面板新增深色/浅色开关，切换时设置 `document.documentElement.dataset.theme`。

### 代码高亮主题

- 浅色模式：`highlight.min.css`
- 深色模式：`highlight-dark.min.css`

## 三、扩展中心

### 设置 Tab 重构

删除训练记录/参数模板/云端配置/审计日志等面板，新增**扩展中心**：

| 功能 | 说明 |
|------|------|
| 统一安装接口 | 上传 ZIP 自动识别类型（model/knowledge/whisper）并安装 |
| Tab 动态显隐 | 未安装的模块对应 Tab 自动隐藏 |
| 通用卸载 | 一键卸载已安装扩展 |
| 安装进度 | 后端 SSE 推送安装进度，前端显示进度条 |

### 新增文件

| 文件 | 说明 |
|------|------|
| `static/vendor/highlight.min.js` | 代码高亮库 |
| `static/vendor/highlight.min.css` | 浅色主题 |
| `static/vendor/highlight-dark.min.css` | 深色主题 |

## 四、KB 状态机简化

### 三态 → 二态

```
旧：[未安装] → [已安装未加载] → [已加载]
新：[未安装] → [已加载]（安装完自动加载）
```

- 移除"已安装未加载"中间状态
- 安装完成后自动触发模型加载
- 问答 Tab、纪要 Tab 适配二态路由

## 五、Agent 智能化改进

### prompts.py v3.2

- 强化工具调用规则：明确 `[TOOL_CALL:xxx|{...}]` 格式要求
- 添加 one-shot 示例：提升小模型工具调用的成功率
- 移除 `web_search` 工具

### agent.py v2.1

- **早期终止**：模型输出含 `[DONE]` 或明确的拒绝信号时立即终止循环
- **硬上限 20**：`min(max_iterations, 20)` 防止配置错误导致无限循环
- **重试机制**：工具调用失败时自动重试一次
- **think 提取**：Agent 回复前提取 `<think/>` 内容

### task_classifier.py

- `web_reader` 工具映射改为 `kb_search`

## 六、代码块高亮 + 复制

### Markdown 渲染

`utils.js` 的 `md()` 函数输出带 `language-{lang}` class 的代码块，`highlight.js` 自动识别并高亮。

### 复制按钮

每个代码块右上角显示"复制"按钮，点击后调用 `copyCode()` 复制代码到剪贴板。
