## 一、权限系统

### `permissions.py`（新增）

4 种权限模式，控制 Skill 执行能力：

| 模式 | 读文件 | 写文件 | 联网搜索 | 安装软件 | 敏感操作 |
|------|--------|--------|----------|----------|----------|
| 问答 | 允许 | 禁止 | 禁止 | 禁止 | 禁止 |
| 规划 | 允许 | 禁止 | 允许 | 禁止 | 禁止 |
| 执行 | 允许 | 允许（沙箱内） | 允许 | 禁止 | 需确认 |
| 员工 | 允许 | 允许（沙箱内） | 允许 | 需确认 | 需确认 |

### 权限检查中间件

- Skill 执行前检查权限
- 白名单路径校验
- 操作类型校验（读/写/创建）
- 越界操作拒绝

### 前端权限选择

- 发送按钮旁下拉菜单切换权限模式
- 不同模式不同图标和颜色
- 敏感操作弹窗确认（展示操作类型+目标路径）
- 可勾选"自动允许"

## 二、审计日志

### `audit_log.py`（新增）

记录所有 Skill 文件操作：

| 字段 | 说明 |
|------|------|
| 时间戳 | 操作发生时间 |
| Skill 名 | 触发操作的技能 |
| 操作类型 | 读/写/创建/删除 |
| 目标路径 | 操作的文件路径 |
| 结果 | 成功/失败/拒绝 |
| 确认状态 | 用户是否确认 |

存储格式：JSON Lines，存 `logs/audit.jsonl`

### 审计查看 UI

设置页展示审计记录列表，支持按 Skill / 时间 / 操作类型筛选。

## 四、反馈机制

### `feedback.py`（新增）

| 功能 | 实现 |
|------|------|
| 赞/踩按钮 | 每条回复下方，反馈持久化到 `feedback.json` |
| 反馈细分类 | 踩时弹出原因选项（答非所问/信息错误/不完整/风格不喜欢/其他） |
| 结构化存储 | 消息 hash / 评分 / 原因 / 时间戳 / session_id |
| 正向范例固化 | 点赞 -> QA 对自动标记为正向范例 -> 写入 memory（type: good_answer） |
| 即时纠正 | 选中文字 -> "这里不对，应该XXX" -> 保存到记忆列表 |

## 五、安全修复（代码审查 V1-V3 修复）

| 问题 | 修复 |
|------|------|
| 文件上传路径遍历 | `_safe_filename()` 校验文件名 |
| 对话管理路径遍历 | `_safe_chat_name()` 校验对话名 |
| ZIP Slip 漏洞 | `_safe_extract_path()` 校验解压路径 |
| API Key 明文存储 | XOR 混淆加密 |
| CORS 允许所有来源 | 环境变量控制 |
| 上传文件无大小限制 | `_UPLOAD_MAX_SIZE` 检查 |
| 数据文件并发写入 | pet_notebook / feedback / training 各自加 `_save_lock` |
