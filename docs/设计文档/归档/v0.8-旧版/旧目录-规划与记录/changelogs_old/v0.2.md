# v0.2 变更记录 (2026-04-29)

## 里程碑：流式输出 + 互斥加载

### 新增
- `chat_stream()` 流式生成器：OpenVINO GenAI streamer 回调 + queue.Queue + 独立线程
- 思维链过滤：缓冲 token，检测 `<think...>` 标签，过滤后输出
- LLM 互斥加载：加载新 LLM 前自动卸载旧的（NPU 显存有限）
- MCP → HTTP API 共享：MCP Server 不再独立加载模型，改调 localhost:8976 API
- 流式降级策略：streamer 不支持时回退到非流式一次性输出

### 踩坑
1. 思维链泄露 — DeepSeek R1 模型输出推理过程，有时有 `<think` 标签有时没有
   - `_strip_think()` 正则过滤，流式模式用缓冲区检测
   - 1.5B 小模型经常不用标准标签，直接把推理混在回复里 → v0.3 继续

### 架构
```
用户浏览器 → server.py (FastAPI+Gradio, :8976)
                    │
                    ├── ModelManager (单例)
                    │     ├── LLM (NPU, 互斥)
                    │     └── OCR (CPU, 常驻)
                    │
小虾(云端) → mcp_server.py → HTTP API → server.py
```
