## 一、Skill 框架

### `skill_loader.py`（新增）

技能导入执行引擎，核心流程：

```
ZIP 导入 -> 解压到 skills/ -> 读 skill.json -> 注册到内存列表 -> 持久化 skills_registry.json
```

| 能力 | 实现 |
|------|------|
| 技能注册 | `skill.json` 解析 + 元信息提取 |
| 执行引擎 | `execute_skill(name, params)` -> 参数校验 -> subprocess 执行 `main.py` -> 超时控制(30s) -> 结果捕获 |
| 沙箱隔离 | subprocess 独立进程，超时自动终止 |
| 卸载 | 删除技能目录 + 从注册表移除 |

### 技能目录结构

```
skills/
  ├── registry.json           # 技能注册表（自动生成）
  ├── builtin/                # 内置技能（随版本发布）
  │   ├── file-ops/
  │   ├── word-reader/
  │   ├── word-writer/
  │   ├── code-runner/
  │   ├── kb-search/
  │   ├── xlsx-reader/
  │   └── long-reader/
  └── custom/                 # 用户导入的技能
```

## 二、7 个内置技能

### 内置技能列表

| 技能 | 文件 | 功能 | 依赖 |
|------|------|------|------|
| file-ops | `skill_fileops.py` | 文件操作（列目录/搜索/读文本/新建文件），白名单沙箱 | 无 |
| word-reader | `doc_reader.py` | Word 文档分段读取（首段2000字+尾段500字+中间标题摘要），表格结构提取 | python-docx |
| word-writer | `doc_writer.py` | 模板驱动生成 .docx（报告/摘要/信函模板），输出到 files/ 目录 | python-docx |
| code-runner | 内置 | Python 沙箱执行（subprocess 隔离，30s 超时），支持 matplotlib 图表生成 | 无 |
| kb-search | 内置 | 知识库检索，复用 KB 语义搜索接口 | knowledge_base.py |
| xlsx-reader | 内置 | Excel 读取（多 sheet，最多 50 行），从 server.py 内嵌逻辑提取为独立技能 | openpyxl |
| long-reader | 内置 | 长文本分段处理，自动路由到 chunking_orchestrator | chunker.py |

### 文件操作沙箱

```
操作范围：C:\tmp\_local-ai\files\{session_id}\
允许操作：读取、创建、搜索
禁止操作：删除、移动、重命名、执行
路径校验：realpath 必须在沙箱目录内
```
