# v0.8.2 变更记录

> 2026-05-17 — Agent 框架：agent.py 引入 + 场景路由 + 任务分类增强

---

## 一、Agent 框架

### `agent.py`（新增）

统一 Agent 循环，核心能力：

| 能力 | 实现 |
|------|------|
| Agent 循环 | 思考 -> 工具调用 -> 观察 -> 下一轮 |
| 工具路由 | 根据任务自动选择工具执行 |
| 长文本路由 | `_execute_long_reader()` 自动检测长文本 -> 分段处理 |
| scratchpad 管理 | `_trim_scratchpad()` 限制上下文消息数 |
| 压缩触发 | `_maybe_compress()` 达到阈值时压缩历史 |

### 场景路由

用户可手动选择场景模式，影响 Prompt 构建和工具选择：

| 场景 | 功能 | 工具权限 |
|------|------|----------|
| chat | 通用对话 | 基础 |
| doc | 文档处理 | 文件读取 + 长文本分段 |
| code | 代码辅助 | code-runner 执行 |

## 二、任务分类增强

### `task_classifier.py` 升级

| 版本 | 改动 |
|------|------|
| v7 -> v8 | 四类任务分类：reasoning / code / text / agent |
| v8 -> v9 | 新增 `get_classify_signals()` 提取子信号：is_math / is_writing / is_logic / is_summary |

### Prompt 双引擎体系

```
第一层：场景模式（用户手动选）
  对话 / 文档 / 代码
  |
第二层：task_classifier（代码自动判断）
  text / reasoning / code / agent
  |
各类型对应不同的 think_instruction
```
