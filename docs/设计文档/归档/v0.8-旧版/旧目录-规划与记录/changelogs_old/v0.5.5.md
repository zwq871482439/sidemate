# v0.5.5 - 三层记忆架构 + 模型自适应 + 基准测试升级

> 日期: 2026-04-30

## 架构总览：三层记忆

```
Layer 1: 近期对话（原始，短窗口）
         ↓ 对话超过阈值时压缩
Layer 2: Session 缓存（每个会话的压缩摘要，存 session JSON）
         ↓ 积累到一定量时蒸馏
Layer 3: Notebook 小册子（跨会话永久记忆，注入 system prompt）
```

## 核心变更

### 1. 三层记忆架构（核心）

**Session 缓存（Layer 2）**
- Session JSON 格式从纯数组 `[{...}]` 升级为 `{"messages": [...], "context_cache": "...", "version": 2}`
- 对话轮数超过 profile 阈值（如 8B=8轮）时，自动压缩旧轮到 `context_cache`
- 压缩策略：保留最近 N 轮原始消息，其余按轮生成摘要（用户:xxx | 助手:xxx）
- Cache 总长度限制 500 字符，超长时保留最新部分
- `_load_chat()` 向后兼容：自动识别 v1（纯数组）和 v2 格式
- `_list_chats()` 显示缓存状态：`session名 (N条) [有缓存]`

**蒸馏到小册子（Layer 3）**
- 压缩时同时触发 `_distill_to_notebook()`
- 从旧消息中提取用户名/城市/职业/偏好 → 写入 notebook
- 从 cache 文本中提取技术偏好（"我喜欢用XX"、"XX比较好"）
- 所有蒸馏操作失败不影响主流程

**注入到模型**
- `_build_prompt()` 新增 `context_cache` 参数
- Cache 以 `[本会话较早的对话摘要]` 形式注入 system prompt
- 流式/非流式 API 都读取并传入当前 session 的 cache

### 2. 模型大小自适应参数系统
- 新增 `_MODEL_PROFILES` 配置表，5 个档位（0.5B / 1.5B / 4B / 8B / 14B）
- 每个档位独立配置：历史上下文上限、max_tokens、停顿检测阈值、温度、top_p、repetition_penalty、最大轮数
- **替换所有硬编码常量**，换模型自动适配

| 参数 | 0.5B | 1.5B | 4B | 8B | 14B |
|------|------|------|-----|-----|------|
| 历史上限 | 2500字 | 3500字 | 5000字 | 6000字 | 8000字 |
| max_tokens | 1024 | 1536 | 2048 | 4096 | 4096 |
| 停顿阈值 | 2.5字/s | 3.0字/s | 3.5字/s | 4.0字/s | 5.0字/s |
| 最大轮数 | 4 | 5 | 6 | 6 | 8 |
| temperature | 0.5 | 0.55 | 0.6 | 0.6 | 0.7 |

### 3. 轻量上下文压缩器（新增 `context_compressor.py`）
- **纯规则压缩，不调用 LLM**（适合本地小模型）
- 三级压缩策略：自然语言/代码块/极简摘要
- 保护最新 2 轮对话不被压缩
- 压缩失败自动回退到截断

### 4. 基准测试 v2.0（`benchmark.py` 重写）
- 8 个标准测试用例 + 多轮上下文测试 + 自动评分（0-10分）
- JSON 结果保存到 `benchmark_results/`
- `--quick` / `--json` / `--compare` 参数

### 5. API 增强
- `/api/models` 新增 `profile` 字段：暴露当前模型运行参数
- `/api/chat` 和 `/api/chat/stream` 新增 `context_cache` 支持
- `_clean_history_for_model` 的 `max_rounds` 改为从 profile 动态获取

## 技术决策
- **为什么三层记忆？** 完全模拟人类记忆：短期（对话窗口）→ 中期（session摘要）→ 长期（小册子知识库）
- **为什么 session cache 不用 LLM 压缩？** 本地小模型自己摘要自己效果差 + 浪费算力，规则压缩零开销
- **为什么 cache 限制 500 字？** 太长会挤占 system prompt 空间（小册子 1700 字 + cache 500 字 + 规则 ≈ 2500 字总量可控）
- **蒸馏时机：** 不是每轮都蒸馏，只在压缩触发时（省性能）
