## 二、设置 Tab 重布局（Patch 8B 设计）

### 三区块结构

```
📊 资源调度中心 — 系统内存总览 + 内存预算
🧠 模型管理 — 模型选择/加载/算力设备/Reranker/导入模型
⚙️ 高级设置（折叠） — 云端 API / 环境信息 / 训练记录
```

### 统一数据源

- 新增 `GET /api/resource-info` 端点，合并原 `/api/kb/memory-info` 和 `/api/kb/stats` 的数据
- 新增 `POST /api/budget` 端点，支持用户通过滑块调整内存预算（8G~12G）
- 前端 `refreshResourcePanel()` 改为单 API 调用

## 三、内存预算逻辑修正

### 根本问题

旧 `MemoryManager` 用进程总 RSS 与固定 8G 预算比较，导致预算检查永远失败，KB 加载不可用。

### 修正方案

| 变更 | 说明 |
|------|------|
| `modules_used_mb` | 改为所有已注册模块占用之和（非进程 RSS） |
| `can_allocate()` | 基于 `(modules_used + estimated) <= budget * 0.9` |
| `register()` | 新增 `category` 参数，区分 llm/kb/other |
| `recommended_budget()` | 基于系统物理内存动态建议 |
| LLM 注册 | `models.py` 加载/卸载 LLM 时 register/unregister memory_manager |

## 四、会话锁修正

- `kbLockOverlay` 从 `position:fixed` 改为 `position:absolute`，仅覆盖对话区内部
- KB 处理中不再阻挡 Tab 导航切换
