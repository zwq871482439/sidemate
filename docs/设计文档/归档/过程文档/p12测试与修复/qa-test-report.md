### 5. 文库问答 ⚠️ 阻塞

**操作**: 在输入框输入"请介绍一下已上传的文档内容"，点击提问按钮  
**预期**: 模型生成回答，显示流式响应  
**实际**: 模型持续显示"加载中..."，问答功能不可用  
**截图**: `qa-04-answer.png`

**问题分析**:
- 页面顶部提示："文库模型未加载，请点击右侧按钮加载"
- 点击"加载模型"按钮后，显示"加载中..."并持续较长时间（>2分钟）
- 模型加载未完成，导致问答功能无法使用
- 输入框可正常输入文本
- 提问按钮存在但可能因模型未加载而未响应

**阻塞原因**:
- 文库模型（嵌入模型 + Reranker）需要首次加载
- 根据界面提示，加载约需10-30秒，但实际测试中持续加载中
- 可能原因：模型文件较大、系统资源限制、或需要后台服务支持

## 发现的问题

### 问题1: 文库模型加载超时/阻塞

**严重程度**: 高  
**影响范围**: 步骤5、6、7  
**描述**: 点击"加载模型"后，模型持续显示"加载中..."状态超过2分钟，导致问答功能无法使用  
**可能原因**:
1. 模型文件较大，加载需要更长时间
2. 系统内存不足（当前可用8.5GB，预算4.8GB/10GB）
3. 后台服务（Ollama）可能需要额外配置
4. 首次加载需要下载或初始化嵌入模型

**建议**:
1. 增加模型加载进度指示（百分比或详细状态）
2. 添加加载超时提示和重试机制
3. 在文档中说明首次加载所需时间和资源要求

### 问题2: 文档列表中部分文档信息截断

**严重程度**: 低  
**描述**: 文档名称较长时显示省略号，无法查看完整名称  
**建议**: 添加鼠标悬停提示显示完整文档名

### 问题3: "新聊天"按钮未清空输入框

**严重程度**: 低  
**描述**: 点击"新聊天"后，输入框中之前的文本仍然存在  
**可能原因**: 模型未加载时，新聊天功能未完全激活
