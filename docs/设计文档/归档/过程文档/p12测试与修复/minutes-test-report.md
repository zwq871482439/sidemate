## 问题汇总

### 需修复

1. **录音列表缺少会话名** — 列表项仅显示日期 `2026-06-04 20:50`，应增加录音会话名称/标题
2. **录音列表缺少时长** — 列表项未显示录音时长，但弹窗内有时长信息（01:17）

### 观察/建议

3. **播放器未深度测试** — 因页面路由频繁切换，未能完整验证播放/暂停/进度条移动，建议在稳定环境下补充测试
4. **导出按钮位置** — "存为TXT"和"入库"仅在弹窗内，列表页无快捷导出入口
5. **全部接受按钮** — "全部接受"在对比原文模式下出现，符合设计预期
