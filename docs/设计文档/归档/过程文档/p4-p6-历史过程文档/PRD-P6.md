## 二、产品定义

### 2.1 产品目标

1. **消除模式混乱**：用户只需在 Chat Tab 一个地方切换离线/在线/并行，不再需要在 Chat 和 KB Tab 之间跳转实现"本地安全+云端补充"。
2. **前端 UI 统一**：建立一致的视觉语言（品牌色 #1E3A5F、SVG 图标、Token 条融合输入框），消除骨架屏、emoji 图标、CSS 重复定义等 P5 遗留问题。
3. **知识库职责单一化**：知识库 Tab 只做档案管理（上传/删除/打标/检索诊断），原有问答功能全量迁移到 Chat Tab 的离线/并行模式。

### 2.2 用户故事

| # | 用户故事 | 优先级 |
|---|---------|--------|
| US1 | As a **普通用户**, I want 在 Chat 页面用三段按钮一键切换离线/在线/并行模式，so that 我不需要在不同 Tab 之间跳转就能选择合适的工作模式。 | P0 |
| US2 | As a **知识库用户**, I want 在知识库 Tab 中通过标签树筛选和卡片网格浏览文档，so that 我能快速管理和定位档案，不被对话功能干扰。 | P0 |
| US3 | As a **并行模式用户**, I want 看到 AgentTimeline 展示检索→生成→融合的完整过程，so that 我能理解 AI 的工作流程并建立信任。 | P0 |
| US4 | As a **注重隐私的用户**, I want 切换模式时看到功能说明和风险告知弹窗，so that 我能清楚知道数据是否会离开本机。 | P1 |
| US5 | As a **高级用户**, I want 在设置页通过左侧竖排 Tab 快速导航不同配置区，so that 我不需要在单页中反复滚动。 | P1 |

### 3.3 模式切换弹窗设计

切换任一模式时弹出 Modal，含三部分：
1. **模式功能说明**：2-4 条特性列表（绿色对勾图标）
2. **限制说明**：如有配置依赖，红色叉号图标标注
3. **风险告知**（仅并行模式）：红色警告框「并行模式下，你的问题会同时发给云端 AI。但知识库文档、本地检索结果、本地 AI 生成的答案都不会离开本机。云端只能看到你的原始提问。」

## 五、待确认问题

1. **并行模式 actions**：当前并行模式无 actions 分类（自动融合），未来是否需要支持用户指定"并行+查知识库"等组合？
2. **设置页「云端 AI」Tab**：API 配置是否需要在切换在线/并行模式时做可用性校验？（当前用户可能在未配置 API 时切换到在线模式）
3. **知识库 Tag 父子层级算法**：PATCH6-BRAINSTORM 推荐方案 D（前缀匹配 + Embedding 细筛），是否需要在 P6 内完成 `tag_parent` 字段新增和自动归并？
4. **依赖清理回归范围**：13 个 pip 包移除后，是否需要对全量功能做回归测试，还是仅针对核心流程？
5. **Live Trace 回放存储方案**：AgentTimeline 步骤数据持久化采用本地 SQLite 还是 JSON 文件？
6. **render_html 的安全边界**：云端生成的 HTML 是否需要服务端预清洗（去除 script/外部资源），还是仅依赖 CSP？
