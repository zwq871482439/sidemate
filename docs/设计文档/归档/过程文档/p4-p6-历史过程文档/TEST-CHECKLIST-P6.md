## 一、聊天核心

### 1.1 基础对话
- [x] 新建对话 → 发送"你好" → **验收**:几秒内出现 AI 回复,带"聊天"tag 和时间戳
- [x] 多轮对话:基于上一条回复继续追问 → **验收**:AI 能理解上下文(比如先问"北京",再问"它的天气呢")
- [x] **思考过程**:发一条需要推理的问题(如数学题) → **验收**:若模型支持思考,先显示"思考中"再显示"回答中",计时器从 0 开始正常递增,回答结束后**计时器消失**

### 1.2 🔴 手动终止响应(本轮重点修复)
> **这是本轮最关键的测试,涉及多次修复,请严格按步骤验证**

- [x] 发送一条慢消息(如"写一篇 800 字的散文") → 等正文开始输出 → **点终止按钮** → **验收**:
  - ① 计时器**立即停止**(不再跳动)
  - ② 页面**只剩一张卡片**(没有重复卡片)
  - ③ 卡片底部出现**终止提示**("用户已手动终止响应",带停止图标)
  - ④ 卡片有"聊天"**tag**
  - ⑤ 速度显示**正常**(不是"0字/s")
- [x] **重渲染验证**:终止后,切到别的会话再切回来 → **验收**:终止提示、tag、速度**仍然存在**(不丢失)
- [x] **终止后继续对话**:终止一条消息后,立即发送新消息 → **验收**:新消息正常发送和回复,无残留状态干扰
- [x] **快速终止**:发消息后立即点终止(不等任何输出) → **验收**:显示"[用户已手动终止响应]"提示,不报错
- [x] **连续终止**:连续两次发送消息并各终止一次 → **验收**:两次都正常,无计时器泄漏(观察一段时间,没有"幽灵计时器"在跳)

### 1.3 🔴 联网搜索(本轮 curl_cffi 激活)
- [x] 切到"在线"模式 → 点"联网搜索"按钮 → 输入"最新的 AI 新闻" → **验收**:
  - ① 启动日志/控制台出现 `[SEARCH] 使用 curl_cffi`(不是"不可用")
  - ② 搜索结果被引用,回答里带来源
  - ③ 若 curl_cffi 不可用时,fallback 到 httpx 也能正常搜索(不报错)
- [x] **验证 TLS 伪装生效**:搜索一个通常会拦截爬虫的网站内容 → **验收**:能正常抓取(对比修复前可能被拦)

### 1.4 文档生成
- [ ] 点"写文档"按钮 → 输入"写一份项目周报模板" → **验收**:
  - ① 先出现确认提纲的界面
  - ② 确认后生成完整文档
  - ③ 完成后出现下载按钮,点击能下载 .docx 文件
- [ ] **终止文档生成**:在生成过程中点终止 → **验收**:正常终止,不报错,已生成部分保留
