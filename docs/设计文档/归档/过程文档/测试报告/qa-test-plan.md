## 一、💬 对话模块

## 四、📄 文档生成（Doc Action）

### 4.1 Phase 1: 提纲生成
- [ ] 切换到"文档"标签页
- [ ] 输入"请帮我写一份项目计划书"
- [ ] 确认模型先输出提纲（带 `#` 和 `##` 标题）
- [ ] **提纲完成后不应自动推进**（不应有倒计时）
- [ ] 应出现"✅ 确认生成"和"取消"按钮

### 4.2 Phase 2: 完整文档
- [ ] 点击"✅ 确认生成"
- [ ] 确认开始生成完整文档
- [ ] 生成完成后，chat 消息内出现下载按钮（"📄 下载文档"）
- [ ] Toast 提示"文档生成完成"（不是"点击下载"）

### 4.3 下载持久化
- [ ] 下载按钮出现后，切换到其他标签页再切回来 → 按钮仍在
- [ ] 新建对话后查看旧对话 → 下载按钮仍在
- [ ] 点击下载按钮 → 确认 .docx 文件下载成功
- [ ] 打开 .docx 确认内容完整

### 4.4 取消流程
- [ ] 再次生成文档 → 提纲阶段点"取消"
- [ ] Toast 显示"已取消文档生成"
- [ ] 不会继续生成
