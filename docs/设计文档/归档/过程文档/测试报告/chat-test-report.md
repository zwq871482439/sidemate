### 建议

1. **P0 - Markdown渲染**：用户消息和AI消息内容应进行 Markdown 到 HTML 的转换，支持标题、列表（ol/ul）、代码块（pre/code）、加粗/斜体等基础语法
2. **P1 - 复制按钮**：`copyMsgContent(this)` 函数内应更新按钮 `title` 属性为"已复制"，并可添加 `data-copied` 属性或CSS类以提供视觉反馈
3. **P2 - Stats标签**：将 stats 容器中的 `<code>` 标签替换为 `<span>` 或者 `<small>`，去除代码语义
4. **暗色模式优化**：建议为用户消息和AI消息在暗色模式下使用不同的背景色区分（例如用户消息使用略亮的深色）
5. **模型回复质量**：测试中 qwen3.5-4b 模型返回内容过短（如仅"1""无法"），建议检查模型配置或考虑使用更大参数模型
