# 桌伴 · Sidemate 0.9 patch1 — 前端 UX 审计报告

> 审计日期：2026-06-02 | 审计范围：index.html、main.css、chat.js、minutes.js、qa.js、settings.js

## 一、元素问题

### 1.1 CSS 属性值拼写错误 — 背景色解析失败 🔴

**chat.js L855**: `background:var(--bg-primary)beb;` — `beb` 后缀导致 CSS 解析失败  
**chat.js L880**: `background:var(--bg-primary)3cd;` — `3cd` 后缀导致 CSS 解析失败

### 1.2 JS 引用不存在的 DOM 元素（4 处死代码）🔴

| 文件 | 行号 | 引用 ID | 说明 |
|------|------|---------|------|
| minutes.js | 94 | `whisperModelLabel` | 设置模型名称，元素已不存在 |
| minutes.js | 95 | `whisperMemLabel` | 设置内存占用，元素已不存在 |
| minutes.js | 251 | `llmEnhanceLabel` | LLM 状态提示，元素已不存在 |
| qa.js | 665 | `kbUninstallBtn` | 卸载按钮操作，元素已不存在 |

### 1.3 幽灵按钮 — `playBtn_` 系列永不渲染

`minutes.js` L1156 的 `playAudio()` 操作 `playBtn_` 按钮，但 `loadMinutesHistory()` 渲染的历史卡片中从未生成此按钮。整个函数为死代码。

### 1.4 孤立 DOM 节点

- `index.html` L360: `#whisperBottomLabel` — 无任何 JS 写入，一直为空
- `index.html` L611: `#envTable` — 写入内容但 `display:none`，与 `#envTable-sys` 内容重复
- `index.html` L365: `#transcriptModal` — 同一 style 属性中 `display:none` 出现两次

### 1.5 CSS 注释残留

`main.css` L235, L298: 已移除功能（imgPreview、OCR）的注释仍存在。

## 二、描述/标签问题

### 2.1 脆弱的 onclick 选择器（3 处）🔴

`index.html` L77, L87, L174: 使用 `document.querySelector('[onclick*=settings]')` 来跳转设置页。如果设置按钮的 onclick 属性被重构，三个按钮全部失效。应改为直接调用 `switchTab('settings')`。

### 2.2 "前往模型管理" 标签不匹配

`index.html` L87: 按钮文字「前往模型管理」实际跳转到完整设置页（包含系统状态、资源、扩展、缓存等内容），应改为「前往设置」。

### 2.3 "请联系管理员" 提示不通用

`index.html` L158: 文库安装提示假设企业部署场景。个人用户/开源场景下会困惑。

## 三、功能重复

### 3.1 文库问答双入口独立实现 🔴

对话 Tab 的「文库问答」Action（chat.js）和文库 Tab 的问答输入框（qa.js）调用同一后端 API，但各自维护独立的对话历史和渲染逻辑。用户在一处提问后切换 Tab 看不到之前的问答记录。

### 3.2 不必要包装函数

`minutes.js` L188: `handleWhisperUnload() { unloadWhisper(); }` — 纯转发，无附加逻辑。

## 四、不完整问题

### 4.1 跨模块变量冲突 🔴

`_kbBusyLastState` 在 chat.js 中声明（L578），但 qa.js 直接修改（L650, L680）。由于 JS 加载顺序，qa.js 修改的是全局新变量而非 chat.js 闭包内的原变量。

### 4.2 启动无 loading 指示

`init()` 调用时无 `showLoading()`，后端响应慢时用户看到白屏。

### 4.3 Action 栏空状态

Action 栏（`#actionBar`）无 action 时显示为一条空白边框线，浪费空间且视觉不协调。

### 4.4 `loadWhisper` 注释与代码不一致

`minutes.js` L1320 注释说 `loadWhisper` 已移除，但 `reloadWhisper()` 仍存在且功能完整。

## 五、UX 体验问题

### 5.1 transcriptModal 缺 Escape/遮罩关闭 🔴

`#transcriptModal` 只能通过 X 按钮关闭，不支持 Escape 键或点击遮罩区域关闭。

### 5.2 KB Lock Overlay 硬编码偏移 🔴

`main.css` L347: `.kb-lock-overlay { top:48px; }` — 工具栏高度变化会导致遮罩错位。

### 5.3 Send/Stop 按钮切换布局抖动

两个按钮通过 `display` 切换，文字和 padding 不同导致 input 栏左右抖动。

### 5.4 图标体系不统一

SVG 图标与 Emoji 混用：Tab 导航用 SVG，KB 文档状态用 Emoji（✅❌📝），纪要历史用 SVG，思考过程用 Emoji（💭✍️）。同一应用内视觉密度不一致。

### 5.5 KB 用户消息视觉区分不足

`qa.js` L394-396: KB 问答中用户消息和 AI 消息都使用 `var(--bg-secondary)` 背景，仅靠 `text-align` 区分。

### 5.6 KB 左侧面板自动折叠无提示

首次加载文档列表后 300ms 自动折叠，无动画或提示。

### 5.7 无响应式设计

`body { overflow:hidden }` 无小窗口适配，设置页虽有 `@media(max-width:600px)` 但 Tab 导航、对话区等无响应式处理。

### 5.8 实时转写气泡清空逻辑不稳健

`minutes.js` L337-344: 清空容器时 `emptyEl` 元素检查逻辑在极端情况下可能遗漏旧气泡。
