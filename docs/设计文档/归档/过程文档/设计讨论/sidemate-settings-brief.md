# 桌伴 Sidemate — 设置页（Settings Page）需求摘要

> 文档类型：需求发现文档 | 版本：v1.0 | 日期：2026-06-05
> 产出角色：许明需（需求发现分析师）

---

## 一、设计目标陈述

为「桌伴·Sidemate」（v0.9）设计一个**桌面客户端设置页**，目标是让个人用户和小型团队能够高效地配置本地 AI 会议录音助手的各项参数。

### 核心设计目标

| 目标 | 说明 |
|------|------|
| **清晰可扫** | 用户 30 秒内定位目标设置项，无需阅读说明书 |
| **节制专业** | 不炫技、不花哨，体现本地 AI 工具的技术自信 |
| **安全可信** | 本地优先的产品哲学需要在设置页中被感知——数据存在哪、API 指向哪，一目了然 |
| **即改即生效** | 设置变更实时生效或仅需一次「应用」确认，不需要重启 |
| **可扩展** | 预留未来功能（GPU 加速开关、多会议模板、插件管理等）的入口 |

## 二、五维度需求分析

### 维度 1 — 场景（Surface）

| 属性 | 结论 |
|------|------|
| **形态** | 桌面客户端设置面板（Desktop App Settings Panel） |
| **平台** | Windows / macOS 原生桌面应用（Electron 或类似框架） |
| **呈现方式** | 侧边栏导航 + 右侧内容区（二级面板布局） |
| **交互模式** | 点击切换分类，内容区滚动浏览 |
| **特殊要求** | 深色主题为默认/唯一模式；需要文件路径选择器等原生控件 |

**布局推断**：左侧 200–240px 导航栏（图标 + 文字），右侧内容区自适应。典型桌面设置页比例约 1:3。

### 维度 2 — 受众（Audience）

#### 主要用户画像

**画像 A：知识工作者（核心用户）**
- 每天参加 2–5 场会议的产品经理、研究员、记者、咨询顾问
- 需要可靠的会议转写和纪要，但不想操心技术细节
- 技术素养：中等——能理解「模型」「API 地址」等概念，但不具备开发能力
- 期望：「装好就能用」，设置项有合理默认值，只需少量调整

**画像 B：技术型早期用户（次要用户）**
- 已在本地部署 Ollama 的开发者或技术爱好者
- 会主动切换模型、调整 VAD 灵敏度等高级参数
- 技术素养：高——熟悉命令行、本地模型部署
- 期望：参数暴露充分，不隐藏高级选项

**画像 C：小型团队负责人**
- 管理 3–10 人团队，统一配置公司内部的 Ollama 服务地址
- 关注点在稳定性和路径管理（共享存储路径）
- 技术素养：中高

#### 共同特征
- 日常工作语言以中文为主，需支持中英双语界面
- 对「AI 工具」有一定审美预期——参考 Notion AI、Raycast、Linear 等产品
- 隐私敏感：选择本地产品本身就说明对数据主权的重视

### 维度 3 — 调性（Tone）

**主导学派：Tech Utility（技术工具感）**
**辅助学派：Modern Minimal（现代极简）**

| 要素 | 方向 |
|------|------|
| **色彩** | 深色底（#0D0D0D–#1A1A1A）+ 低饱和中性灰 + 单一强调色（蓝绿 or 靛蓝） |
| **字体** | 系统原生无衬线（SF Pro / Segoe UI / Inter），等宽字体用于技术参数（API 地址、路径） |
| **图标** | 线性图标（1.5px 描边），统一风格，不填色 |
| **间距** | 宽松留白，8px 栅格系统，信息密度低于 VS Code 但高于 Notion |
| **动效** | 极简过渡（150ms ease-out），无弹性动画，无装饰性动效 |
| **语言** | 中文为主，技术术语保留英文（如「VAD 灵敏度」「Ollama API 端点」） |
| **「不可为」** | ❌ 彩色渐变背景、❌ 圆角过大（>8px）、❌ 装饰性插画、❌ emoji 图标、❌ 过多营销语言 |

**情绪板关键词**：精准 · 安静 · 可信 · 工具感 · 不打扰

### 维度 4 — 品牌上下文（Brand Context）

| 属性 | 状态 |
|------|------|
| **品牌名称** | 桌伴 / Sidemate |
| **品牌阶段** | v0.9，早期产品，尚无正式品牌手册 |
| **品牌定位** | 本地 AI 桌面工具，核心理念「你的会议伙伴，数据不离开你的电脑」 |
| **现有视觉线索** | 深色主题为主；强调本地优先、隐私安全 |
| **品牌人格** | 可靠、安静、技术扎实，不张扬 |

**品牌提取建议**：
- 从产品名称「桌伴」中提取「陪伴」感——设置页不应该是冰冷的控制面板，而是一个「帮你调好工具」的助手
- 品牌色可考虑低饱和蓝绿（#4ECDC4 方向），暗示 AI 又不过分科技冷感
- 暂无品牌手册约束 → 设计自由度大，但需自建一致性

**推荐设计系统参考**：
- **Radix UI Colors（dark scale）**：深色主题的基础色板
- **VS Code Dark+**：桌面工具感深色主题的标杆
- **Linear Dark Mode**：现代工具产品的简洁美学

### 维度 5 — 规模（Scale）

| 属性 | 结论 |
|------|------|
| **页面数量** | 1 个设置页面（单页），5 个分类 section |
| **内容深度** | 约 30–40 个可配置项 |
| **导航层级** | 2 级——分类（一级导航）→ 设置项（内容区直接展示，不折叠） |
| **响应式** | 不需要（固定窗口尺寸，建议 800×600 最小尺寸） |
| **交互复杂度** | 中等——含开关、下拉、输入框、路径选择器、按钮、状态提示 |
| **特殊状态** | 连接测试中、模型加载中、路径无效警告、未保存变更提示 |

## 三、功能模块清单与层级

### 信息架构

```
设置页（Settings）
├── 01 通用设置（General）
│   ├── 界面语言（下拉：简体中文 / English）
│   ├── 开机自启动（开关）
│   ├── 通知偏好（多选：会议结束提醒 / 转写完成提醒 / 纪要生成提醒）
│   └── 最小化到系统托盘（开关）
│
├── 02 语音转写（Speech-to-Text）
│   ├── STT 引擎（下拉/单选：faster-whisper small / medium / large-v3）
│   ├── 转写语言（下拉：中文 / 英文 / 日文 / 自动检测）
│   ├── VAD 灵敏度（滑块：1–10，默认 5）
│   ├── 实时转写显示（开关）
│   └── 模型下载管理（入口按钮 → 下载面板）
│
├── 03 AI 增强（LLM / AI）
│   ├── Ollama API 地址（输入框 + 连接测试按钮）
│   ├── 摘要模型（下拉：qwen3.5:4b / qwen3.5:8b / 自定义）
│   ├── 纠错润色（开关）
│   ├── 自动生成纪要（开关）
│   ├── 纪要模板（下拉：标准 / 详细 / 简洁 / 自定义）
│   └── 高级：GPU 加速（开关，灰色/不可用标记为 "即将推出"）
│
├── 04 录音（Recording）
│   ├── 音频输入设备（下拉：系统设备列表）
│   ├── 录音格式（下拉：WAV / MP3 / FLAC）
│   ├── 采样率（下拉：16kHz / 44.1kHz / 48kHz）
│   ├── 保存路径（输入框 + 浏览按钮）
│   └── 自动清理录音文件（下拉：从不 / 7天 / 30天 / 90天）
│
└── 05 关于（About）
    ├── 版本号（显示：v0.9.0）
    ├── 检查更新（按钮 + 状态）
    ├── 开源许可（链接 / 弹窗）
    ├── 用户指南（链接）
    └── 隐私声明（链接）
```

### 功能优先级

| 优先级 | 模块 | 理由 |
|--------|------|------|
| **P0** | 通用设置 | 基础体验，必须 |
| **P0** | 语音转写 | 核心功能配置，必须 |
| **P0** | AI 增强 | 核心功能配置，必须 |
| **P0** | 录音 | 核心功能配置，必须 |
| **P1** | 关于 | 版本信息和合规，v1.0 前需完成 |
| **P2** | 模型下载管理 | 增强体验，可延后 |
| **P2** | GPU 加速 | 性能优化，v1.x |
| **P3** | 纪要模板自定义编辑器 | 高级功能 |

## 四、设计参考与灵感方向

### 直接参考

| 产品 | 参考价值 | 参考点 |
|------|----------|--------|
| **Raycast Settings** | ⭐⭐⭐⭐⭐ | 深色主题 + 侧边栏导航的黄金标准；搜索框置顶；分类图标清晰；信息密度精准 |
| **VS Code Settings** | ⭐⭐⭐⭐ | 桌面应用设置页标杆；分类 + 搜索 + 分组折叠；JSON 编辑器思路可迁移到「高级配置」 |
| **Linear Settings** | ⭐⭐⭐⭐ | 极简深色美学；侧边栏 hover 态精致；开关组件设计优秀 |
| **Obsidian Settings** | ⭐⭐⭐ | 插件式设置扩展思路；大量开关/下拉组合的排版参考 |
| **Figma Desktop Settings** | ⭐⭐⭐ | 桌面应用设置页的字体/间距尺度参考 |

### 关键设计模式参考

1. **Sidebar Navigation** — Slender left rail with icon + label, active state indicated by a subtle accent bar (2px left border) or background highlight
2. **Settings Group Card** — Each logical group wrapped in a subtle card (1px border, 4px radius) with a section title
3. **Inline Validation** — Path validation, connection test results shown inline near the relevant control, not as a global toast
4. **Search-First** — Consider a search bar at the top of the sidebar to filter settings by keyword (Raycast pattern)
5. **Dirty State** — If a setting is modified but not yet applied, show a subtle indicator (dot / accent border) + a floating "Apply" bar at the bottom

## 五、交互与状态设计要点

### 组件清单

| 组件类型 | 用途 | 数量（估） |
|----------|------|------------|
| Toggle Switch | 布尔型设置 | ~8 |
| Select Dropdown | 枚举型设置 | ~10 |
| Text Input | 路径、地址 | ~3 |
| Slider | 连续值（VAD 灵敏度） | 1 |
| Button | 操作触发（测试连接、浏览、检查更新） | ~5 |
| Status Indicator | 连接状态、版本状态 | ~3 |
| Checkbox Group | 多选设置（通知偏好） | 1 |
| Tooltip / Help Text | 辅助说明 | 若干 |

### 关键状态覆盖

| 状态类别 | 具体状态 |
|----------|----------|
| **连接测试** | 检测中（loading spinner）、成功（绿色 ✓）、失败（红色 ✗ + 原因）、未测试（灰色 —） |
| **模型状态** | 已安装（版本号）、未安装（下载按钮）、下载中（进度条） |
| **路径验证** | 有效（静默）、无效（红色边框 + 提示文字）、路径不存在（警告图标） |
| **未保存变更** | 修改后未应用（分类标签旁出现 ⬤）、应用按钮亮起 |
| **加载中** | 设置页首次加载 skeleton screen、模型列表加载中 spinner |
| **错误** | API 不可达、权限不足、磁盘空间不足 |
| **空状态** | 无音频设备时提示、无已安装模型时提示 |

## 六、约束条件与风险

| 类别 | 内容 |
|------|------|
| **技术约束** | Electron 框架内需使用原生文件对话框（非自定义）；Ollama API 检测可能受防火墙影响 |
| **性能约束** | 设置页加载时不应阻塞主窗口；模型列表需异步获取 |
| **版本约束** | v0.9 意味着设计需考虑 v1.0 改动幅度可控——不要过度设计 |
| **本地化** | 至少支持中英双语，UI 文案长度需预留 30% 扩展空间（英→德/法等） |
| **可访问性** | 键盘导航（Tab 顺序）、屏幕阅读器支持（ARIA 标签）为 v1.0 加分项 |
| **风险** | 用户对「本地 AI」设置复杂度的预期不一致——高级用户要全部暴露，普通用户要简单 |

## 七、需求总结矩阵

| 维度 | 结论 |
|------|------|
| **场景** | 桌面客户端设置面板，侧边栏 + 内容区布局，深色主题 |
| **受众** | 知识工作者为主（中等技术素养），兼顾技术型早期用户和小团队负责人 |
| **调性** | Tech Utility × Modern Minimal，精准安静可信的工具感 |
| **品牌** | 桌伴 Sidemate v0.9，本地优先 AI 工具，尚无品牌手册 |
| **规模** | 单页 5 模块 ~35 配置项，固定窗口，无响应式需求 |

### 推荐方向

- **设计系统**：自建轻量设计系统，参考 Radix UI Colors (dark) + VS Code Dark+ 色板
- **导航模式**：左侧图标+文字侧边栏，5 个固定分类
- **布局原型**：参考 Raycast Settings / VS Code Settings 的信息架构
- **特别注意**：
  1. 侧边栏建议加上搜索框（即使 v0.9 不实现也预留位置）
  2. 底部状态栏统一展示连接状态和「恢复默认」入口
  3. AI/LLM 设置区的连接测试是用户高频操作，交互需流畅醒目
  4. 所有路径选择器使用系统原生对话框，不自定义
