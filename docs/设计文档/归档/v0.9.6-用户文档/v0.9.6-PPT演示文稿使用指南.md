# PPT 演示文稿使用指南

> ✅ **本文档随 0.9.6 首发重发**（PPT 演示文稿是 0.9.6 重要新功能）。
>
> 版本：v0.9.6 | 适用人群：需要做演示/汇报/教学场景的用户

---

## 1. 什么是 PPT 演示文稿

PPT 演示文稿是 Sidemate 在 0.9.6 新增的产物格式：**单文件 HTML 演示文稿**，使用 reveal.js 引擎渲染。

**对比传统 PowerPoint**：

| 维度 | PowerPoint | Sidemate PPT（HTML） |
|------|-----------|------------------|
| 文件大小 | 几 MB ~ 几十 MB | **~3.5 MB**（含 reveal.js + mermaid） |
| 打开方式 | PowerPoint/WPS | 任意浏览器 |
| 翻页 | 鼠标/键盘 | **方向键 / 空格 / 触屏滑动** |
| 全屏演示 | F5 | **F 键** |
| 导出 PDF | 另存为 PDF | URL 加 `?print-pdf` 后 Ctrl+P |
| 图表支持 | 静态图片 / SmartArt | **mermaid 流程图/时序图（动画渲染）** |
| 美观度 | 主题模板 | **深色专业商务风 + 大数字 + 渐变卡片** |

## 2. 怎么生成 PPT

### 2.1 对话里直接说

进入文档模式或 chat → Action=doc 模式，对话框输入：

> 「帮我做一个**PPT 演示文稿**：XXX 主题，5 页左右」

AI 会自动：
1. 调 `write_workspace` 写入 `.ppt.html` 文件（每个 `<section>` 一张幻灯片）
2. 调 `set_doc_status` 生成最终产物
3. 出现 **「下载 HTML 报告 xxxPPT.html」** 按钮

### 2.2 文件命名

文件名后缀必须是 `.ppt.html`（两个点）—— 系统据此识别走 PPT 渲染路径。

## 3. 怎么写 PPT 内容

### 3.1 基础结构

每个 `<section>` 是一张幻灯片：

```html
<section>
  <h1>主标题页</h1>
  <p>副标题</p>
</section>

<section>
  <h2>内容页标题</h2>
  <p>内容...</p>
</section>

<section>
  <h2>数据页</h2>
  <div class="stats">
    <div class="stat">
      <div class="stat-num">58%</div>
      <div class="stat-label">提升</div>
    </div>
  </div>
</section>
```

### 3.2 垂直嵌套（子页）

外层 `<section>` 包内层 `<section>` 做"点开看更多"的子页：

```html
<section>
  <h2>总览</h2>
  <section>
    <h3>详情 1</h3>
    <p>...</p>
  </section>
  <section>
    <h3>详情 2</h3>
    <p>...</p>
  </section>
</section>
```

按方向键下展开子页，按上收起。

---

## 4. 演示时怎么操作

打开 `.ppt.html` 后：

| 操作 | 按键 |
|------|------|
| 下一张 / 下一个子页 | `→` / `Space` |
| 上一张 / 上一个子页 | `←` |
| 全屏 / 退出全屏 | `F` |
| 演讲者视图（带备注） | `S` |
| 黑屏暂停 | `B` |
| 缩略图导航 | `Esc` |
| 触屏滑动 | 左右滑 |

---

## 5. 导出 PDF

1. 浏览器打开 PPT 文件
2. URL 后面加 `?print-pdf`（如 `file:///C:/path/to/file.ppt.html?print-pdf`）
3. `Ctrl + P` 打开打印
4. 目标选"另存为 PDF"
5. **关键**：边距选"无"，勾选"背景图形"—— 否则 PDF 缺背景

> **小技巧**：导出前先 `F` 进全屏模式，PDF 会更干净。

## 6. PPT 内容设计原则

### 6.1 标题页

```html
<section>
  <h1 style="font-size: 3.6rem">主标题</h1>
  <p style="color: #64ffda">副标题</p>
  <div style="margin-top: 40px; font-size: 0.9em; color: #888">2026年6月 · 张三</div>
</section>
```

### 6.2 数据页（关键指标）

```html
<section>
  <h2>关键指标</h2>
  <div class="stats">
    <div class="stat">
      <div class="stat-num pos">+58%</div>
      <div class="stat-label">增长率</div>
    </div>
    <div class="stat">
      <div class="stat-num accent">1.2M</div>
      <div class="stat-label">用户数</div>
    </div>
  </div>
</section>
```

数字用 `stat-num`，下面用 `stat-label` 解释。**单页不超过 4 个数字**——多会显得拥挤。

### 6.3 对比页（两栏对比）

```html
<section>
  <h2>方案对比</h2>
  <div class="grid-2">
    <div class="card">
      <div class="card-title">方案 A</div>
      <ul>
        <li>优点 1</li>
        <li>优点 2</li>
      </ul>
    </div>
    <div class="card">
      <div class="card-title">方案 B</div>
      <ul>
        <li>优点 1</li>
        <li>优点 2</li>
      </ul>
    </div>
  </div>
</section>
```

### 6.4 流程页（mermaid 图）

```html
<section>
  ```mermaid
  flowchart TD
    A[用户输入] --> B{是否合法}
    B -->|是| C[处理]
    B -->|否| D[报错]
  ```
</section>
```

mermaid 图在 PPT 里也能渲染，并随翻页触发。

### 6.5 表格页

普通 `<table>` 标签已被美化，直接写即可。

## 7. 美观度参考

**默认风格**：深色背景（#1a1a2e）+ 亮色文字 + 蓝色高亮（#64ffda）

**关键配色**：
- 数字（pos）: 绿色 `#10b981`（正面）
- 数字（neg）: 红色 `#ef4444`（负面）
- 数字（accent）: 橙色 `#f59e0b`（强调）
- 高亮色: `#64ffda`（CTA / 强调）

**字号建议**：
- 标题（h1）: 3.0 ~ 3.6 rem
- 副标题（h2）: 2.0 ~ 2.4 rem
- 正文: 1.0 ~ 1.2 rem
- 数据数字: 2.5 ~ 3.0 rem（用 `stat-num` class）

## 8. 常见问题

### 8.1 浏览器打开后是空白页

检查 `<script src="reveal.min.js">` 路径——PPT 是自包含的，reveal.js 应该已经内联，不依赖外网。

### 8.2 mermaid 图渲染失败

跟可视化报告一样，PPT 里的 mermaid 也会带源码的友好错误提示。

### 8.3 翻页乱跳

每个 `<section>` 不要嵌套太深（建议 ≤ 2 层），否则方向键行为会混乱。

### 8.4 字体太小

PPT 默认字号可能因窗口大小变化。在 `<section>` 上加 `style="font-size: 1.2em"` 整体放大。
