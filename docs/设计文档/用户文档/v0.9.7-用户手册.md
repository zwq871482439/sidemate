## 1. 产品简介

**桌伴 Sidemate** 是一款**本地优先**的 Windows 桌面 AI 助手。核心理念是：数据默认不出本机，云端能力按需连接。

### 技术底座

| 项目 | 说明 |
|------|------|
| 推理底座 | **llama.cpp**（通过 `llama-server.exe` 运行 GGUF 模型），支持 Vulkan GPU 加速，无 GPU 自动回退 CPU |
| 本地模型 | 通义千问 Qwen3.5 三档（0.8B / 2B / 4B），均为 Q4_K_M 量化，按需从 ModelScope 下载 |
| 知识库模型 | bge-m3（向量化，约 2.3GB）+ bge-reranker-v2-m3（重排序，约 2.2GB），合计约 4.5GB |
| 云端模型 | 用户自行配置 OpenAI 兼容 API（如 DeepSeek、GPT、Claude、通义千问等） |
| 开源协议 | 核心代码采用 Apache-2.0 开源协议 |

### 为什么选择桌伴

- **隐私可控**：默认离线运行，对话、文档、知识库数据 100% 存储在本机。
- **离线可用**：本地 LLM + 本地知识库，断网也能完成对话、文档生成、知识库问答。
- **云端按需**：需要更强模型时，可配置云端 API，仅在在线/并行模式下数据会发送到你所选的云服务商。
- **国产模型生态**：本地模型与知识库模型均从魔搭 ModelScope 下载，国内网络稳定无需代理。

## 2. 三种运行模式

聊天页底部输入框附近的三段式按钮切换 AI 运行模式。切换时会弹出确认对话框，说明功能变化与数据流向。

### 2.1 离线模式（默认）

- **引擎**：纯本地 LLM（llama-server 加载 Qwen3.5 GGUF）。
- **数据流**：所有 AI 计算在本地完成，**不发送任何数据到外部服务器**。
- **可用功能**：对话、写作、翻译、总结、知识库问答、文档生成（.docx）、本地工具（calculator/search_kb/read_workspace/write_workspace 等）。
- **不可用**：联网搜索（search_web）、读网页（fetch_url）——这些需要网络。
- **适用场景**：注重隐私、断网环境、处理敏感资料、无需最强模型能力。

### 2.2 在线模式

- **引擎**：云端 AI（你配置的 OpenAI 兼容 API）。
- **数据流**：对话内容会发送到你配置的云端 API；本地文件内容默认不发送（除非你主动引用知识库文档或粘贴）。
- **可用功能**：所有云端大模型的能力 + 联网搜索/读网页 + Agent 多轮工具调用。
- **适用场景**：需要更强推理/创作能力、联网搜索、处理非敏感内容。
- **前提**：已在「设置 → 云端 AI」填写 API 地址、Key、模型名称。

### 2.3 并行模式（本地 + 云端协作）

- **引擎**：本地 KB 检索 + 云端通用知识双线并行，本地模型实时融合两路信息。
- **数据流**：**本地知识库原文永不离开本机**；只把检索到的片段和问题发给云端。
- **适用场景**：既要云端模型的强能力，又要本地知识库的精准资料支持，取长补短。

> 详细对比与使用场景见 [v0.9.7-三模式使用指南](v0.9.7-三模式使用指南.md)。

## 3. 核心功能

### 3.1 对话（Chat）

最核心的功能，底部输入框与 AI 交流。

- **基础对话**：Enter 发送，Shift+Enter 换行；AI 流式生成，可随时点「停止」中断。
- **明盒渲染（ClearBox）**：左色条区分用户（蓝）和 AI（紫），折叠统计、工具调用时间线、知识库来源卡片，过程透明可见。刷新页面后工具链/推理步骤卡片不丢失。
- **多会话管理**：每个对话独立保存上下文，支持新建/切换/重命名/删除。
- **文件上传**：支持 txt/md/pdf/docx/xlsx/csv 等格式，作为对话上下文，输入框上方实时显示词元占用。
- **上下文指示器**：合并显示本轮 + 历史 + 总容量 + 剩余容量，接近上限变红提醒。

### 3.2 知识库问答

> 需要先在「设置 → 模型下载」安装知识库模型（bge-m3 + reranker）。

上传文档资料，AI 自动分块、向量化、打标聚类，并基于文档内容回答。

- **上传文档**：支持 txt/md/pdf/docx/xlsx/csv 等格式，可批量拖入；自动处理「分块 → 向量化 → 重排序」。
- **检索流程**：dense（语义）+ sparse（关键词）双路融合 → bge-reranker 精排 → 相关性阈值过滤（<0.05 的完全不相关结果不会返回）。
- **标签树 + 卡片网格**：左侧按 AI 聚类的分类分组筛选，右侧卡片显示文件名、标签、摘要、词元数、被搜索次数。
- **AI 洞察仪表盘**：环形图统计分类分布，AI 分析主题覆盖与补充方向，3 条建议追问一键跳转对话。
- **问答引擎可选**：知识库问答的 AI 引擎独立于全局模式，可在「设置 → 知识库 → 问答引擎」选择「本地 LLM（隐私优先）」或「云端 LLM（质量优先）」。
- **文档权限**：支持私密文档标记 + 三档访问权限（full/search-only/disabled）。
- **审计日志**：每次检索记录访问明细（时间/访问者/查询词/命中片段/相关性评分），每篇文档最多保留 200 条。

> 详细操作见 [v0.9.7-知识库使用指南](v0.9.7-知识库使用指南.md)。

### 3.3 文档生成（.docx）

让 AI 撰写格式化文档：

1. 发起文档请求（如「帮我写一份关于 XX 的报告」）。
2. AI 先生成**提纲（Markdown）**，可在编辑栏自由修改章节、切换预览。
3. 确认提纲后，AI 按你的修改生成完整文档。
4. 文档可下载为 `.docx` 文件。

> 刷新页面后提纲编辑栏会自动恢复，不会丢失。

### 3.4 可视化报告（HTML）

生成**自包含 HTML 单文件**（内联 marked.js + mermaid.js），浏览器打开即可看完整图文排版与可缩放拖拽图表。

- 示例：「把 XX 做成可视化报告，包含 mermaid 流程图」「对比 A/B/C 三个方案，做可视化报告」。
- AI 回答下方 actionBar 一键「生成可视化报告」。
- 双击 `.html` 文件即可在浏览器查看，完全离线。

### 3.5 PPT 演示文稿（.ppt.html）

生成**自包含 HTML 单文件**（多个 `<section>` + 内联演示引擎），浏览器打开即可演示。

- 示例：「帮我做一个 PPT 演示文稿：XX 主题，5 页左右」。
- 浏览器打开：**方向键翻页** / `F` 全屏 / 幻灯片内支持 mermaid 图表、表格、列表。
- 可在聊天记录中直接点击下载链接获取 `.ppt.html` 文件。

> 文档生成/报告/PPT 的详细操作见 [v0.9.7-文档生成与报告指南](v0.9.7-文档生成与报告指南.md)。

### 3.6 工具调用（Agent）

AI 可自主调用工具完成多步任务，工具调用过程在明盒时间线中可见。

**在线模式可用工具：**

| 工具 | 用途 |
|------|------|
| `search_web` | 联网搜索（Bing），获取最新信息 |
| `fetch_url` | 读取网页正文，深入某个网页 |
| `deep_read` | 深度阅读长网页，分段提取要点 |
| `search_kb` | 检索本地知识库文档 |
| `write_workspace` / `read_workspace` / `read_workspace_chunk` | 创建/读取/分段读取工作区文件（含文档生成） |
| `set_doc_status` | 标记文档生成进度（.docx/.html/.ppt.html） |
| `calculator` | 精确数值计算（折扣、汇率、求和等） |
| `format_convert` | 格式转换 |
| `table_ops` | 读写 Excel 表格 |
| `get_current_time` | 查询当前时间/日期 |

**离线模式可用工具：** `search_kb`、`read_workspace`、`write_workspace`、`set_doc_status`、`calculator`、`get_current_time`、`format_convert`、`table_ops`（不含联网类工具）。

> 工具调用有轮次上限保护：总轮次上限 20 轮，搜索/阅读类工具有单独限流（search_web 3 次、search_kb 5 次、fetch_url 5 次），本地工具不计轮次。达到上限时 AI 会自动收尾总结。
>
> 详细说明见 [v0.9.7-工具调用使用指南](v0.9.7-工具调用使用指南.md)。

### 3.7 模型管理

通过「设置 → 模型下载」页统一管理所有 AI 模型的下载、安装和删除。

- **LLM 模型（三档）**：0.8B（0.5GB）/ 2B（1.3GB）/ 4B（2.7GB），按需下载，可删除释放磁盘后重新下载。
- **知识库模型**：bge-m3 + bge-reranker-v2-m3 组合（共约 4.5GB），一键下载安装。
- **下载源**：魔搭 ModelScope（默认，国内快）/ HuggingFace（备选），支持断点续传，刷新页面进度不丢失。
- **从本地安装**：支持 `.sidemate` 离线包安装（自动识别 LLM 或 KB 类型）。
- **删除/卸载**：LLM 删除后保留 meta.json（显示「未安装」，可重新下载）；KB 卸载删除模型文件。

> 详细操作见 [v0.9.7-设置页使用手册](v0.9.7-设置页使用手册.md)。

## 4. 设置页总览

设置页左侧竖排导航，共 **6 个 Tab**：

| Tab | 管什么 |
|-----|--------|
| **常规** | 外观（深色模式）、当前模型与 token 上限（跟随模型动态变化）、模型加载/卸载/自动加载、Reranker 常驻策略、资源占用、缓存与备份恢复 |
| **云端 AI** | API 配置（地址/Key/模型名）、数据发送策略、工具权限（联网搜索/知识库检索/文件读写/内网访问开关）、用量统计 |
| **知识库** | 文档统计、**问答引擎选择**（本地 LLM / 云端 LLM，独立于全局模式）、审计日志管理（统计+清空）、重置知识库 |
| **隐私安全** | 数据存储位置、隐私声明、CORS 调试开关、数据导出 |
| **模型下载** | 下载源选择（ModelScope/HuggingFace）、从本地安装(.sidemate)、LLM 三档卡片（下载/重新下载/删除）、知识库组合卡片（下载/重新下载/卸载）、下载进度条 |
| **关于** | 版本信息、组件状态、系统资源、环境信息、重新查看新手指引 |

> 各 Tab 的完整操作说明见 [v0.9.7-设置页使用手册](v0.9.7-设置页使用手册.md)。
