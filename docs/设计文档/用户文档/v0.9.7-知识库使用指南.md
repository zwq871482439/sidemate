# 知识库使用指南

> 版本：v0.9.7 | 适用人群：想上传文档建知识库、用 AI 检索问答、管理文档权限的用户
>
> 需要先安装「文库扩展包」。v0.9.7 嵌入模型为 bge-m3，检索采用 dense + sparse 融合 + reranker 精排。

---

## 1. 知识库概述

知识库（文库）让你把文档资料上传到本机，AI 自动分块、向量化、打标、聚类，并提供语义检索问答。

**核心隐私承诺**：

- 文档存储、分块、向量化、检索**全在本机**完成
- 文档原文**永不离开本机**
- 离线模式下零外发；在线/并行模式下云端可见性由你配置的权限决定

---

## 2. 上传文档

### 2.1 操作

1. 进入知识库 Tab，点击「上传文档」或直接拖拽文件
2. 支持批量拖入多个文件
3. 上传后自动处理：切分段落 → 向量化 → AI 打标
4. 底部浮动栏显示实时处理进度（如「正在向量化 · 60%」）

### 2.2 支持的格式

| 格式 | 说明 |
|------|------|
| **PDF** | 文本型 PDF 直接提取；扫描件需 OCR |
| **Word** | .docx / .doc |
| **TXT** | 纯文本 |
| **Markdown** | .md（保留标题层级结构） |
| **CSV** | 表格数据 |
| **JSON** | 结构化数据 |

> 不支持的格式会被拒绝并提示原因。

---

## 3. 文档分块与向量化

上传后，文档经过以下处理（全自动）：

1. **切分（chunking）**：按段落/语义边界把文档切成若干 chunk（小块），便于精准检索
2. **向量化（embedding）**：用 **bge-m3** 模型把每个 chunk 转成 1024 维向量
3. **AI 打标**：一次 LLM 调用生成 3-5 个标签 + 100 字摘要，用于分类和洞察
4. **聚类**：AI 按标签自动归并为 3-5 个大类

所有这些处理都在**本地**完成，向量数据存储在 `data/kb/` 目录。

> bge-m3 支持多语言 + 8192 长序列，比旧版 bge-base-zh 中英文混合检索效果更好。

## 4. 检索流程

当你在 Chat/并行/在线模式下提问，或 AI 调用 `search_kb` 时，检索流程如下：

```
用户问题
   ↓
1. 向量化（bge-m3 把问题也转成向量）
   ↓
2. 双路召回
   ├─ Dense 检索：向量余弦相似度 top-k（权重 α=0.7）
   └─ Sparse 检索：关键词稀疏匹配 top-k（权重 0.3）
   ↓
3. 分数融合：score = α × dense + (1-α) × sparse
   ↓
4. Reranker 精排：bge-reranker-v2-m3 对候选重排序，返回 top-5
   ↓
5. 相关性过滤：剔除相似度低于阈值（0.35）的低质量结果
   ↓
最终 KB chunk 注入 LLM 上下文
```

### 关键参数（设置页「知识库」可调）

| 参数 | 默认 | 说明 |
|------|------|------|
| `kb_vector_score_threshold` | 0.35 | 最低余弦相似度，低于此值的结果被过滤 |
| `kb_reranker_top_k` | 5 | Reranker 精排返回数量 |
| `kb_dense_sparse_alpha` | 0.7 | dense / sparse 融合权重 |
| `kb_enable_sparse` | True | 是否启用 sparse（关闭则降级为 BM25） |
| `kb_search_top_k_local` | 3 | 本地模式检索 top-k |
| `kb_search_top_k_cloud` | 5 | 云端模式检索 top-k |

## 5. 问答引擎选择（kb_ai_mode）

知识库问答使用的 LLM 引擎独立于 Chat 的 AI 模式，由 `kb_ai_mode` 配置控制：

| 值 | 引擎 | 说明 |
|----|------|------|
| `local`（默认） | 本地 llama.cpp | KB 问答完全本地完成，隐私最优 |
| `cloud` | 云端 LLM | KB 检索结果发送云端推理，答案质量更高但数据外发 |

**选择建议**：

- 默认 `local`：KB 文档含敏感信息时用，问答零外发
- 切 `cloud`：需要更强推理能力且文档非敏感时用

> `kb_ai_mode` 独立于 Chat 的离线/在线/并行模式。即使 Chat 在离线模式，`kb_ai_mode=cloud` 也会用云端引擎回答 KB 问答。

配置位置：设置 Tab → 知识库。

## 6. AI 洞察仪表盘

知识库顶部为 AI 洞察卡片，自动分析整个文库：

- **环形图**：100px SVG donut，按分类统计文档分布比例
- **洞察文字**：AI 分析知识库的主题覆盖、交叉价值和补充方向
- **建议追问**：3 条紧扣文库内容的追问按钮，点击直接跳转 Chat 提问
- **三重联动**：点击环形图扇区 / 图例 / 侧栏色点可互相联动，对应分类文档排序置顶

### 文档聚类与归并

- 上传后 AI 自动打标聚类
- 点击工具栏「整理」按钮，AI 将碎片标签归并为 3-5 个宽泛大类
- 未生成聚类的文档统一归入「正在等待智能筛选」分类

## 7. 文档权限

### 7.1 私密文档

每个 KB 文档有 `is_private` 标记：

| `is_private` | 本地 AI | 云端 AI |
|--------------|---------|---------|
| `false`（公开） | 可见 | 可见（取决于 `kb_permission`） |
| `true`（私密） | 可见 | **默认不可见** |

操作：

- **单文档**：文档卡片点击「私密」图标（锁标）
- **批量**：勾选多个文档 → 顶部工具栏「设为私密」
- **取消私密**：会主动撤销该文档所有未过期令牌（fail-safe）

> 设为私密后弹窗提示：「设为私密后，云端模型将无法读取该文档内容。」

### 7.2 kb_permission 三档配置

设置 Tab → 知识库 →「云端 AI 访问本地知识库」：

| 配置值 | 含义 | 适用场景 |
|--------|------|----------|
| `full`（默认） | 公开文档**全文**注入云端 prompt | 信任云端、追求最佳答案 |
| `search-only` | 仅发送检索**关键词**，不发送文档内容 | 敏感场景：云端辅助但不暴露数据 |
| `disabled` | 云端模式**完全不访问** KB | 纯本地优先用户 |

### 7.3 与三模式联动

| 模式 | `full` | `search-only` | `disabled` |
|------|--------|---------------|------------|
| 离线 | 不涉及 | 不涉及 | 不涉及 |
| 在线 | KB 全文注入 | KB 关键词注入 | 无 KB 上下文 |
| 并行 | 本地检索 + 云端**摘要**补充 | 本地检索 + 云端关键词补充 | 本地检索 + 云端无 KB 上下文 |

> **并行模式**：即便 `full` 档，云端看到的也只是本地生成的摘要（≤200 字），KB chunk 原文永不外传。

### 7.4 访问令牌（AccessToken）

用于把私密文档按粒度分享给他人，三档级别：

| 级别 | 含义 |
|------|------|
| `full` | 全文可见（分享给完全信任的人） |
| `search` | 检索可见（可被检索到，不暴露全文） |
| `none` | 不可见（等同于撤销） |

- 令牌为 64 字符 hex，绑定单个文档 ID
- 默认永不过期，可配置有效期
- 令牌仅存内存，进程重启后清空（防长期遗留）
- 取消私密时自动撤销该文档所有令牌

## 8. 审计日志

v0.9.7 新增 KB 文档访问审计日志：

- **存储位置**：`data/kb/audit_logs/{doc_id}.json`
- **容量**：每个文档 FIFO 保留最近 200 条
- **记录内容**：
  - **actor**（访问者）：`local` / `cloud` / `user`
  - **access_type**（访问类型）：`kb_search` / `agent_read` / `manual_cite`
  - 时间戳

### 查看

- KB 卡片上「被搜索 N 次」可点击弹窗查看该文档访问记录
- 设置页「审计日志」管理入口：查看全局统计、清空日志

> 审计日志让你清楚知道每篇文档何时被谁（本地/云端/用户）访问过，便于合规追溯。

## 9. 文档管理操作

### 9.1 标签树 + 卡片网格

- **左侧标签树**：按 AI 聚类的 category 分组，点击筛选对应文档，颜色与洞察环形图对应
- **右侧卡片网格**：文件名 + AI 标签 + 摘要 + 文件大小 / 词元 / 被搜索次数
- 支持**卡片视图 / 列表视图**切换

### 9.2 批量操作

多选文档后，顶部出现批量工具栏：删除、重标、私密/公开设置、反选/清除。

### 9.3 去重检测

点击工具栏「诊断」可检测重复文档，热力图显示各文档被搜索次数。

## 10. 常见问题

### Q1：上传的文档会被传到云端吗？
不会。上传、分块、向量化、存储全在本机。只有当你切换到在线模式且 `kb_permission=full` 时，检索到的公开文档 chunk 才会注入云端 prompt。

### Q2：私密文档本地 AI 能读到吗？
能。`is_private` 只对云端 AI 生效，本地 AI 对所有文档有完整读取权。

### Q3：kb_ai_mode 和 Chat 的 AI 模式有什么区别？
- Chat 的 AI 模式（离线/在线/并行）控制对话引擎
- `kb_ai_mode`（local/cloud）控制**知识库问答**专用引擎，两者独立

### Q4：检索结果不准怎么办？
- 点击「整理」让 AI 重新聚类归并标签
- 调整 `kb_vector_score_threshold`（降低阈值召回更多）
- 确认 sparse 检索已启用（`kb_enable_sparse=True`）

### Q5：令牌重启后还在吗？
不在。令牌仅存内存不持久化，重启后需重新生成。这是有意设计，防止长期遗留令牌被滥用。
