# 工具调用使用指南

> 版本：v0.9.7 | 适用人群：使用在线 Agent 模式、想让 AI 自动联网搜资料/读写文件/写文档的用户
>
> 工具调用（Tool Calling）是在线模式的核心能力：AI 自主判断何时调用哪个工具，多轮交替完成复杂任务。

---

## 1. 工具调用概述

在线模式下，AI 不是一个只会回答问题的聊天机器人，而是一个能**自主使用工具**的 Agent：

```
用户提问 → AI 判断是否需要工具
   ├─ 不需要 → 直接回答
   └─ 需要 → 选择合适工具调用
        ├─ 读文件 / 搜资料 / 计算 ...
        └─ 拿到工具结果 → 继续推理
             ├─ 还需要更多工具 → 继续调用
             └─ 信息够了 → 生成最终回答
```

例如你问「帮我查一下 2026 年新能源车销量并做个汇总」：

1. AI 调 `search_web` 搜互联网
2. AI 调 `fetch_url` 抓取相关网页正文
3. AI 调 `calculator` 算汇总数据
4. AI 综合信息给出带数据的回答

整个过程 AI 自主决策，你只需提一个问题。

## 2. 在线模式工具列表

在线模式（Agent）可用工具：

| 工具 | 用途 | 单轮上限 |
|------|------|----------|
| `search_web` | 联网搜索互联网（Bing） | 3 次 |
| `fetch_url` | 抓取指定网页正文 | 5 次 |
| `search_kb` | 检索本地知识库（受 `kb_permission` 控制） | 5 次 |
| `deep_read` | 深度阅读长文档，返回结构化分析 | 不限 |
| `write_workspace` | 写工作区文件 | 不限 |
| `read_workspace` / `read_workspace_chunk` | 读取工作区文件 | 不限 |
| `list_workspace` / `list_docs` | 列出工作区文件 / 已完成文档 | 不限 |
| `append_workspace` / `edit_workspace` / `delete_workspace` | 追加 / 编辑 / 删除工作区文件 | 不限 |
| `set_doc_status` | 生成可下载产物（.docx / .html / .ppt.html） | 不限 |
| `summarize_history` | 压缩对话历史 | 不限 |
| `calculator` | 算术计算（折扣、汇率、求和、百分比） | 不限 |
| `get_current_time` | 查询当前时间 | 不限 |
| `format_convert` | 文件格式转换（md/docx/txt 互转、pdf 提取） | 不限 |
| `table_ops` | Excel 表格读写 | 不限 |

> 在线模式最多 **20 轮** Agent 循环。搜索类（search_web/search_kb/fetch_url）有次数上限，其他工具不限。

## 3. 离线模式工具列表

离线模式不跑完整 Agent 循环，但支持以下本地工具与能力：

| 工具 | 用途 |
|------|------|
| `search_kb` | 检索本地知识库 |
| `read_workspace` / `read_workspace_chunk` | 读取工作区文件 |
| `write_workspace` | 写工作区文件 |
| `set_doc_status` | 生成可下载产物 |
| `calculator` | 算术计算 |
| `get_current_time` | 查询当前时间 |
| `format_convert` | 文件格式转换 |
| `table_ops` | Excel 表格读写 |

> 离线模式**不支持**：`search_web`（联网搜索）、`fetch_url`（抓网页）、`deep_read`（深度阅读）以及完整的多轮 Agent 循环。

### 离线 / 在线工具对照

| 工具 | 离线 | 在线 |
|------|------|------|
| `search_kb`（KB 检索） | 支持 | 支持（受 `kb_permission`） |
| `read_workspace` / `write_workspace` | 支持 | 支持 |
| `set_doc_status`（生成产物） | 支持 | 支持 |
| `calculator` / `get_current_time` | 支持 | 支持 |
| `format_convert` / `table_ops` | 支持 | 支持 |
| `search_web`（联网搜索） | 不支持 | 支持（3 次/轮） |
| `fetch_url`（抓网页） | 不支持 | 支持（5 次/轮） |
| `deep_read`（深度阅读） | 不支持 | 支持 |
| 完整 Agent 多轮循环 | 不支持 | 支持（最多 20 轮） |

## 4. 工具调用约束

为防止 AI 死循环和 token 爆炸，Agent 循环有以下硬约束：

### 4.1 总轮次上限：20 轮

- 一次性任务最多 **20 轮** Agent 推理
- 达到上限后系统注入「禁止再调工具，直接给最终回答」指令，追加一轮纯对话生成总结
- 不会静默退出——你总能看到 AI 基于已有信息的总结回答

### 4.2 Cheap 工具（不计轮次）

本地、不消耗 token 预算的操作，**不计入 20 轮上限**：

| Cheap 工具 | 说明 |
|------------|------|
| `read_workspace` / `read_workspace_chunk` | 读取文件 |
| `list_workspace` / `list_docs` | 列出文件 |
| `summarize_history` | 压缩历史 |
| `get_current_time` | 查询时间 |
| `calculator` | 算术 |
| `format_convert` | 格式转换 |
| `table_ops` | 表格读写 |

> 效果：AI 连续读 30 次文件也不会卡住 20 轮上限。

### 4.3 搜索类工具上限

消耗 token 的「贵」工具有单轮次数上限：

| 工具 | 单轮上限 | 说明 |
|------|----------|------|
| `search_web` | 3 次 | 互联网搜索 |
| `search_kb` | 5 次 | 知识库检索（本地便宜，可多查） |
| `fetch_url` | 5 次 | 网页阅读 |

达到上限后：首次发友好提示「已搜索 N 次，基于已获取信息继续回答」，之后静默拒绝。下一条消息计数重置。

### 4.4 总 token 上限

工具历史最大 60000 字符（约 40000 token），超限自动压缩。

## 5. 工具权限配置

### 5.1 工具级开关

并非所有工具都强制开启。设置 → 云端 AI → 工具权限，可按类禁用：

| 权限开关 | 控制的工具 |
|----------|------------|
| `tool_enabled_kb_search` | `search_kb` |
| `tool_enabled_web_search` | `search_web` / `fetch_url`（抓取网页归入联网搜索） |
| `tool_enabled_file_rw` | `read_workspace` / `write_workspace` / `list_workspace` / `delete_workspace` / `append_workspace` / `edit_workspace` |

此外，系统内置 **SSRF 防护**：`fetch_url` 默认拒绝访问内网地址（如 192.168.x.x），通过权限预设（trusted/cautious/offline）整体控制安全级别，而非单独开关。

### 5.2 配置入口

**设置 Tab → 云端 AI → 工具权限**

- 关闭某类工具后，AI 在 Agent 循环中看不到该工具，不会调用
- 内网地址默认被拦截（SSRF 防护），需要抓取内网页面时选择更宽松的权限预设

### 5.3 KB 权限（kb_permission）

`search_kb` 工具的可见性还受 KB 权限影响（独立于工具开关）：

| `kb_permission` | `search_kb` 行为 |
|-----------------|------------------|
| `full` | 可检索并返回 chunk 全文 |
| `search-only` | 仅返回检索关键词命中，不返回 chunk 内容 |
| `disabled` | 工具不可用（即便工具开关开着） |

配置位置：设置 → 知识库 → 云端 AI 访问本地知识库。

## 6. 工具调用失败处理

工具调用失败时，错误状态会显示**具体原因**（而非裸「操作异常」）：

| 现象 | 含义 | 解决 |
|------|------|------|
| 文件不存在：xxx.docx（文件可能在远程而非工作区） | LLM 用错了远程文件名 | 改用 `list_workspace` 看本地文件 |
| 路径不安全，已拒绝 | 文件路径试图越界（含 `..`） | 检查路径合法性 |
| 操作受限：xxx | 其他工具限制 | 看具体 reason 内容 |

AI 拿到失败结果会**自己调整**（换文件名、换工具）。连续失败 5 次会主动放弃并告知你。

## 7. 减少 token 消耗的技巧

### 7.1 短问短答

- 差：「帮我分析一下 XXX 这个事」
- 好：「XXX 的核心机制是什么？3 点」

### 7.2 引用而不是复述

- 差：把整个长文档粘进对话框让 AI 总结
- 好：「用 `read_workspace` 读 workspace/xxx.md 帮我总结」

### 7.3 切文档模式生成长文

- 差：让 AI 在 chat 里「现场写 3000 字报告」
- 好：切到 doc 模式，AI 用 `write_workspace` + `set_doc_status` 流式生成产物

### 7.4 用 actionBar 一键复用

不要让 AI「再读一次当前回答」再生成报告——直接点 actionBar，AI 直接调 `set_doc_status`，省一轮。

## 8. 调试工具调用

工具频繁失败时，查看 server 日志：

```
data/logs/server.log  搜索 "[AGENT]"
```

| 日志 | 含义 |
|------|------|
| `[AGENT] === 第 N 轮 ===` | AI 第 N 轮推理开始 |
| `[AGENT] 工具调用: <name>(args)` | AI 决定调用的工具 |
| `[AGENT] 工具 <name> 已达上限 N/M` | 工具触发硬限制 |
| `[AGENT] 子类超限，移除工具: [...]` | 工具被从列表移除 |
| `[AGENT] 达到最大轮次 20` | 触发收尾流程 |

## 9. 常见问题

### Q1：AI 反复读同一文件然后停了？
v0.9.7 已修复：`read_workspace` 等 cheap 工具不计入 20 轮上限，读 30 次也不会卡。

### Q2：达到 20 轮后怎么办？
系统注入收尾指令，AI 基于已有信息生成总结回答。如果纯对话调用也失败，显示兜底文案，建议你在新消息里继续提问或切文档模式。

### Q3：怎么让 AI 不要联网搜索？
设置 → 云端 AI → 工具权限，关闭 `tool_enabled_web_search`，AI 就看不到 `search_web` / `fetch_url`。

### Q4：离线模式能用 Agent 工具链吗？
离线模式不跑完整 Agent 循环，但支持 `search_kb` / `read_workspace` / `write_workspace` / `calculator` 等本地工具。联网搜索类工具仅在在线模式可用。

### Q5：工具上限是「本日」还是「本轮」？
**本轮**（每次 Agent 循环重置）。文案明确写「本轮对话」，下一条消息可重新使用。

### Q6：AI 抓内网页面失败？
内网地址默认被拦截（SSRF 防护）。这是安全设计，防止 AI 被诱导访问内部服务。如确需抓取内网页面，可在设置中调整权限预设。
