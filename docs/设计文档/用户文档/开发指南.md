> 版本：v0.9.7 | 面向开发者

## 1. 环境搭建

### 1.1 前置条件

- Windows 10/11 64-bit
- Python 3.14（项目自带嵌入式 Python，位于 `python/`）
- Git

### 1.2 启动开发环境

```bash
# 克隆仓库
git clone <repo> Sidemate
cd Sidemate

# 直接启动（需要完整的运行时资产）
.\Sidemate.exe
```

Sidemate.exe 是 Go Launcher，自动：拉起 Ollama → 启动 FastAPI → 打开浏览器。

后端端口：`127.0.0.1:8976`

## 3. SSE 调试

### 3.1 关键规则

**每个 SSE 错误出口必须发 `done` 事件**，否则前端 UI 锁死。

```python
# 正确示例
try:
    yield sse_data(...)
except Exception:
    yield sse_done_event()  # ← 必须！
```

### 3.2 调试 SSE

```bash
# 直接 curl 查看原始 SSE 流
curl -N -X POST http://127.0.0.1:8976/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"message":"你好"}'
```

### 3.3 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 前端 UI 卡死 | SSE 缺少 done 事件 | 检查所有 `except` 出口 |
| 流式断掉 | 超过 60s 超时 | 调整 `timeout` 参数 |
| 离线模式无反应 | 模型未加载 | 检查 `/api/status` |

## 5. 测试

### 5.1 运行已有测试


### 5.2 测试文件说明

| `test_bg_init_state.py` | 后台初始化状态测试 |
| `test_extension_fallback.py` | 扩展回退测试 |

### 5.3 写新测试

测试文件使用 Python 标准库 `unittest`，参考 `test_regression_v31.py` 的结构：

```python
import unittest
import requests

class TestKB(unittest.TestCase):
    def setUp(self):
        self.base = "http://127.0.0.1:8976"

    def test_health(self):
        r = requests.get(f"{self.base}/api/health")
        self.assertEqual(r.json()["status"], "ok")
```

- 改 `server/*.py` 后重启 `Sidemate.exe` 即生效

- 别删 `.workbuddy/` 目录
- 别碰 `python/` `models/` `lib/`（runtime，不进 git）
- 改已有功能后必须测试
