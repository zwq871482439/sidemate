# 并行模式使用指南

> 版本：v0.9.6（当前发版） | Chat Tab 第三档
>
> 📘 v0.9.7 起此文档将被 `v0.9.7-三模式切换使用指南.md` 覆盖（涵盖离线 / 在线 / 并行三模式完整说明）。本文档暂留作 v0.9.6 期间参考。

---

## 1. 什么是并行模式

并行模式 = **本地检索知识库 + 云端通用知识**，各自独立回答，本地自动融合。

核心原则：**KB 原文永不离开本机**。云端模型只看到本地生成的摘要，无法访问原始文档。

---

## 2. 如何开启

1. Chat Tab 顶栏点击最右侧「并行」按钮
2. 确认弹窗提示后完成切换
3. 输入问题，开始使用

---

## 3. 三阶段时间线

每次提问后，AgentTimeline 展示三步流程：

| 阶段 | 说明 | 耗时 |
|------|------|------|
| **检索** | 本地检索 KB 相关文档 chunk | ~0.5s |
| **本地生成** | 本地 LLM 基于 KB 内容生成回答 | 3-10s |
| **云端补充** | 云端 LLM 基于本地摘要补充通用知识 | 3-15s |
| **融合** | 本地自动合并两端结果 | ~1s |

各阶段独立计时，以阶段卡片形式展示。历史消息持久化可回放。

---

## 4. 齿轮开关

并行模式下可选开启「允许云端模型生成关键词」开关：

- **开启**：云端拆解 3-5 个检索关键词增强本地召回
- **关闭**：仅使用用户原始问题检索 KB

---

## 5. 与离线/在线模式的区别

| | 离线 | 在线 | 并行 |
|------|------|------|------|
| 数据隐私 | 完全本地 | 发送至云端 | KB 本地，摘要送云端 |
| KB 可用 | 是（查知识库 action） | 是（引用） | 是（自动检索） |
| 回答速度 | 快 | 中 | 较慢（多阶段） |
| 知识广度 | 仅 KB | 仅云端 | KB + 云端融合 |
