## 1. 首次启动

运行 `Sidemate.exe`，启动器会自动启动后端服务并打开浏览器页面。

### 1.1 欢迎弹窗

首次进入会弹出**欢迎弹窗**，根据当前状态智能分支：

- **未安装任何 AI 引擎**：提示选择「本地 AI」或「云端 AI」。本指引走本地路线，点「前往设置」。
- **已就绪 AI、未装知识库**：提示可开始对话，可选安装知识库。
- **全功能就绪**：直接「开始浏览」。

点「前往设置」进入设置页，左侧导航选「**模型下载**」。

### 1.2 交互式引导（TourGuide）

部分场景会进入 5 步聚光引导，高亮关键操作位置。可点「跳过」直接探索，之后在「设置 → 关于 → 重新查看新手指引」可随时重看。

## 2. 下载本地对话模型（LLM）

进入 **设置 → 模型下载**。

### 2.1 选择下载源

页面顶部「下载设置」卡片的「下载源」下拉：

- **魔搭 ModelScope（国内推荐，速度快）**：默认，国内网络稳定无需代理。
- **HuggingFace（国际源，需代理）**：备选。

本指引保持默认 ModelScope。

### 2.2 选一档 LLM 下载

「对话模型（LLM）」卡片列出三档，按你的内存/显存选择：

| 档位 | 大小 | 最低内存 | 说明 |
|------|------|----------|------|
| **通义千问 3.5 (0.8B · Q4_K_M)** | 约 0.5GB | 2GB | 低端，老旧设备也能跑，能力有限 |
| **通义千问 3.5 (2B · Q4_K_M)** | 约 1.2GB | 4GB | 中端，4GB 显存流畅，推荐大多数用户 |
| **通义千问 3.5 (4B · Q4_K_M)** | 约 2.5GB | 8GB | 中高，8GB 显存流畅，能力最强 |

> 建议：8GB 以上内存的机器选 **2B 或 4B**；不确定就先下 2B，后续可再下 4B。

点对应卡片的「**下载**」按钮。

### 2.3 等待下载完成

页面顶部出现进度条，实时显示：

- 已下载 / 总大小（如 `0.8GB / 2.5GB`）
- 下载速度（如 `5.2MB/s`）
- 剩余时间（如 `剩余 3m20s`）

支持**断点续传**——中断后重新点下载会接着上次继续。下载完成后自动安装，卡片显示「已安装」。

> 同时只允许一个下载任务，下载完一个再下下一个。

## 3. 安装知识库模型

知识库功能依赖两个模型：**bge-m3（向量化）** + **bge-reranker-v2-m3（重排序）**，合计约 4.5GB。

仍在 **设置 → 模型下载** 页面，「知识库模型」卡片：

1. 点「**下载知识库模型**」。
2. 进度条显示多文件累计下载进度（会逐个下载 embedding 和 reranker 的权重与配置文件）。
3. 完成后自动注册并加载，卡片显示「已安装」。

> 想用知识库问答就必须装这两者；只用纯对话则可跳过本步。

### 从本地安装（可选）

如果你有离线 `.sidemate` 安装包（LLM 或知识库模型），可在「从本地安装」卡片点「选择 .sidemate 文件」直接安装，自动识别是 LLM 还是知识库模型。

## 4. 第一次对话

回到 **对话** 页（顶栏左侧「对话」Tab）。

### 4.1 加载模型（若未自动加载）

如果输入框上方提示需要启动模型，去 **设置 → 常规 → 模型与资源**，在下拉选择已下载的模型，点「切换」。

> 勾选「启动时自动加载模型（推荐）」可省去这一步，以后启动即就绪。

### 4.2 开始聊天

1. 在底部输入框输入问题，例如：「你好，请介绍一下你自己」。
2. 按 **Enter** 发送（**Shift+Enter** 换行）。
3. AI 流式生成回答，左侧紫色色条标识 AI 消息。

### 4.3 试试进阶玩法

- **上传文件**：点附件按钮上传 pdf/docx 等，AI 基于文件内容回答。
- **生成文档**：输入「帮我写一份关于时间管理的报告」，AI 先出提纲，确认后生成 `.docx`。
- **可视化报告**：输入「把 XX 做成可视化报告，包含 mermaid 流程图」，生成自包含 HTML 文件。
- **PPT**：输入「帮我做一个 PPT：XX 主题，5 页」，生成 `.ppt.html`。

## 5. 第一次知识库问答

### 5.1 上传文档

进入 **知识库** Tab（顶栏中间）：

1. 点「上传文档」，选 txt/md/pdf/docx 等文件，或直接拖入。
2. 底部浮动栏显示实时处理进度（分块 → 向量化 → 打标）。
3. 处理完成后，文档出现在右侧卡片网格，左侧标签树显示 AI 聚类的分类。

### 5.2 查看 AI 洞察

知识库顶部「AI 洞察仪表盘」：

- **环形图**：按分类统计文档分布。
- **洞察文字**：AI 分析主题覆盖、交叉价值、补充方向。
- **建议追问**：3 条紧扣文库内容的按钮，点击直接跳对话提问。

### 5.3 提问

回到 **对话** Tab，提问时 AI 会自动检索知识库。或者直接点洞察卡片上的「建议追问」按钮。

回答中会显示知识库来源卡片（命中了哪些文档、相关度分数），引用上标可点击跳转。

### 5.4 选择问答引擎（可选）

去 **设置 → 知识库 → 问答引擎**：

- **本地 LLM（隐私优先）**：用本地模型回答，数据不出本机。
- **云端 LLM（质量优先）**：用云端模型回答，质量更高但会发送检索片段到云端。

这个设置独立于全局的离线/在线模式——你可以全局用离线，但知识库问答用云端，反之亦然。

## 6. 三种模式切换入门

顶栏「离线 / 在线 / 并行」三段按钮切换。切换时弹确认框，说明功能与数据流变化。

| 模式 | 引擎 | 数据流 | 何时用 |
|------|------|--------|--------|
| **离线** | 本地 LLM | 全部本地，不联网 | 隐私优先、断网、敏感资料 |
| **在线** | 云端 API | 对话发往你配置的云端 | 需要更强能力、联网搜索 |
| **并行** | 本地 KB + 云端协作 | 知识库原文不出本机，片段+问题发云端 | 既要强模型又要本地资料 |

### 入门建议

1. **先熟悉离线模式**：下载好本地模型后，离线模式开箱即用，无需任何配置。
2. **想试在线**：去 **设置 → 云端 AI** 填入 API 地址、Key、模型名称（OpenAI 兼容格式），点「测试连接」成功后保存，即可切换在线模式。
3. **进阶并行**：配好云端 API + 装好知识库模型 + 上传文档后，并行模式让云端大模型基于你的本地资料回答。

## 7. 常见疑问

**Q：必须下载本地模型吗？**
不一定。如果你只想用云端 AI，可以跳过 LLM 下载，直接在「云端 AI」配置 API。但知识库功能必须有本地知识库模型（bge-m3 + reranker）。

**Q：下载很慢怎么办？**
确认下载源是「魔搭 ModelScope」（国内推荐）。支持断点续传，中断后重新点下载会接着继续。同一时刻只能下一个任务。

**Q：三档 LLM 怎么选？**
内存 ≥8GB 选 4B 或 2B；4–8GB 选 2B；低于 4GB 选 0.8B。可同时装多档，在「设置 → 常规」随时切换。

**Q：数据安全吗？**
默认离线模式，对话/文档/知识库 100% 存本地。只有切换到在线/并行模式，对话内容才会发往你配置的云端 API。详见「设置 → 隐私安全」。

**Q：想重看新手引导？**
**设置 → 关于 → 重新查看新手指引**。
