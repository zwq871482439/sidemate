# 桌伴 Sidemate 常见问题 (FAQ)

> 版本：v0.9.7（当前发版） | 适用于 Windows 桌面版
>
> v0.9.7 起底座为 **llama.cpp（llama-server.exe）**，本地模型为 **Qwen3.5 三档**。

---

## 1. 安装与启动

### Q1：程序无法启动 / 双击没反应

1. 确认系统为 Windows 10/11 64 位
2. 安装路径建议纯英文（如 `D:\Sidemate\`），避免中文或空格
3. 以管理员身份运行 `Sidemate.exe`
4. 查看 `data/logs/` 日志，寻找 `error` 行

### Q2：启动后界面提示「服务未就绪」

首次启动需 1-2 分钟初始化（Go launcher 拉起 llama-server + Python 后端 + 浏览器）。若长时间未就绪：

1. 确认已在「设置 → 模型下载」下载并加载模型
2. 检查端口 11434（llama-server）/ 8976（Python 后端）是否被占用
3. 重启 Sidemate

### Q3：启动时弹「端口被占用」

11434 或 8976 端口被其他程序占用。关闭占用程序，或重启电脑后重试。详见《故障排查》§1。

## 2. 模型下载

### Q1：模型下载失败 / 速度很慢

**网络问题**：
1. 默认源为 **ModelScope（魔搭）**，国内速度较快
2. 在「模型下载」页切换下载源为 **HuggingFace**（海外用户或 ModelScope 异常时）
3. 下载中断可点「继续」断点续传

**彻底换源仍失败**：
- 改用「**从本地安装**」：在可联网机器下载 `.sidemate` 包，拷贝到本机导入

### Q2：应该选哪个 LLM 档位？

| 档位 | 体积 | 内存占用 | 建议 |
|------|------|----------|------|
| Qwen3.5-0.8B | ~0.5 GB | ~1.5 GB | 8GB 内存机器、快速问答 |
| Qwen3.5-2B | ~1.3 GB | ~3 GB | 通用对话（推荐起步） |
| Qwen3.5-4B | ~2.7 GB | ~6 GB | 16GB 内存、复杂推理 |

内存不够时优先降档位，不要硬上 4B。

### Q3：不下载 KB 模型可以用知识库吗？

**不能**。知识库依赖 bge-m3（向量化）+ bge-reranker-v2-m3（重排序），共约 4.5GB。未加载时上传文档会报「嵌入模型未就绪」。LLM 档位和 KB 组合可分别下载，互不依赖。

## 3. 本地模型慢 / 卡顿

### Q1：本地回答很慢

| 情况 | 原因 | 解决 |
|------|------|------|
| 首次很慢 | 模型加载 / Vulkan 首次编译 | 等待 1-2 分钟 |
| 持续慢 | 内存不足或跑在 CPU | 关闭其他大内存程序；降一档模型；有独显则开启 Vulkan |
| 中途变慢 | 对话历史过长 | 新建对话 |
| 顿挫明显 | 4B 档位吃满内存 | 换 2B 或 0.8B |

**参考速度（CPU 模式）**：0.8B 每秒 ~15 字，2B ~8 字，4B ~3-5 字。开启 Vulkan 后普遍 2-4 倍提升。

### Q2：切换推理设备（CPU / GPU / Vulkan）在哪设置？

在「设置 → 常规」中选择推理后端。有 Vulkan 支持的独显选 Vulkan 性能最佳；无独显选 CPU（稳定）。

## 4. 云端模式配置

### Q1：切换到在线 / 并行模式后报错

1. 确认已联网
2. 确认「设置 → 云端 AI」的 Base URL / API Key / 模型名称填写正确
3. 点「保存」会自动测试连接，看测试是否通过
4. 企业内网可能屏蔽外部 API —— 需联系网管放行，或使用本地模式

### Q2：三种模式怎么选？

| 模式 | 数据流向 | 适合 |
|------|----------|------|
| **离线** | 全本地，不出本机 | 隐私敏感、无网络、离线环境 |
| **在线** | 提问发送云端 | 通用题、追求最强回答质量 |
| **并行** | 本地+云端同时答，检索段落发云端 | KB 知识题，融合本地资料 + 云端能力 |

简单口诀：**隐私题→离线，通用题→在线，KB 知识题→并行**。

### Q3：并行模式会把知识库文档传到云端吗？

**不会传原文**。云端只看到检索后筛选出的少量段落（作为上下文），不是整篇文档。如需更严格，可在「设置 → 知识库」调整 KB 权限为 search-only（仅发检索词）或 disabled（完全不发）。

## 5. 知识库上传 / 检索

### Q1：上传文档失败 / 一直「处理中」

**支持格式**：`.txt` `.md` `.pdf` `.docx` `.xlsx` `.pptx` `.csv` `.json`

1. 确认格式在支持列表
2. 确认文件未损坏（能正常打开）
3. 确认 KB 模型（bge-m3 + bge-reranker-v2-m3）已加载——在「模型下载」页检查
4. 卡在「处理中」：刷新页面或重启程序；重启后存量文档会自动恢复

### Q2：检索不到我上传的内容 / 回答不准

1. 确认文档已处理完成（状态不是「排队中」）
2. 知识库最多支持 200 个文档；过多会降低检索精度
3. 改用更具体的问题，或在问题中带上文档里的关键词
4. 切换 KB 问答引擎为 cloud（见下节），用云端模型回答 KB 问题

### Q3：上传后侧栏分类为空

AI 打标在后台异步执行（P2 优先级），新文档需排队。等打标完成后点「整理」即可聚类。

## 6. KB 问答引擎选择（kb_ai_mode）

### Q：local 和 cloud 有什么区别？怎么选？

v0.9.7 起知识库问答引擎可选：

| 模式 | 回答用谁 | 数据流向 | 适合 |
|------|----------|----------|------|
| **local**（默认） | 本地 Qwen3.5 | 全本地，不出本机 | 隐私敏感、离线 |
| **cloud** | 云端模型 | KB 检索段落 + 问题发云端 | 追求回答质量、KB 内容可对外 |

在「设置 → 知识库」中切换。选 cloud 时，只有检索到的段落和问题发往云端，原始文档全文不上传。

## 7. 报告 / PPT 生成

### Q1：让 AI 生成报告，但没出现「下载」按钮

AI 可能没调用报告完成标记。解决：
- 在新消息里说「请把刚才的内容生成 HTML 报告」
- 或在 AI 回答下方的 actionBar 点「生成可视化报告 / 生成 PPT」

### Q2：HTML 报告里图表显示「渲染失败」

LLM 写的 mermaid 语法有错（常见：节点标签用了半角双引号）。让 AI 重新生成，或手动改 `.html` 里 `<pre>` 中的源码。

### Q3：PPT 文件名是 `.ppt.html`，能改成 `.pptx` 吗？

**不能**。`.ppt.html` 是 Sidemate 的 HTML 包装格式（reveal.js），不是真正的 PowerPoint 文件。如需 PPTX：在浏览器打开后 `?print-pdf` + `Ctrl+P` 导出 PDF，再用 PowerPoint 打开另存。

### Q4：PPT 打开是空白页

F12 看 Console 是否报 `Reveal is not defined`。重新生成 PPT 即可（确认服务端版本 ≥ v0.9.6-final）。

## 8. 数据与卸载

### Q：数据存在哪里？

全部在安装目录下的 `data/` 文件夹：对话（`chats/`）、知识库（`kb/`）、模型、设置、日志。详见《隐私与安全说明》。

### Q：如何完全卸载？

1. 托盘图标右键退出
2. 控制面板卸载（默认保留 `data/`）
3. 彻底清除：手动删除安装目录

> 卸载前如需保留数据，请先备份 `data/` 文件夹。

## 还有问题？

1. 查看 `data/logs/` 日志文件
2. 重置配置：删除 `settings.json` 后重启（自动恢复默认值）
3. 紧急模式：在「设置 → 常规」切到 CPU 推理后重启
4. 详见《故障排查.md》
