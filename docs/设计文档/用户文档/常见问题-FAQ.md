# 桌伴 Sidemate 常见问题 (FAQ)

> 版本 v0.9.6（当前发版） | 适用于 Windows 桌面版
>
> 📘 v0.9.7 新增功能相关 FAQ（Onboarding / 知识库权限 / AI 洞察 v2）见同目录 `v0.9.7-*.md` 文档。

## 1. 程序无法启动

**现象**：双击图标或运行启动脚本后，程序没有反应或弹出错误窗口。

**排查步骤**：

1. 确认你的电脑是 Windows 10/11 64 位系统
2. 检查安装目录路径是否包含中文或空格——如果路径中有中文字符，请将整个文件夹移到纯英文路径下（例如 `D:\Sidemate\`）
3. 确认磁盘空间充足（程序和模型文件大约需要 5 GB 以上）
4. 尝试以管理员身份运行启动脚本
5. 如果仍然无法启动，查看 `data\logs\` 文件夹中的日志文件，寻找包含 "error" 的行

**提示**：启动后需要等待一段时间让 AI 模型加载完成，首次加载可能需要 2-5 分钟，请耐心等待。

---

## 2. AI 不回答 / 回答很慢

**现象**：发送消息后没有收到回复，或者回复速度非常慢。

**可能的原因和解决方案**：

| 情况 | 可能原因 | 解决方法 |
|------|---------|---------|
| 一直显示"思考中" | AI 模型尚未加载完成 | 等待 2-5 分钟，首次启动需要加载模型 |
| 回复中断或为空 | 对话历史过长，超出模型处理能力 | 新建一个对话（点击"新建对话"按钮） |
| 回复内容重复 | 模型参数需要调整 | 在设置中尝试切换推理设备（CPU/GPU） |
| 速度明显变慢 | 电脑内存不足 | 关闭其他占用内存的程序 |

**参考速度**：
- 首次使用 NPU/GPU：需要 2-5 分钟编译，之后恢复正常
- CPU 模式：每秒生成 3-8 个字
- GPU 模式：每秒生成 10-30 个字

---

## 3. 云端模式不工作

**现象**：切换到在线/云端模式后，AI 无法回答或报错。

**排查步骤**：

1. 确认你的电脑已连接互联网
2. 确认网络没有屏蔽外部 API 访问（部分企业网络可能有限制）
3. 检查设置中的云端模型配置是否正确
4. 如果使用代理上网，确认代理设置正确

**注意**：云端模式需要网络连接。如果你的环境是纯内网（无法访问互联网），请使用本地模式。

---

## 4. 知识库上传失败

**现象**：向知识库上传文档时失败或一直显示"处理中"。

**支持的文件格式**：`.txt`、`.md`、`.pdf`、`.docx`、`.xlsx`、`.pptx`、`.csv`、`.json`

**排查步骤**：

1. 确认文件格式在上述支持列表中
2. 确认文件没有损坏（能正常打开）
3. 确认文件大小合理（过大的文件处理时间会较长）
4. 如果状态一直卡在"处理中"，尝试刷新页面或重启程序
5. 检查磁盘空间是否充足——知识库索引文件存放在 `data\kb\` 目录

**提示**：文档上传成功后，程序会自动为文档生成 AI 标签和摘要，这个过程在后台进行，不会影响你正常使用。知识库最多支持同时管理 **200 个文档**（`kb_max_documents: 200`）。

---

## 5. 知识库文档不显示分类

**现象**：上传文档后，侧栏分类标签为空或只有「正在等待智能筛选」。

**原因**：AI 打标需要时间，新上传的文档在后台排队。等待打标完成后点击「整理」按钮即可自动聚类。

**提示**：知识库支持最多同时管理 **200 个文档**（`kb_max_documents: 200`）。

---

## 6. 界面显示异常

**现象**：页面白屏、内容不显示、排版错乱等。

**常见情况**：

| 问题 | 解决方法 |
|------|---------|
| 页面白屏/无响应 | 按 F5 刷新页面；如果持续白屏，重启程序 |
| 知识库列表不更新 | 刷新页面或重新切换到知识库标签页 |
| 数学公式显示异常 | 检查是否处于离线环境（公式渲染需要本地资源文件完整） |
| 暗色模式颜色异常 | 切换回亮色模式再切换一次，或重启程序 |
| 聊天内容突然中断 | 程序可能正在后台重启，等待几秒后页面会自动恢复连接 |

**提示**：推荐使用 Chrome 或 Edge 浏览器访问。程序运行期间请勿关闭控制台窗口。

## 7. 如何更新

**更新方式**：

1. 下载最新版本的安装包
2. 运行安装程序覆盖安装（不会影响你的数据和设置）
3. 安装完成后重新启动程序即可

**更新前建议**：如果新版本跨度较大，建议备份 `data\` 文件夹，以防万一。

---

## 8. 数据存在哪里

所有用户数据存储在程序安装目录下的 `data\` 文件夹中：

| 目录 | 内容 |
|------|------|
| `data\logs\` | 运行日志 |
| `data\kb\` | 知识库索引和文档数据 |
| `data\chats\` | 聊天记录 |
| `data\tmp_upload\` | 临时上传文件 |

配置文件（如 `settings.json`）位于程序根目录。

**安全提示**：你可以通过复制上述文件夹来备份你的数据。卸载前请务必备份 `data\` 文件夹。

---

## 9. 如何完全卸载

**步骤**：

1. 关闭正在运行的桌伴程序
2. 删除程序安装文件夹（默认在安装时选择的路径）
3. 如果需要清除所有数据，一并删除整个安装目录（包括 `data\` 文件夹）

**注意**：卸载会删除所有聊天记录和知识库数据。如果需要保留数据，请在删除前备份 `data\` 文件夹。

---

## 还有问题？

如果以上方案未能解决你的问题：

1. 查看 `data\logs\` 文件夹中的日志文件，寻找错误信息
2. 尝试重置配置：删除程序目录下的 `settings.json` 文件，然后重新启动程序（配置会自动恢复默认值）
3. 尝试紧急模式：在配置中将推理设备切换为 CPU 后重新启动

## 10. 新手指引（Onboarding）相关

> 📘 详细使用说明见 [v0.9.7-新手指引使用手册.md](v0.9.7-新手指引使用手册.md)（v0.9.7 待发版功能）

### Q1：首次启动没看到欢迎弹窗？

**原因**：欢迎弹窗状态保存在浏览器 localStorage，清理浏览数据会导致重新出现。如果仍没看到：

1. 硬刷新 `Ctrl+Shift+R`
2. 浏览器控制台（F12）查看 `[welcome]` 相关错误
3. 手动重置：设置 → 关于 → 「重新查看新手指引」

### Q2：TourGuide 引导过程中想退出？

点击引导遮罩的外部（卡片外区域）或按 Esc 即可退出。下次启动不再自动弹。

### Q3：模式按钮 / 输入框 / 设置入口的聚光位置不准确？

1. 浏览器缩放比异常 → 调整为 100% 后硬刷新
2. 屏幕分辨率过小（< 800×600）→ 聚光会自动退化到整屏纯遮罩 + 卡片居中
3. 详见 [v0.9.7-Onboarding前端设计.md](../架构与设计/v0.9.7-Onboarding前端设计.md) §4.5

### Q4：「重新查看新手指引」点击没反应？

1. 检查控制台（F12）是否有 `[resetOnboarding]` 错误
2. 确认浏览器允许 localStorage（隐私模式下不持久）
3. 调试快捷键：`Ctrl+Shift+O` 清状态 + 刷新页面

## 11. 三模式切换相关

> 📘 详细使用说明见 [v0.9.7-三模式切换使用指南.md](v0.9.7-三模式切换使用指南.md)

### Q1：切换模式时弹窗太烦，能关掉吗？

v0.9.6 在切换弹窗里勾选「**下次不再提示**」可按模式单独关闭。全局关闭开关计划在 v0.9.8 添加。

### Q2：并行模式 KB 文档会上传云端吗？

**不会**。云端只看到本地生成的摘要（`memory_local` ≤200 字），KB 原文不外传。详见 [v0.9.7-知识库权限与令牌.md](v0.9.7-知识库权限与令牌.md) §4。

### Q3：三种模式哪个回答质量最高？

取决于场景：KB 内的知识题 → 并行；通用题 → 在线；隐私题 → 离线。详见 [v0.9.7-三模式切换使用指南.md](v0.9.7-三模式切换使用指南.md) §8。

## 12. 知识库权限 / 令牌相关

### Q1：设为私密后，本地 AI 也读不到？

**不会**。本地 AI 对所有文档有完整读取权。`is_private` 只对**云端**生效。详见 [v0.9.7-知识库权限与令牌.md](v0.9.7-知识库权限与令牌.md) §2。

### Q2：进程重启后令牌还在吗？

**不在**。令牌仅存内存，不持久化。重启后需要重新生成。这是有意设计（P5 决策）—— 防止长期遗留令牌被滥用。

### Q3：在线模式下能引用 KB 文档吗？

能，但取决于 `kb_permission` 配置（full / search-only / disabled 三档）。详见 [v0.9.7-知识库权限与令牌.md](v0.9.7-知识库权限与令牌.md) §3。
