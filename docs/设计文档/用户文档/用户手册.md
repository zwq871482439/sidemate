## 1. Chat 对话

对话是 Sidemate 的核心功能。你可以在这里与 AI 进行交流、提问、获取建议或撰写文档。

### 1.1 基础对话

- 在底部输入框中输入你的问题或内容
- 按 **Enter** 发送消息，**Shift + Enter** 换行
- AI 流式生成回答，可随时点击**停止按钮**中断
- 离线模式下回答采用**卡片式明盒（ClearBox）**渲染：左色条区分用户（蓝）和 AI（紫），折叠统计，AgentTimeline 时间线

### 1.2 多会话管理

每个对话独立保存上下文，支持新建/切换/重命名/删除。

### 1.3 文件上传与文档引用

- 点击输入框旁附件按钮上传文件（支持 txt/md/pdf/docx 等）
- 上传后文件内容作为对话上下文，可在上下文条实时查看词元占用
- 知识库文档可引用（离线模式下「查知识库」action）

### 1.4 AI 模式切换

顶栏为**三段式按钮组**：

| 模式 | 说明 |
|------|------|
| **离线** | 纯本地 LLM（qwen3-5-4b），无需联网，隐私安全 |
| **在线** | 云端 AI（可配置 GPT/Claude/DeepSeek 等），需要 API Key |
| **并行** | 本地检索 KB + 云端通用知识各自独立回答，本地自动融合；KB 原文永不离开本机 |

切换时弹出确认对话框，含功能说明和风险告知。

### 1.5 上下文指示器

输入框上方独立 Token 上下文条，合并显示：本轮预计 + 对话历史 + 总容量 + 剩余容量。接近上限时变红提醒。

### 1.6 文档生成

在对话中，你可以让 AI 撰写文档：

1. 发起文档请求（如「帮我写一份关于 XX 的报告」）
2. AI 先生成**提纲（Markdown 格式）**，在编辑栏中可自由修改章节
3. 点击「预览」可查看渲染后的提纲样式，点「编辑」切回修改
4. 确认提纲后，AI 按你的修改生成完整文档
5. 文档可下载为 .docx 文件

> 刷新页面后提纲编辑栏会自动恢复，不会丢失。

## 2. 知识库（文库）

> 此功能需要安装「文库扩展包」。

知识库让你上传文档资料，AI 自动打标、聚类并生成洞察分析。

### 2.1 上传文档

1. 进入知识库 Tab，点击「上传文档」
2. 支持 txt/md/pdf/docx 等格式，可批量拖入
3. 上传后自动处理：切分段落 → 向量化 → AI 打标
4. 底部浮动栏显示实时处理进度（如「正在向量化 · 60%」）

### 2.2 文档管理

知识库采用**标签树 + 卡片网格**布局：

- **左侧标签树**：按 AI 聚类后的 category 分组，点击筛选对应文档。颜色与洞察环形图一一对应
- **右侧卡片网格**：文件名 + AI 标签 + 摘要 + 文件大小/词元/被搜索次数。支持卡片/列表视图切换
- **分类归并**：点击「整理」按钮，AI 自动将碎片标签归并为 3-5 个宽泛大类

### 2.3 AI 洞察仪表盘

知识库顶部为 AI 洞察卡片，包含：

- **环形图**：100px SVG donut，按分类统计文档分布
- **洞察文字**：AI 分析知识库的主题覆盖、交叉价值和补充方向
- **建议追问**：3 条紧扣文库内容的追问按钮，点击直接跳转 Chat 提问
- **三重联动**：点击环形图扇区/图例/侧栏色点可互相联动，对应分类文档排序置顶

### 2.4 批量操作

多选文档后，顶部出现批量工具栏：删除、重标、私密/公开设置、反选/清除。

### 2.5 去重检测

点击工具栏「诊断」可检测重复文档，热力图显示各文档被搜索次数。

## 3. 设置

左侧竖排导航，五组子 Tab：

### 3.1 常规

- 版本信息、开发团队
- 设备切换（CPU / GPU Vulkan）
- 模型管理（加载/卸载/删除 LLM）

### 3.2 云端 AI

配置云端 AI 服务：接口地址、API Key、模型名称。保存后可切换在线/并行模式。

### 3.3 知识库

- 扩展包安装/卸载
- 模型状态（嵌入模型 + Reranker）
- 内存占用详情

### 3.4 隐私安全

- 数据目录查看
- 会话清理、缓存管理

### 3.5 关于

- 版本号、诊断报告导出
- 环境检测报告

## 4. 隐私与令牌

### 4.1 本地优先

默认离线模式，对话数据和文档均保存在本地，不会上传到任何服务器。

### 4.2 文档私密与令牌

知识库中的文档可设为「私密」：

- **设为私密后**：云端模型将无法读取该文档内容
- **生成令牌**：在私密文档卡片上点击「令牌」按钮，可生成访问令牌分享给需要的人
- 本地模型不受私密限制

### 4.3 云端模式

仅在切换到在线/并行模式时，对话内容会发送到你配置的云端 AI 服务。数据传输和处理遵循所选云服务商的隐私政策。

## 5. 可视化报告（v0.9.6-final）

详见 [v0.9.6-可视化报告使用指南](v0.9.6-可视化报告使用指南.md)。**快速入门**：

1. 切到「文档模式」（或 Chat → Action=doc）
2. 输入：「帮我整理一份**可视化报告**：XXX 主题，包含 mermaid 流程图」
3. AI 生成 → 出现「下载 HTML 报告」按钮 → 点击下载
4. 双击 `.html` 文件，浏览器打开（完全离线）

**示例 prompt**：
- 「把'兵棋推演原理'做成可视化报告，包含六维度对比图」
- 「把我这段代码的架构做成可视化报告」
- 「对比巴巴罗萨/越战/伊拉克/俄乌四个案例，做可视化报告」

## 6. PPT 演示文稿（v0.9.6-final）

详见 [v0.9.6-PPT演示文稿使用指南](v0.9.6-PPT演示文稿使用指南.md)。**快速入门**：

1. 文档模式，输入：「帮我做一个**PPT 演示文稿**：XXX 主题，5 页左右」
2. AI 生成 `.ppt.html` → 下载
3. 浏览器打开：方向键翻页 / `F` 全屏 / `Esc` 缩略图导航
4. 导出 PDF：URL 加 `?print-pdf` + `Ctrl+P` 另存为

## 7. 上下文与工具调用（v0.9.6-final）

详见 [v0.9.6-上下文管理与工具调用](v0.9.6-上下文管理与工具调用.md)。**关键点**：

- **总轮次上限 20 轮**——AI 不会无限循环
- **本地工具不计轮次**——`read_workspace` / `calculator` 等本地操作可多次调用
- **达 20 轮自动收尾**——AI 会基于已有信息给总结，不会静默退出
- **actionBar**——AI 回答下方一键「生成可视化报告 / 生成 PPT」
- **错误友好提示**——具体原因（文件不存在 / 路径不安全等）而不是裸「操作异常」
