## 1. Chat 对话

对话是 Sidemate 的核心功能。你可以在这里与 AI 进行交流、提问、获取建议或处理文档。

### 1.1 基础对话

- 在底部输入框中输入你的问题或内容
- 按 **Enter** 发送消息
- 按 **Shift + Enter** 在输入框内换行
- AI 会根据你的输入生成回答
- 回答生成过程中，你可以点击「停止」按钮中断生成

### 1.2 多会话管理

你可以同时保持多个对话，每个对话独立保存上下文：

- **新建会话**：点击左上角的「+ 新建对话」按钮，创建一个新的空白对话
- **切换会话**：在左侧会话列表中点击对应会话即可切换
- **重命名会话**：在会话列表中右键点击会话名称，选择「重命名」
- **删除会话**：在会话列表中右键点击会话名称，选择「删除」

### 1.3 文件上传

你可以在对话中上传文件，AI 会阅读文件内容并回答相关问题：

1. 点击输入框旁边的附件按钮（回形针图标）
2. 选择要上传的文件
3. 支持的文件格式：`txt`、`md`、`pdf`、`docx` 等
4. 上传成功后，文件内容会作为对话上下文的一部分
5. 你可以针对文件内容提问，例如「请总结这个文件的主要内容」

### 1.4 文档生成

在对话过程中，你可以将 AI 的回答直接生成为文档：

1. 在 AI 回答的下方，点击「生成文档」按钮
2. 系统会将回答内容整理并保存为文档
3. 你可以在文档列表中查看和管理已生成的文档

### 1.5 在线 / 离线模式切换

Sidemate 支持本地 AI 和云端 AI 两种模式：

- 在主界面顶栏可以看到当前模式标签
- **离线模式**：使用本地 AI 模型，无需联网，隐私安全
- **在线模式**：使用云端 AI，回答质量更高，需要配置云端 API（详见 [设置 → 云端 AI 配置](#43-云端-ai-配置)）
- 点击顶栏模式标签即可切换

### 1.6 上下文指示器

在对话过程中，顶栏会显示一个环形进度条，表示当前对话的上下文使用情况：

- 环形进度正常显示时，表示上下文空间充足
- 当进度达到 **80%** 时，进度条会变为红色，提示你当前对话内容较多
- 建议在变红后新建一个会话，以保证 AI 回答的质量

> 提示：对话越长，AI 记住的内容越多，但也会消耗更多上下文空间。适时新建会话有助于保持回答质量。

## 2. 文库

> 文库功能需要先安装「文库扩展包」。如果你没有安装，左侧导航栏不会显示此入口。安装方法请参考《安装部署指南》。

文库功能可以让你上传文档资料，然后基于这些文档与 AI 进行问答。

### 2.1 上传文档

1. 点击左侧导航栏的「文库」进入文库页面
2. 点击「上传文档」按钮
3. 选择要上传的文件
4. 支持的文件格式：`txt`、`md`、`pdf`、`docx`
5. 上传后，系统会自动处理文档内容

### 2.2 AI 问答

1. 在文库页面的输入框中输入你的问题
2. AI 会基于你上传的文档内容来回答
3. 回答中会标注信息来源，方便你查阅原文

### 2.3 对比模式

如果你同时配置了云端 AI，可以使用对比模式获得更全面的分析：

1. 在文库问答界面，开启「对比模式」开关
2. 提问后，本地 AI 和云端 AI 会同时给出回答
3. 系统会自动将两个回答进行融合分析，生成综合结果
4. 你可以对比查看不同来源的回答

> 对比模式需要同时满足：已安装文库扩展包 + 已配置云端 AI。

### 2.4 文档管理

在文库页面中，你可以管理已上传的文档：

- **激活**：文档处于激活状态时，AI 问答会参考该文档内容
- **停用**：暂时不让 AI 参考该文档，但文件仍保留在文库中
- **删除**：从文库中彻底移除该文档

## 3. 纪要

> **该功能目前处于测试阶段，部分功能可能不够完善，使用体验会持续优化。**
>
> 纪要功能需要先安装「纪要扩展包」。如果你没有安装，左侧导航栏不会显示此入口。安装方法请参考《安装部署指南》。

纪要功能帮助你记录会议内容，自动将语音转为文字，并生成智能摘要。

### 3.1 录音

1. 点击左侧导航栏的「纪要」进入纪要页面
2. 点击「开始录音」按钮
3. 录音过程中，界面会显示录音时长
4. 点击「停止录音」按钮结束录音
5. 录音文件会自动保存

### 3.2 转写

1. 录音结束后，系统会自动将语音转换为文字
2. 转写需要一定时间，取决于录音长度
3. 转写完成后，你可以在界面上查看完整的文字内容
4. 你可以对转写内容进行编辑和修正

### 3.3 摘要

1. 转写完成后，点击「生成摘要」按钮
2. AI 会自动分析会议内容，生成结构化的会议纪要
3. 摘要通常包含：会议要点、关键决策、待办事项等
4. 你可以对生成的摘要进行编辑

### 3.4 导出

1. 在纪要详情页面，点击「导出」按钮
2. 选择导出格式（文档格式）
3. 纪要内容会保存为文档文件到指定位置

## 4. 设置

点击左侧导航栏的「设置」进入设置页面。

### 4.1 关于

在这里可以查看：

- Sidemate 当前版本号
- 开发团队信息
- 相关许可声明

### 4.2 扩展管理

管理已安装的扩展包：

- **查看已安装扩展**：显示当前已安装的所有扩展包及其状态
- **安装扩展**：点击「上传扩展包」按钮，选择 `.sidemate` 格式的扩展包文件进行安装
- **卸载扩展**：在已安装的扩展列表中，点击对应扩展的「卸载」按钮

目前可用的扩展包：
- AI 模型包 — 提供本地对话能力（推荐安装）
- 文库扩展包 — 提供文档知识库问答功能
- 纪要扩展包 — 提供会议录音和纪要功能

### 4.3 云端 AI 配置

配置云端 AI 服务以使用在线模式：

1. 在设置页面选择「云端 AI 配置」
2. 填写以下信息：
   - **接口地址**：AI 服务提供商给你的接口地址（以 http:// 或 https:// 开头）
   - **API Key**：你的 API 密钥，用于身份验证
   - **模型名称**：填写或选择要使用的云端模型
3. 点击「保存」使配置生效
4. 配置成功后，可以在对话页面切换到「在线」模式使用

> 请妥善保管你的 API Key，不要分享给他人。如果 API Key 泄露，请立即到服务商平台重置。

### 4.4 设备切换

你可以选择 AI 模型运行的计算设备：

- **CPU 模式**：使用处理器运行，兼容性最好，所有电脑都支持
- **GPU 模式（Vulkan）**：使用显卡加速运行，速度更快，需要显卡支持 Vulkan 技术

切换方法：在设置页面选择「设备切换」，然后选择你想要的运行设备。切换后需要重启 Sidemate 使设置生效。

> 如果不确定你的显卡是否支持 Vulkan，可以先尝试选择 GPU 模式。如果运行异常，切回 CPU 模式即可。

## 5. 隐私说明

Sidemate 非常重视你的隐私安全：

- **本地优先**：默认使用本地 AI 模型，对话数据不会离开你的电脑
- **数据留存**：所有对话记录、上传文档和录音文件都保存在本地，不会上传到任何服务器
- **云端模式**：仅在切换到在线模式时，对话内容会发送到你配置的云端 AI 服务。数据传输和处理遵循你选择的云服务商隐私政策
- **扩展包安全**：所有扩展包均在本地运行，不会向外部发送数据

详细的隐私政策请参阅独立的《隐私说明》文档。
