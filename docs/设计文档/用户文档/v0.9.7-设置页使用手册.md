## 1. 常规

日常使用的状态查看与模型、资源、数据维护。

### 1.1 外观与状态

- **深色模式**：开关切换深色/浅色主题。
- **当前模型**：显示已加载的 LLM 名称（如「未加载」则需在下方加载）。
- **最大输入**：模型单次能接收的最大输入 token 数。
- **最大输出**：模型单次能生成的最大 token 数。
- **知识库**：知识库模型是否就绪。

### 1.2 模型与资源

**LLM 管理（下拉 + 切换 + 卸载）：**

- 下拉框列出所有已安装的 Qwen3.5 档位（0.8B / 2B / 4B），选择后点「切换」加载。
- llama.cpp 底座为「一进程一模型」，切换模型 = 重启 `llama-server` 加载新 GGUF，切换时会有短暂等待。
- 可对已加载模型执行卸载。

**自动加载：**

- 「启动时自动加载模型（推荐）」勾选后，启动器在启动阶段自动加载 LLM，省去首次问答的等待。

**Reranker 常驻策略：**

- 「Reranker 常驻内存」勾选后，知识库重排序模型常驻不卸载。
- 未勾选时，可设置「闲置 N 分钟后自动卸载」（节省内存，下次使用知识库时重新加载）。

**资源占用：**

- 显示系统内存、可用内存，以及各模块（LLM / Embedder / Reranker）的内存占用。

### 1.3 数据维护

**缓存管理：**

- 查看/清理上传的文件缓存等。
- 支持「刷新」「批量删除」「清空全部」，带分页。

**备份与恢复：**

- 「导出备份」：导出所有对话、设置和知识库元数据到 ZIP 文件。
- 「恢复」：选择 ZIP 文件恢复。

### 1.4 反馈

- 问题反馈入口（如暂不可用会标注），以及反馈邮箱 `sidemate@deskware.cn`。

## 2. 云端 AI

配置和使用云端模型（OpenAI 兼容 API）的相关设置。用户自行配置 API，不绑定具体厂商。

### 2.1 云端 AI 模型配置

| 字段 | 说明 |
|------|------|
| **API 地址** | 云端服务的 Base URL（OpenAI 兼容格式） |
| **API Key** | 访问密钥（可点「显示」查看明文） |
| **模型名称** | 要调用的模型标识 |
| **模型能力** | 输入模型名称后自动匹配能力（输入/输出上限等） |

操作：「测试连接」验证配置是否可用 → 「保存配置」。

### 2.2 云端 AI 权限与数据策略

**数据发送策略**（控制发送到云端的对话内容范围）：

- **完整发送（默认）**：发送完整对话历史。
- **仅发送当前消息**：只发本轮问题。
- **精简历史**：仅保留最近 N 轮（可填 1–50）。

> 引用的知识库文档内容始终会随对话发送（用于让云端模型看到资料）。

**工具权限**：控制云端 Agent 可使用的工具（联网搜索、读网页、查知识库、内网访问等），逐项开关。

### 2.3 用量统计

- 真实 token 计数，按 7 天小时维度统计。
- 柱状图分段显示（输入 / 输出 / 推理），按模型进度条同样分段。
- 汇总行显示输入/输出/推理总量。

## 3. 知识库

知识库功能的状态、引擎、审计与重置。

> 前提：已在「模型下载」安装知识库模型（bge-m3 + reranker）。

### 3.1 文档统计

| 指标 | 说明 |
|------|------|
| 文档总数 | 已导入的全部文档数 |
| 就绪文档 | 处理完成可检索的文档数 |
| 处理中文档 | 正在分块/向量化的文档数 |
| 失败文档 | 处理失败的文档数 |
| 磁盘占用 | 知识库数据占用的磁盘空间 |

点「刷新统计」更新。

### 3.2 问答引擎（kb_ai_mode）

选择知识库问答使用的 AI 引擎，**独立于全局的离线/在线模式**：

- **本地 LLM（隐私优先）**：用本地 Qwen3.5 回答，数据不出本机。
- **云端 LLM（质量优先）**：用云端模型回答，质量更高，检索片段会发送到云端。

> 例如：你可以全局保持「离线」，但知识库问答选「云端」——这样普通对话走本地（省 token、隐私），知识库问答走云端（质量好）。

### 3.3 审计日志管理

每次检索知识库时会记录访问明细（时间 / 访问者 / 查询词 / 命中片段），每篇文档最多保留 200 条。

| 指标 | 说明 |
|------|------|
| 日志条数 | 累计审计记录数 |
| 涉及文档 | 被检索过的文档数 |
| 磁盘占用 | 审计日志占用空间 |

操作：「刷新」更新统计；「清空全部审计日志」清除所有记录。

### 3.4 重置知识库

- 清空所有已导入的文档、文本片段和向量索引。
- **此操作不可撤销**，重置后需重新导入文档。
- 仅清除数据，知识库功能本身（模型、引擎）不受影响。

## 4. 模型下载

管理所有模型的下载、安装与卸载。v0.9.7 通过 ModelScope/HuggingFace 下载 GGUF 模型文件。

### 4.1 下载设置

**下载源选择：**

| 源 | 说明 |
|----|------|
| **魔搭 ModelScope（国内推荐，速度快）** | 默认，国内网络稳定无需代理 |
| **HuggingFace（国际源，需代理）** | 备选，国内需代理 |

支持断点续传，中断后重新点下载会接着继续。同一时刻只允许一个下载任务。

### 4.2 下载进度条

下载时页面顶部出现进度卡片：

- 进度条（百分比）。
- 实时文字：已下载/总大小 · 速度/s · 剩余时间。
- 「取消」按钮中断当前下载。

> 页面刷新后会自动恢复当前下载任务的进度条显示。

### 4.3 对话模型（LLM）三档卡片

列出三档 Qwen3.5（Q4_K_M 量化），每张卡片显示名称、大小、最低内存要求：

| 模型 | 大小 | 最低内存 | 推荐显存 |
|------|------|----------|----------|
| 通义千问 3.5 (0.8B) | 约 0.5GB | 2GB | — |
| 通义千问 3.5 (2B) | 约 1.2GB | 4GB | 2GB |
| 通义千问 3.5 (4B) | 约 2.5GB | 8GB | 6GB |

每张卡片的操作：

- **未安装**：「下载」按钮。
- **已安装**：「重新下载」+ 「删除」按钮（删除释放磁盘，保留元数据，可再次下载恢复）。

### 4.4 知识库模型组合卡片

一张卡片管理知识库所需的两个模型：

| 组件 | 角色 | 大小 |
|------|------|------|
| bge-m3 | 向量化（embedding），支持语义+关键词检索 | 约 2.3GB |
| bge-reranker-v2-m3 | 重排序（reranker），精排搜索结果 | 约 2.2GB |

合计约 4.5GB。下载会逐个获取 embedding 和 reranker 的权重与配置文件，进度按累计字节计算。

卡片操作：

- **未安装**：「下载知识库模型」按钮（一次下载两个组件）。
- **部分安装**：提示缺失的组件（如「⚠️ 向量化模型缺失」）。
- **已安装**：「重新下载」+「卸载」按钮。

下载完成后自动注册扩展并加载模型，即可使用知识库功能。

### 4.5 从本地安装

选择 `.sidemate` 离线包安装，自动识别是 LLM 模型还是知识库模型。适用于：

- 离线环境（无法联网下载时用预先准备好的安装包）。
- 分发模型给他人。

点「选择 .sidemate 文件」即可。

## 5. 隐私安全

数据存储位置与隐私声明的查看入口。

### 5.1 数据存储位置

- **存储位置**：本地数据目录的绝对路径。
- **数据占用**：本地数据的磁盘占用大小。

> 对话、文档、模型、设置等所有数据均存储在本地。仅在云端 AI 模式下，对话内容会发送到你配置的云端 API。

### 5.2 隐私声明

要点：

- **数据本地存储**：对话、文档、设置默认 100% 存储在本地。
- **云端 AI 通信**：使用云端/并行模式时，对话内容发送到你配置的云端 API，数据不经过第三方。
- **网页搜索**：Agent 启用联网搜索时，会向搜索引擎发送查询关键词。
- **知识库权限保护**：文档受令牌授权保护。
- **随时可清除**：删除安装目录即可彻底卸载。

点「查看完整隐私声明」展开详情。

### 5.3 开发调试

- 「允许第三方页面访问本机 API」（CORS 开关）：默认关闭（推荐）。开启后取消本机 API 的来源限制，便于用第三方前端工具调试，存在本机恶意网页静默读取数据的风险，**调试完成后请关闭，修改后需重启服务生效**。

### 5.4 数据导出

- 「导出备份」：导出所有对话数据为可读格式。
- 「导出诊断报告」：生成环境与运行状态诊断信息。

## 6. 关于

版本信息、运行状态与团队。

### 6.1 程序版本

- 显示桌伴 Sidemate 版本号（v0.9.7）。
- 「重新查看新手指引」按钮：重置 Onboarding 状态并重新加载页面，重看交互式引导。

### 6.2 运行状态

**组件状态**：各组件（如 LLM 引擎、知识库模型）的就绪状态，带状态点。

**系统资源：**

| 指标 | 说明 |
|------|------|
| 总内存 | 系统物理内存总量 |
| 显存 | GPU 显存信息 |
| GPU | GPU 型号 |

**环境信息：**

| 指标 | 说明 |
|------|------|
| Python | 嵌入式 Python 版本 |
| 操作系统 | Windows 版本 |

「导出诊断报告」生成完整诊断信息，用于问题排查。

### 6.3 产品描述

桌伴 Sidemate 是一款本地优先的 AI 办公助手：所有数据存储在你的电脑上，云端模式下对话仅发送到你配置的 API；支持离线智能对话、文档生成、知识库问答。

### 6.4 团队信息

项目负责人、AI 架构师、AI 工程师、AI 产品经理、AI QA、AI 开发助手。

### 6.5 法律信息

开源协议（Apache-2.0 + 补充说明）与第三方许可声明。
