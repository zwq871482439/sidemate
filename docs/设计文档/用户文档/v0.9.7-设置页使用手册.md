# 设置页使用手册

> ⚠️ **本文档描述 v0.9.7 待发版功能**（已实现于 main 分支，尚未发版；当前 `config.py` 仍为 0.9.6）。发版前请同步验证代码与本文。
>
> 版本：v0.9.7 | 文件：`server/static/js/settings.js` / `server/index.html`（#settingsNav）
> 适用人群：需要配置云端 / 调整模型 / 管理扩展 / 查看诊断的用户

---

## 1. 概览

Sidemate v0.9.6 起设置页采用**左侧竖排导航 + 右侧内容面板**布局，五组子 Tab：

| 子 Tab | 主要职责 | 何时访问 |
|--------|----------|----------|
| **常规** | 模型加载 / 设备切换 / 备份 | 切换 CPU/GPU；加载/卸载 LLM；数据备份 |
| **云端 AI** | API Key / 模型 / 用量 | 首次配置云端模型；查看用量统计 |
| **知识库** | 扩展包 / 模型状态 / 重置 | 安装文库扩展包；查看嵌入/Reranker 状态 |
| **隐私安全** | 数据目录 / 隐私声明 | 查看本地数据位置；阅读隐私细节 |
| **关于** | 版本 / 诊断 / 重启引导 | 查看版本号；导出诊断报告；重置新手指引 |

切换逻辑：`switchSettingsTab(tabId, navEl)`，URL 状态保留在 tab ID 维度。

## 2. 常规 Tab

### 2.1 顶部：程序版本 + KB 状态

```
┌─ 程序版本 ───────────────────┐
│ Sidemate v0.9.7              │
│ 重新查看新手指引              │ ← 点击 → resetOnboarding()
├─ 状态 ──────────────────────┤
│ 知识库        ● 已安装        │
│ 云端 API      ● 已配置        │
│ 设备          GPU (Vulkan)   │
└──────────────────────────────┘
```

### 2.2 模型管理

- **当前模型**：显示 LLM 名称 + 状态（loaded / unloaded / loading）
- **加载 / 卸载模型**：
  - 点击「加载」→ 调用 `/api/model/load`，按钮显示「加载中...」
  - 加载完成 → 按钮变为「卸载」
  - 卸载 → 释放显存，节省内存
- **删除模型**（危险）：
  - 红色「删除」按钮
  - 弹窗确认「删除后无法恢复，需要重新下载」
  - 删除后设置页模型列表移除该项

### 2.3 推理设备切换

| 设备 | 速度 | 适用 |
|------|------|------|
| **CPU** | 3-8 字/秒 | 通用；无 GPU 时 |
| **GPU (Vulkan)** | 10-30 字/秒 | 推荐；NVIDIA / AMD GPU |
| **GPU (CUDA)** | 30-50 字/秒 | 仅 NVIDIA GPU + CUDA 驱动 |

切换时弹窗：
- 显示预估速度
- 切换后模型需重新加载（几秒到几分钟）

### 2.4 自动卸载（节省内存）

设置项：

- **Reranker 自动卸载**：空闲 N 分钟后自动卸载 Reranker
- **Whisper 自动卸载**：录音完成后立即卸载
- **嵌入模型驻留**：是否常驻嵌入模型（影响 KB 检索速度）

### 2.5 备份与恢复

- **导出全部数据**：导出对话 / 设置 / KB 元数据为 ZIP
- **导入备份**：从 ZIP 恢复（覆盖当前数据）
- **清空数据**：危险操作，需二次确认

```
│ [ 测 试 连 接 ]  [ 保 存 ]          │
└─────────────────────────────────────┘
```

### 3.2 验证流程

保存前自动测试连接：
- 发送 1 个最小请求到云端
- 验证 API Key + 模型名是否正确
- 失败时显示具体错误（401 / 404 / 网络超时等）

### 3.3 KB 权限

控制发送到云端的 KB 内容范围（详见 `v0.9.7-知识库权限与令牌.md`）：

| 选项 | 行为 |
|------|------|
| **full** | 公开文档全文注入云端 prompt |
| **search-only** | 仅发送检索关键词 |
| **disabled** | 云端模式完全不可访问 KB |

切换时弹窗提示：
- 「从 full 切到 search-only 可能降低回答质量」
- 「从 disabled 切到 full 会暴露 KB 全文给云端」

### 4.1 扩展包管理

```
┌─ 扩展包 ─────────────────────────┐
│ 知识库扩展      v1.2.0  ●已装    │
│ [卸 载]                          │
│                                   │
│ ─── 上传新扩展包 ───              │
│ ┌─────────────────────────────┐   │
│ │ 拖拽 .sidemate 文件到此处    │   │
│ │ 或 [点击选择文件]            │   │
│ └─────────────────────────────┘   │
└───────────────────────────────────┘
```

### 4.2 模型状态

| 组件 | 状态 | 内存占用 |
|------|------|----------|
| **嵌入模型**（bge-m3） | ●已加载 | 1.2 GB |
| **Reranker** | ●空闲待命 | 0.8 GB |
| **Whisper** | ○未安装 | -- |

可单独加载/卸载每个组件。

### 4.3 知识库统计

- 文档总数 / 总 chunk 数 / 总词元
- 索引文件大小
- 检索平均响应时间

### 4.4 重置知识库

- 红色按钮「重置知识库」
- 弹窗：「仅清除导入的数据，知识库功能本身不受影响」
- 确认后删除所有文档 / chunk / 元数据

### 4.5 检索参数（高级）

| 参数 | 默认 | 说明 |
|------|------|------|
| `kb_search_top_k_local` | 3 | 本地模式 top-k |
| `kb_search_top_k_cloud` | 5 | 云端模式 top-k |
| `kb_vector_score_threshold` | 0.35 | 向量相似度门槛 |
| `kb_context_max_chars_local` | 5000 | 本地注入字符上限 |
| `kb_context_max_chars_cloud` | 12000 | 云端注入字符上限 |

## 5. 隐私安全 Tab

### 5.1 数据存放位置

```
┌─ 数据目录 ───────────────────────┐
│ 安装目录                          │
│  └─ data/                         │
│     ├─ chats/      对话历史       │
│     ├─ kb/         KB 索引/文档   │
│     ├─ kbsession/  KB 会话        │
│     ├─ recordings/ 录音文件       │
│     ├─ logs/       日志           │
│     └─ settings.json  配置文件    │
└───────────────────────────────────┘
```

### 5.2 数据管理

- **打开数据目录**：调用系统资源管理器
- **清理缓存**：删除临时上传文件
- **导出对话**：批量导出为 JSON
- **清空所有对话**：危险操作

### 5.3 隐私声明

简版：
- 离线模式：数据全在本地
- 在线模式：对话内容发送到配置云端
- 知识库：受三级令牌保护

点「查看完整隐私声明」展开 `v0.9.7-知识库权限与令牌.md` 的内容。

### 5.4 高级开关

- **允许第三方访问（CORS）**：默认关闭；启用后外部网页可调用本地 API
- **禁用网络遥测**：默认关闭；启用后停止任何匿名使用数据上报

## 8. 常见问题

### Q1：模型一直显示「loading」？
检查：
- 控制台日志（`data/logs/`）
- 模型文件是否完整
- 显存是否充足（GPU 模式）
- 重新加载 / 重启 Sidemate

### Q2：云端 API Key 保存后测试失败？
- 检查 API Key 是否正确
- 检查 Base URL 是否带 `/v1` 后缀
- 检查模型名是否拼写正确
- 检查网络 / 代理

### Q3：知识库扩展包安装失败？
- 确认 `.sidemate` 文件未损坏（> 0 字节）
- 确认磁盘空间充足
- 确认扩展包 SHA256 校验通过
- 查看错误日志

### Q4：想清空 KB 但保留扩展包？
使用「重置知识库」按钮（4.4 节）—— 仅清除数据，不卸载扩展。

### Q5：诊断报告里有什么？
- 程序版本 + 依赖版本
- 硬件信息 + 资源占用
- 当前配置（脱敏）
- 最近错误日志（最近 100 条）

不含对话内容 / 文档内容 / API Key。

### Q6：能改设置页 Tab 顺序吗？
不能（v0.9.7）。v0.9.8 计划支持自定义。

### Q7：模式确认弹窗太烦，能关掉吗？
v0.9.7：在切换弹窗里勾选「下次不再提示」可按模式单独关闭。
全局关闭开关 v0.9.8 添加。

### Q8：重置引导会丢失数据吗？
**不会**。`resetOnboarding()` 仅清 `localStorage` 中的 `sidemate_welcomed` / `sidemate_toured` 标记 + 重新显示欢迎弹窗。对话、KB、设置**完全保留**。
