# 隐私与安全说明

> 最后更新：v0.9.7（当前发版）
>
> v0.9.7 底座为 **llama.cpp（llama-server.exe）**，本地模型为 **Qwen3.5 三档**，知识库模型为 **bge-m3 + bge-reranker-v2-m3**。核心代码采用 **Apache-2.0** 协议开源。

---

## 核心原则：本地优先

**桌伴 Sidemate 采用「本地优先」架构，用户数据默认不出本机。**

- 对话、文档、知识库、模型、设置全部存储在本地 `data/` 目录
- 离线模式下，所有 AI 计算在本地完成，不与任何外部服务器通信
- 仅在用户主动启用「在线 / 并行模式」或选择「KB 问答引擎 = cloud」时，才将必要的提问内容发送给云端
- 云端 API Key 仅本地存储，用于与用户自己配置的云端服务通信

---

## 数据存储位置

所有数据均保存在本地安装目录下的 `data/` 文件夹中：

| 数据类型 | 存放位置 | 说明 |
|---------|---------|------|
| 对话历史 | `data/chats/` | JSON 格式，含消息内容与元数据 |
| 上传文档 / 知识库 | `data/kb/` | 分块文本 + 向量索引（bge-m3 1024 维）+ 标签摘要 |
| KB 会话 | `data/kbsession/` | 知识库 Tab 的独立对话记录 |
| 本地模型 | `models/` | Qwen3.5 LLM + bge-m3 / bge-reranker-v2-m3 |
| 配置信息 | `server/settings.json` | 含云端 API Key（base64 编码） |
| 日志 | `data/logs/` | llama-server / Python 后端 / launcher 日志，30 天自动清理 |

> 说明：录音纪要（Whisper）功能已在 v0.9.7 前归档，不再使用，相关历史文件如存在则保留在 `data/` 对应目录。

## 三种模式的数据流向

### 离线模式（默认，最严格）

**所有计算在本地完成，不发送任何数据到外部。**

- 本地 Qwen3.5（通过 llama-server）处理所有对话
- 知识库检索在本地向量库中执行（bge-m3 + reranker）
- 文档 / 报告生成在本地完成
- **零外部通信**（除用户主动发起的模型下载）

### 在线模式

切换到在线模式后，**用户的问题与对话历史**会发送给云端模型：

| 场景 | 发送到云端 | 不发送 |
|------|-----------|--------|
| Chat 对话 | 用户消息 + 对话历史 | 本地文件内容（除非用户主动粘贴） |
| Chat + KB 权限开启 | 用户消息 + 历史 + **本地检索结果段落** | 知识库原始文档全文 |
| 网页搜索工具 | 搜索查询词 | 本地数据 |

> 关键：在线模式发送的是「提问内容」和「检索到的少量段落」，**不是整篇文档**。可通过「设置 → 知识库」的 KB 权限进一步收紧。

### 并行模式

本地与云端同时作答，融合后呈现：

- **云端只看到**：用户问题 + 检索筛选后的少量段落（作为上下文）
- **云端看不到**：本地 AI 的回答、知识库原始文档全文
- 本地与云端记忆独立维护（`memory_local` / `memory_cloud`），互不污染

## KB 问答引擎的隐私边界（kb_ai_mode）

v0.9.7 起知识库问答引擎可选 local / cloud，两者的隐私边界不同：

| 模式 | 回答用谁 | 发送到云端的内容 | 适合 |
|------|----------|------------------|------|
| **local**（默认） | 本地 Qwen3.5 | **无**，全本地 | 隐私敏感、离线环境 |
| **cloud** | 云端模型 | KB 检索到的**少量段落** + 用户问题 | 追求回答质量、KB 内容可对外 |

**重要**：即便选 cloud，也只发送检索后筛选出的相关段落，**原始文档全文从不上传**。如需完全不发，保持 local 即可。

---

## 云端 API Key 安全

- API Key 以 **base64 编码**存储在 `settings.json` 中（防肉眼直接读取，非强加密）
- **不会**包含在安装包中
- 覆盖安装 / 升级时不会覆盖用户已有配置
- API Key 仅在与用户自己配置的云端服务通信时使用
- 不记录用户的 prompt 和模型输出到任何外部服务

## 模型下载的网络通信

v0.9.7 在「设置 → 模型下载」页下载模型时，会与以下源之一通信：

| 下载源 | 用途 | 何时连接 |
|--------|------|----------|
| **ModelScope（魔搭）** | 国内默认下载源（速度快） | 用户点击下载时 |
| **HuggingFace** | 海外备选源 | 用户切换到此源时 |

通信内容仅为模型文件下载请求。**下载完成后即断开**，日常使用（离线模式）不与这些源通信。

> 从本地安装 `.sidemate` 包时：安装前会做 SHA256 完整性校验，确保包未被篡改。

## 开源协议

Sidemate 核心代码采用 **Apache-2.0** 协议开源：

- 源代码托管在 GitHub 仓库
- **1.0.0 正式版发布后公开**仓库
- Apache-2.0 允许商业使用、修改、分发，要求保留版权与许可声明

模型文件（Qwen3.5、bge-m3、bge-reranker-v2-m3）遵循各自模型的原作者许可协议。

## 数据导出与删除

| 操作 | 方法 |
|------|------|
| 导出对话 | Chat Tab → 菜单 → 导出 |
| 删除单条对话 | Chat Tab → 菜单 → 删除 |
| 清空知识库 | 文库 Tab → 管理 → 清空 |
| 备份全部数据 | 复制 `data/` 文件夹 |
| 卸载（保留数据） | 控制面板卸载，`data/` 默认保留 |
| 彻底清除 | 卸载后手动删除安装目录 |

## 网络通信总览

| 连接 | 方向 | 用途 | 可关闭 |
|------|------|------|--------|
| llama-server localhost:11434 | 本地 | 本地 LLM 推理 | ❌（离线模式必需） |
| Python 后端 localhost:8976 | 本地 | Web 服务 | ❌ |
| 云端 API（可选） | 出站 | 在线 / 并行模式、KB cloud 引擎 | ✅ 不配置即不连接 |
| 网页搜索（可选） | 出站 | Agent 搜索工具 | ✅ 不使用即不连接 |
| ModelScope / HuggingFace（可选） | 出站 | 模型下载 | ✅ 仅下载时连接 |

> **结论**：在离线模式 + 不下载模型时，Sidemate 可完全断网运行，零外部通信。
