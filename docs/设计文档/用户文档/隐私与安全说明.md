## 核心原则

**桌伴 Sidemate 采用「本地优先」架构设计，用户数据默认不出本机。**

## 数据存放位置

所有数据均保存在本地安装目录下的 `data/` 文件夹中：

| 数据类型 | 存放位置 | 说明 |
|---------|---------|------|
| 对话历史 | `data/chats/` | JSON 格式，包含消息内容和元数据 |
| 知识库文档 | `data/kb/` | 分块文本 + 向量索引 + 标签 |
| KB 会话 | `data/kbsession/` | 文库 Tab 的独立对话记录 |
| 录音文件 | `data/recordings/` | WebM 音频 + 转写文本 |
| 配置信息 | `server/settings.json` | 含云端 API Key（base64 编码） |
| 日志 | `data/logs/` | 30 天自动清理 |

## 离线模式（默认）

在离线模式下，**所有 AI 计算均在本地完成**：

- 本地 LLM（Ollama + Qwen）处理所有对话请求
- 知识库检索在本地 FAISS 向量库中执行
- 文档生成在本地完成
- **不发送任何数据到外部服务器**

## 在线模式

切换到在线模式后，以下数据会发送到云端：

| 场景 | 发送内容 | 不发送的内容 |
|------|---------|-------------|
| **Chat 对话** | 用户消息 + 对话历史 | 本地文件内容（除非用户主动粘贴） |
| **Chat 在线 + KB** | 用户消息 + 对话历史 + **本地知识库检索结果** | 知识库原始文档全文 |
| **文库 Tab** | 仅用户问题 + 文库会话历史 | **不发送本地数据** |
| **对比模式** | 用户问题 + 云端自己的历史回答 | 本地回答内容不发给云端 |

### 关键隔离设计

1. **文库 Tab 云端隔离**：即使开启在线模式，文库 Tab 的对话不会将本地知识库数据发送给云端。云端模型只能看到用户的问题和自己之前的回答。

2. **对比模式云端隔离**：对比模式中，云端 AI 只能看到用户的提问和云端自己的历史回答。本地 AI 的回答、知识库内容均不会暴露给云端。

3. **Chat 在线模式的 KB 搜索**：当在线模式 + 知识库权限开启时，Chat 对话会搜索本地知识库并将检索结果作为上下文发给云端。用户可通过设置中的「知识库权限」控制此行为。

## 云端 API Key 安全

- API Key 以 base64 编码存储在 `settings.json` 中
- **不会**包含在安装包中（ISS 只打包 .py 文件）
- 覆盖安装时不会覆盖用户配置
- API Key 仅在与云端服务通信时使用

## 扩展包安全

- 扩展包（.sidemate 文件）通过数字签名验证完整性
- 安装前会校验包内 manifest 与签名一致性
- 扩展包内容仅限：模型文件 + Python wheels + 配置文件

## 数据导出与删除

| 操作 | 方法 |
|------|------|
| 导出对话 | Chat Tab → 菜单 → 导出 |
| 删除单条对话 | Chat Tab → 菜单 → 删除 |
| 清空知识库 | 文库 Tab → 管理 → 清空 |
| 卸载清理 | 控制面板 → 卸载（保留用户数据） |
| 完全清除 | 卸载后手动删除安装目录 |

## 网络通信

| 连接 | 方向 | 用途 | 可关闭 |
|------|------|------|--------|
| Ollama localhost | 本地 | 本地 AI 推理 | ❌ |
| FastAPI localhost | 本地 | Web 服务 | ❌ |
| 云端 API（可选） | 出站 | 在线 AI 模式 | ✅ 不配置即不连接 |
| Bing 搜索（可选） | 出站 | Agent 搜索工具 | ✅ 不使用即不连接 |

## 模型安全

- 本地模型（Qwen）运行在 Ollama 沙箱中
- 模型文件存储在 `models/` 目录，不涉及网络传输
- 输出经过 `response_filter.py` 过滤，移除敏感信息残留
- 不记录用户的 prompt 和模型输出到任何外部服务
