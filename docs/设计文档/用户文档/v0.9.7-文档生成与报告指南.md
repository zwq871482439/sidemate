# 文档生成与报告指南

> 版本：v0.9.7 | 适用人群：需要让 AI 生成 Word 文档 / 可视化报告 / PPT 演示的用户
>
> v0.9.7 支持三种产物格式：`.docx`（Word 文档）/ `.html`（可视化报告）/ `.ppt.html`（PPT 演示）。

---

## 1. 文档生成流程

### 1.1 两阶段生成

Sidemate 文档生成采用**提纲确认 → 正式生成**两阶段流程：

```
1. 你发起文档请求
       ↓
2. AI 生成提纲（Markdown 格式）  ← 第一阶段
       ↓
3. 你在编辑栏修改/确认提纲       ← 可改章节、点「预览」看渲染
       ↓
4. 确认提纲
       ↓
5. AI 按提纲生成完整文档          ← 第二阶段（两阶段生成）
       ↓
6. 生成可下载产物
```

### 1.2 提纲编辑器

- AI 先生成**提纲**（Markdown 格式，按 `#` / `##` / `###` 标题层级）
- 编辑栏可自由修改章节、增删小节
- 点击「预览」查看渲染后的提纲样式，点「编辑」切回修改
- **页面刷新后提纲编辑栏自动恢复**，不会丢失

### 1.3 确认后生成

点击「确认」后，AI 按你修改后的提纲生成完整文档。生成过程流式输出，可实时查看进度。

## 2. 三种产物格式

| 格式 | 后缀 | 适合场景 | 打开方式 |
|------|------|----------|----------|
| **Word 文档** | `.docx` | 纯文字报告、正式文档 | Word / WPS |
| **可视化报告** | `.html` | 多步骤/对比/架构类需要图表说明 | 任意浏览器 |
| **PPT 演示** | `.ppt.html` | 演示、汇报、教学 | 任意浏览器 |

### 2.1 Word 文档（.docx）

- 传统 Word 格式，适合纯文字报告
- 由 `write_workspace` 写 `.md` 文件 + `set_doc_status` 生成 `.docx`
- 标题层级（`#` → 一级标题，`##` → 二级标题）自动映射 Word 标题样式

### 2.2 可视化报告（.html）

- **单文件自包含 HTML**：内联 mermaid.js + marked.js 引擎，浏览器打开即可看完整图文排版
- **无需联网**：不依赖外网，下载后双击即可查看
- **支持图表**：mermaid 流程图 / 思维导图 / 时序图 / 甘特图 / 饼图，可缩放拖拽
- **专业排版**：暖灰背景 + 衬线标题 + 卡片/网格/统计/标签等组件库

> 文件名约定 `<主题>.html`。

### 2.3 PPT 演示（.ppt.html）

- **单文件自包含 HTML**：浏览器翻页演示，**不是标准 reveal.js 主题包**
- **多 section 结构**：每个 `<section>` 是一张幻灯片
- **浏览器操作**：方向键翻页、`F` 全屏、`Esc` 缩略图导航
- 文件名约定 `<主题>.ppt.html`（两个点）——系统据此识别走 PPT 渲染路径

> 下载按钮显示为「下载 HTML 报告 `<主题>`PPT.html」（更易理解），实际文件名保留 `.ppt.html` 后缀。

## 3. 可视化报告组件

可视化报告内置组件库，AI 写 HTML 时直接用 class 即可获得专业排版：

### 3.1 基础组件

| 组件 | 用途 | 示例 |
|------|------|------|
| 卡片 `.card` | 信息块 | 配 `.card-title` 标题 |
| 网格 `.grid-2` / `.grid-3` | 多栏布局 | 自动响应式（手机单列） |
| 提示框 `.callout` | 强调提示 | 配 `.warn` / `.danger` / `.tip` |
| 统计数字 `.stat-num` | 大数字展示 | 配 `.pos`（绿）/`.neg`（红）/`.accent`（橙） |
| 标签 `.badge` | 状态标记 | 配 `.green` / `.orange` / `.red` |
| 表格 `<table>` | 数据对比 | 自带斑马纹 + hover 高亮 |

### 3.2 mermaid 图表

所有 mermaid 图自动渲染为 SVG，并支持：

- **滚轮缩放**（0.3x ~ 3x）
- **鼠标拖拽**移动
- **双击复位**（回到 100%）
- **工具栏**：放大/缩小/百分比/复位

支持的图类型：`flowchart`（流程图）/ `sequenceDiagram`（时序图）/ `mindmap`（思维导图）/ `gantt`（甘特图）/ `pie`（饼图）。

> mermaid 渲染失败时显示带源码的友好错误框，可让 AI 重新生成。

## 4. PPT 操作

### 4.1 基本操作

浏览器打开 `.ppt.html` 后：

| 操作 | 按键 |
|------|------|
| 下一张 / 下一个子页 | `→` / `Space` |
| 上一张 / 上一个子页 | `←` |
| 全屏 / 退出全屏 | `F` |
| 缩略图导航 | `Esc` |
| 黑屏暂停 | `B` |
| 触屏滑动 | 左右滑 |

### 4.2 浏览器打开

下载 `.ppt.html` 文件后，**双击用浏览器打开**即可演示。完全离线，不需要 Sidemate 运行。

### 4.3 垂直嵌套（子页）

外层 `<section>` 包内层 `<section>` 做「点开看更多」的子页：

```html
<section>
  <h2>总览</h2>
  <section><h3>详情 1</h3></section>
  <section><h3>详情 2</h3></section>
</section>
```

按方向键下展开子页，按上收起。

### 4.4 导出 PDF

1. 浏览器打开 PPT 文件
2. URL 后加 `?print-pdf`（如 `file:///C:/path/file.ppt.html?print-pdf`）
3. `Ctrl + P` 打印 → 目标选「另存为 PDF」
4. **关键**：边距选「无」，勾选「背景图形」——否则 PDF 缺背景

## 5. 触发方式

### 5.1 自然语言触发

在文档模式（Doc Mode）或 Chat → Action=doc 模式下，直接说：

| 你说 | AI 生成 |
|------|---------|
| 「写一份关于 XX 的**文档**」 | `.docx`（Word 文档） |
| 「生成一份**可视化报告**」 | `.html`（可视化报告） |
| 「做个 **PPT**」「做一份**演示文稿**」 | `.ppt.html`（PPT 演示） |

AI 会自动：
1. 生成提纲（你确认/修改）
2. 用 `write_workspace` 写入对应格式文件
3. 用 `set_doc_status` 生成最终可下载产物
4. 出现「下载」按钮

### 5.2 示例 prompt

**Word 文档**：
> 「写一份关于团队协作规范的文档，包含沟通机制、会议制度、文档管理三部分」

**可视化报告**：
> 「把'兵棋推演原理'做成可视化报告，包含六维度对比图和 mermaid 流程图」
> 「对比巴巴罗萨/越战/伊拉克/俄乌四个案例，做可视化报告」

**PPT 演示**：
> 「帮我做一个 PPT 演示文稿：季度项目汇报，5 页左右」
> 「把这份架构设计做成 PPT，用于团队宣讲」

### 5.3 actionBar 一键转换

AI 回答下方有 actionBar，支持一键把当前回答转成报告：

- **生成可视化报告** —— 把当前回答转成 HTML 报告
- **生成 PPT** —— 把当前回答转成演示文稿

> 省时技巧：直接点 actionBar 转换，不用让 AI 再读一遍上下文。

## 6. 模式与文档生成

文档生成在三种 AI 模式下均可用，但能力略有差异：

| 模式 | 文档生成 | 特点 |
|------|----------|------|
| 离线 | 支持 | 基于本地 KB + 本地 LLM，隐私安全 |
| 在线 | 支持 | Agent 可联网搜资料再写，内容更丰富 |
| 并行 | 支持 | 本地 KB 深度 + 云端广度融合后生成 |

在线模式下 Agent 写文档的典型流程：
1. `search_kb` 查本地知识库
2. `search_web` 补充互联网资料
3. `fetch_url` 读关键网页正文
4. `write_workspace` 写文档
5. `set_doc_status` 生成产物

## 7. 常见问题

### Q1：下载按钮不出现？
AI 没调 `set_doc_status`。补一句「生成可下载的文档」即可。

### Q2：可视化报告打开后图表不显示？
mermaid 源码语法有错。查看是否显示带源码的错误框，让 AI 重写该图。

### Q3：PPT 文件很大？
约 3.5 MB（含 mermaid + 渲染引擎内联），gzip 后约 1 MB，属正常。

### Q4：PPT 翻页乱跳？
每个 `<section>` 不要嵌套太深（建议 ≤ 2 层），否则方向键行为混乱。

### Q5：提纲刷新后丢了？
不会。提纲编辑栏刷新页面后自动恢复。如果确认后进入生成阶段，提纲已转为正式文档。

### Q6：三种格式能互相转换吗？
可以。已有 `.md` 文件可让 AI 转成可视化报告或 PPT； actionBar 也支持把 Chat 回答一键转格式。
