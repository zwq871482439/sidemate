# Sidemate（桌伴）安装部署指南

> 版本：v0.9.7（当前发版） | 适用系统：Windows 10/11 64-bit
>
> v0.9.7 起：AI 底座由 Ollama 替换为 **llama.cpp（llama-server.exe）**，本地模型改为 **Qwen3.5 三档**，知识库模型改为 **bge-m3 + bge-reranker-v2-m3**，模型下载统一在「设置 → 模型下载」页完成。

---

## 1. 系统要求

| 项目 | 最低要求 | 建议 |
|------|----------|------|
| 操作系统 | Windows 10 或 Windows 11（64 位） | Windows 11 |
| 内存 | 8 GB | 16 GB 及以上 |
| 磁盘空间 | 10 GB 可用 | 15 GB（含知识库模型） |
| 网络 | 首次下载模型需要联网 | — |
| GPU | 可选（Vulkan 加速） | 支持 Vulkan 的独显 |

> 说明：
> - 0.8B 档位在 8GB 内存的机器上可流畅运行；2B / 4B 档位建议 16GB 内存。
> - 知识库模型（bge-m3 + bge-reranker-v2-m3）共约 4.5GB，磁盘需预留空间。
> - 无需另装 Python —— 程序内置嵌入式 Python 3.14。

---

## 2. 安装步骤

### 步骤一：下载安装包

从官方渠道获取 Sidemate 安装包 `Sidemate_Setup.exe`。

### 步骤二：一键安装

1. 双击运行 `Sidemate_Setup.exe`
2. 按向导选择安装路径（建议纯英文路径，如 `D:\Sidemate\`），完成安装
3. 安装完成后桌面会出现 Sidemate 图标

### 步骤三：首次启动引导

1. 双击桌面图标启动 Sidemate
2. 首次启动由 **Go launcher（Sidemate.exe）** 拉起三个组件：
   - **llama-server.exe**（llama.cpp 推理服务，端口 11434）
   - **Python 后端**（FastAPI，端口 8976）
   - **浏览器界面**
3. 首次启动需要 1-2 分钟初始化环境
4. 启动完成后，系统托盘出现 Sidemate 图标，浏览器自动打开主界面

> 提示：首次启动时尚无模型，需要先完成「步骤四」下载模型后才能对话。

---

## 3. 模型下载（必做）

> 这是使用本地对话与知识库功能的必要步骤。v0.9.7 起统一在「**设置 → 模型下载**」页操作。

### 3.1 选择 LLM 档位

进入「设置 → 模型下载」页，选择 Qwen3.5 的三档之一：

| 档位 | 模型 | 体积 | 显存/内存占用 | 适用场景 |
|------|------|------|---------------|----------|
| 轻量 | Qwen3.5-0.8B | ~0.5 GB | ~1.5 GB | 8GB 内存机器、快速问答 |
| 均衡 | Qwen3.5-2B | ~1.3 GB | ~3 GB | 通用对话（推荐） |
| 强力 | Qwen3.5-4B | ~2.7 GB | ~6 GB | 16GB 内存、复杂推理 |

### 3.2 选择知识库组合

如需使用知识库功能，还需下载 KB 模型组合：

| 模型 | 用途 | 体积 |
|------|------|------|
| bge-m3 | 文本向量化（embedding） | ~2 GB |
| bge-reranker-v2-m3 | 检索结果重排序（rerank） | ~2.5 GB |

合计约 **4.5 GB**。不使用知识库可跳过。

### 3.3 在线下载

1. 在「模型下载」页点击对应模型的「下载」按钮
2. 默认从 **ModelScope（魔搭）** 下载，国内速度快
3. 可在页面切换下载源为 **HuggingFace**（海外用户）
4. 下载进度实时显示，完成后自动加载

> 提示：下载中断可点击「继续」断点续传；切换下载源不会丢失已下载的文件。

### 3.4 等待模型加载

- LLM 加载约 10-30 秒（首次可能稍长）
- KB 模型加载约 20-40 秒
- 加载完成后即可开始对话

## 4. 从本地安装 .sidemate 包（备选方式）

> 适用于：内网/离线环境，或网络下载不畅时。提前从可联网的机器下载 `.sidemate` 模型包，再导入本机。

1. 准备 `.sidemate` 格式的模型包文件（Qwen3.5 各档位、KB 模型组合均有对应包）
2. 打开「设置 → 模型下载」页
3. 点击「**从本地安装**」按钮
4. 选择 `.sidemate` 文件，等待校验（SHA256）与解压安装
5. 安装完成后自动加载

> 说明：`.sidemate` 包是自包含的模型文件 + 清单，安装前会做完整性校验。

---

## 5. 可选配置：云端 AI（在线 / 并行模式）

如需更强的云端回答能力：

1. 打开「设置 → 云端 AI」
2. 填写：
   - **接口地址（Base URL）**：云端服务商提供的接口地址
   - **API Key**：你的 API 密钥（base64 编码存储）
   - **模型名称**：选择云端模型
3. 点击「保存」—— 系统会自动测试连接
4. 在 Chat Tab 顶栏切换到「**在线**」或「**并行**」模式即可

> 提示：云端 API Key 仅本地存储，用于与云端服务通信，不会外泄。

---

## 6. 覆盖升级

1. 下载新版安装程序
2. 直接运行，安装到与旧版相同的目录（安装程序会自动检测）
3. 所有用户数据（对话记录、知识库、模型、设置）都会保留
4. 升级后重新启动即可

> v0.9.6 → v0.9.7 升级说明：底座由 Ollama 迁移到 llama.cpp，升级后需在「模型下载」页重新下载 Qwen3.5 / KB 模型（旧版 Ollama 模型不再使用）。

---

## 7. 卸载

1. 关闭正在运行的 Sidemate（右键托盘图标 → 退出）
2. 打开 Windows「设置 → 应用」或「控制面板 → 程序和功能」
3. 找到「Sidemate」，点击「卸载」
4. 卸载程序默认保留用户数据（`data/` 目录）

**彻底清除**：卸载后手动删除安装目录（含 `data/`），将一并删除所有对话、知识库、模型和设置。

## 8. 常见安装问题速查

| 现象 | 解决方法 |
|------|----------|
| 启动后提示「端口被占用」 | 关闭其他占用 11434 / 8976 端口的程序，或重启电脑（详见《故障排查》） |
| 界面提示「AI 服务未就绪」 | 确认已在「模型下载」页下载并加载模型 |
| 模型下载失败 | 切换下载源（ModelScope ↔ HuggingFace），或改用「从本地安装」 |
| 模型加载失败 | 检查内存是否充足；0.8B 档位需 ~1.5GB，4B 档位需 ~6GB |
| 首次启动卡很久 | 初始化环境需要 1-2 分钟，属正常现象 |

> 更详细的排查见同目录《故障排查.md》与《常见问题-FAQ.md》。
