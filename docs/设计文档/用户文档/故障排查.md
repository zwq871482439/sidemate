# 故障排查指南

> 版本：v0.9.6（当前发版）
>
> 📘 v0.9.6 新增功能（Onboarding / AI 洞察 v2）的故障排查见同目录 `v0.9.6-*.md` 文档。

---

## 1. SSE 调试

### 现象：前端 UI 卡死（发送按钮灰色，无法操作）

**原因**：SSE 流式连接的某个错误出口没有发送 `done` 事件。

**排查**：
1. 打开浏览器 F12 → Network → 找到 `/api/chat/stream` 请求
2. 查看 EventStream tab，确认是否有 `done` 事件
3. 检查后端对应的 `except` 块是否调用了 `sse_done_event()`

### 现象：流式回答中断，内容不完整

**可能原因**：超时或 Ollama 崩溃
- 检查 `data/logs/` 中的日志
- 尝试重启 Sidemate.exe

---

## 2. Ollama 问题

### 现象：模型状态显示 "stopped" 但不影响功能

**原因**：Ollama 状态查询接口偶发超时，LLM 实际可用。

**解决**：忽略此状态，直接使用。如需修复，重启 Sidemate.exe。

### 现象：模型加载失败

**排查**：
1. 确认 `models/` 目录下有 GGUF 格式模型文件
2. 确认 `ollama.exe` 可正常运行
3. 检查 Vulkan 驱动是否正常（CPU fallback 可用）

---

## 3. 知识库问题

### 现象：上传文档后一直显示"排队中"

**原因**：后台打标队列阻塞或模型未加载。

**排查**：
1. 检查 `/api/status` 确认 LLM 已加载
2. 查看 `/api/kb/module-status` 确认嵌入模型和 Reranker 已加载
3. 如卡死，重启 Sidemate.exe 后存量文档会自动恢复

### 现象：AI 洞察显示"单一聚类"但分明有多个分类

**原因**：LLM 归并过于激进，把多个分类合并成了 1 个。

**解决**：等待下次打标完成后重新点击「整理」。

---

## 4. 界面问题

### 现象：暗色模式下部分元素颜色异常

**解决**：切换到亮色模式再切回，或硬刷新 (Ctrl+Shift+R)

### 现象：知识库卡片不显示 AI 标签/摘要

**原因**：打标尚未完成（后台 P2 优先级）。

**解决**：等待打标完成 → 「整理」→ 刷新。

---

## 5. 通用排查步骤

1. **硬刷新**：`Ctrl + Shift + R`
2. **重启**：关闭 Sidemate.exe → 重新打开
3. **查看日志**：`data/logs/` 目录
4. **API 检查**：`curl http://127.0.0.1:8976/api/health`
5. **磁盘空间**：确认 `data/kb/` 所在磁盘剩余 > 2GB

## 6. v0.9.6-final 报告生成故障

### 现象：HTML 报告里 mermaid 图显示「图表渲染失败」

**排查**：

1. 打开 `.html` 文件，看哪个图失败
2. hover 错误框，看下方「查看源码」展开
3. 复制源码，浏览器打开 https://mermaid.live 验证语法
4. 让 AI 重新生成（或自己改）

**常见语法错**：

```mermaid
# ❌ 错：节点标签里半角双引号
flowchart LR
  A[任务: "完成"]

# ✅ 对：中文引号或全角
flowchart LR
  A[任务: 「完成」]
```

### 现象：报告里 markdown 没渲染（看到原始 markdown 文本）

**原因**：marked.js 加载失败。

**排查**：

1. 按 F12 看 Network → `marked.min.js` 状态码
2. 看 Console 有无报错
3. 看是否浏览器拦截（罕见，自包含文件应该无网络请求）

**解决**：本问题已在 0.9.6-final 修复。如出现，确认用的是 v0.9.6-final 版本。

### 现象：PPT 文件用浏览器打开是空白页

**排查**：

1. 浏览器 F12 → Console → 看是否报 reveal.js / mermaid.js 加载错
2. 看是否有 `Reveal is not defined` / `mermaid is not defined`

**解决**：重新生成 PPT（确认服务端版本 ≥ 0.9.6-final）

### 现象：PPT 导出 PDF 后背景是白色

**原因**：未勾选「背景图形」。

**解决**：导出 PDF 时：
- 边距选「无」
- **勾选「背景图形」**
- 建议先按 `F` 进全屏再导出

## 7. v0.9.6-final Agent 循环故障

### 现象：AI 反复读同一文件 19 次后静默退出

**原因**：0.9.6 之前每读一次文件算 1 轮工具调用，20 轮耗尽。

**解决**：本问题已在 0.9.6-final 修复——本地工具不计轮次。

### 现象：AI 达 20 轮没有任何总结就停了

**解决**：本问题已在 0.9.6-final 修复——强制收尾，AI 会基于已有信息给总结。

如没看到总结，看 server 日志 `[AGENT] 达到最大轮次 20`，确认强制收尾的纯对话调用是否报错。

### 现象：工具调用一直报错「已达上限」

**原因**：单工具硬限制触发（如 `search_web` 3 次上限）。

**排查**：

1. 看 server 日志 `[AGENT] 子类超限，移除工具: [...]`
2. 看哪些工具被移除
3. 确认是 `search_web` / `search_kb` / `fetch_url` 这 3 个

**解决**：
- 在新消息里重新提问（重置本轮预算）
- 切到本地模型（不走云端 Agent）
- 减少搜索依赖——让 AI 一次搜更精准

### 现象：上下文指示器涨到 80% 后变红

**原因**：历史消息总 token 接近上限。

**解决**：
- 切到新对话
- 或用「总结历史」工具压缩
- 或减少引用 KB 文档数量
