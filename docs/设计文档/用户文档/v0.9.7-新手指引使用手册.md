# Sidemate 新手指引（Onboarding）使用手册

> ⚠️ **本文档描述 v0.9.7 待发版功能**（已实现于 main 分支，尚未发版；当前 `config.py` 仍为 0.9.6）。发版前请同步验证代码与本文。
>
> 版本：v0.9.7 | 文件：`server/static/js/welcome-tour.js`
> 适用人群：首次使用 Sidemate 的用户 / 想要回顾产品能力的老用户

---

## 1. 概览

桌伴 Sidemate 提供**两阶段新手指引**系统，从首次启动到熟练使用全程陪伴：

| 阶段 | 触发时机 | 形式 | 主要作用 |
|------|----------|------|----------|
| **阶段 1：欢迎弹窗** | 首次启动 / 重置后 | 模态弹窗 | 介绍核心能力、引导配置 AI / KB |
| **阶段 2：交互式 TourGuide** | 欢迎弹窗点「开始使用」 | 5 步聚光引导 | 带用户走一遍核心操作流程 |

两阶段状态独立保存在 `localStorage`：
- `sidemate_welcomed` —— 阶段 1 是否被关闭
- `sidemate_toured` —— 阶段 2 是否完成

关闭任一阶段后，下次启动将不再自动弹出，除非主动重置。

## 2. 阶段 1：欢迎弹窗

### 2.1 智能分支

欢迎弹窗会根据你当前的安装状态呈现**不同的引导路径**：

| 系统状态 | 弹窗标题 | 主推操作 |
|----------|----------|----------|
| 未安装 AI 模型 | 欢迎使用桌伴 | 安装本地 LLM / 配置云端 API Key |
| 已安装 AI，未装 KB | AI 已就绪！ | 开始使用 / 跳过（KB 可后装） |
| AI + KB 都已装 | 全功能就绪！ | 开始浏览（带 TourGuide） |

### 2.2 弹窗内容

弹窗顶部带渐变装饰条 + 圆形图标（根据路径不同显示欢迎/对话/完成三种样式），下方为：

1. **标题 + 描述**（核心卖点）
2. **功能卡片列表**（3-4 项，每项含图标 + 标题 + 描述）
3. **主操作按钮**（按当前状态跳转）
4. **跳过引导入口**（小灰字，可一键关闭）

## 3. 阶段 2：交互式 TourGuide

### 3.1 引导流程（5 步）

| 步骤 | Tab | 目标 | 标题 | 内容 |
|------|-----|------|------|------|
| 1 | 对话 | `#chatMode` | 三种 AI 模式 | 离线 / 在线 / 并行 区别 |
| 2 | 对话 | `#msgInput` | 开始对话 | Enter 发送，能聊天/写文档/引用 KB |
| 3 | 知识库 | `#kbToolbar button` | 上传你的文档 | 本地 AI 自动打标，文档不外传 |
| 4 | 知识库 | `#kbAIOverview .s-hdr` | AI 洞察 | 「整理」按钮让 AI 读全文库 |
| 5 | 对话 | 设置 Tab 按钮 | 设置入口 | API Key / 扩展包 / 模型管理 |

### 3.2 引导控件

- **聚光高亮**：目标元素用半透明遮罩 + 镂空 spotlight 突出，其余区域暗色 0.45 透明度
- **说明卡片**：跟随目标位置显示（默认下方，空间不够自动改上方）
- **箭头**：从卡片指向目标中心，自动 clamp 到卡片内 [8, cardW-8]
- **进度点**：5 个圆点，当前步骤用品牌色（accent-color）填充
- **上一步 / 下一步按钮**：第一步隐藏「上一步」，最后一步按钮文案为「完成」
- **关闭**：点击遮罩外部 / Esc 退出

### 3.3 跨 Tab 引导

TourGuide 会**自动切换 Tab**：

- 用 `_tourFindTabBtn()` 智能匹配（兼容 `onclick="switchTab('xxx',this)"` 和文本匹配）
- 切换后用 `setTimeout(150-400ms)` 等待 Tab 渲染完成
- 目标元素若在视口外 → `scrollIntoView({block:'center'})` 居中

### 3.4 兼容性保障

- 即使 `#chatMode` 等目标元素宽度为 0，1s 内轮询 20 次，**绝不卡死**
- 目标不可见时（`offsetWidth/Height == 0`）→ 退化到整屏纯遮罩 + 卡片居中
- 卡片最终 clamp 到 [8, viewW-8] / [8, viewH-8]，**绝不掉出页面**

## 4. 重新查看新手指引

任何时候，你想再走一遍引导，可以：

### 4.1 通过设置页（推荐）

1. 打开 **设置 Tab**
2. 找到「关于」分组
3. 点击「**重新查看新手指引**」按钮
4. 系统清除 localStorage + 重新显示欢迎弹窗

底层实现：

```js
function resetOnboarding() {
  localStorage.removeItem('sidemate_welcomed');
  localStorage.removeItem('sidemate_toured');
  endTour();        // 关闭当前 TourGuide（如果有）
  showWelcome();    // 重新显示欢迎弹窗
}
```

### 4.2 通过调试快捷键

按住 `Ctrl + Shift + O` 可直接清除引导状态并刷新页面（仅在调试场景使用）。

## 5. 常见问题

### Q1：弹窗不小心关掉了，怎么找回？
进入 **设置 → 关于 → 重新查看新手指引**。

### Q2：能不能跳过阶段 1，直接用？
可以。阶段 1 弹窗底部有「跳过新手引导」小灰字，点击即关闭。

### Q3：TourGuide 中途想退出怎么办？
点遮罩外部或按 Esc 退出（会保存「toured=1」状态，下次不再自动弹）。

### Q4：TourGuide 的聚光位置不准确？
v0.9.7 已修复多种边缘情况：
- 目标元素超出视口 → 自动 scrollIntoView
- 目标元素不可见 → 整屏纯遮罩 + 卡片居中
- 卡片掉出页面 → 自动 clamp 到视口内

如仍有问题，请截图反馈。

### Q5：能否彻底禁用 Onboarding？
目前没有配置开关。v1.0 计划添加「设置 → 隐私安全 → 关闭新手指引」选项。

## 7. 设计理念

- **不阻断**：弹窗是「提示」而非「拦截」，半透明背景保留底层内容
- **不冷漠**：空状态有温度、有引导路径
- **不啰嗦**：信息层级极致克制（图标 → 标题 → 描述 → 按钮）
- **隐私友好**：弹窗文案反复强调「数据不出本机」，建立信任
