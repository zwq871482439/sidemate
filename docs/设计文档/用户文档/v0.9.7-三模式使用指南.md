# 三模式使用指南

> 版本：v0.9.7 | 适用人群：想理解离线/在线/并行三种 AI 模式区别、按场景选型的用户
>
> v0.9.7 底座由 Ollama 替换为 **llama.cpp**（llama-server 进程），三种模式的数据流向与适用场景不变。

---

## 1. 概览

Sidemate Chat Tab 顶栏提供**三段式模式按钮组**，对应三种 AI 推理策略，覆盖「完全本地 / 完全云端 / 融合」三大场景：

| 模式 | 数据流向 | 底座 | 适用场景 |
|------|----------|------|----------|
| **离线** | 100% 本地 | 本地 llama.cpp + Qwen | 隐私敏感、无网络、纯本地优先 |
| **在线** | 100% 云端 | 云端 API（GPT/Claude/DeepSeek 等） | 联网需求、追求最强模型、Agent 工具链 |
| **并行** | 本地 KB 检索 + 云端推理 + 本地融合 | 本地 + 云端双线 | 既有本地知识库又要云端广度 |

> **核心承诺**：KB 文档原文永不离开本机。即便并行模式，云端也只能看到本地模型提炼的摘要。

---

## 2. 离线模式详解

### 2.1 能力

- **完全本地推理**：基于 llama.cpp（llama-server 进程）加载 Qwen 系列 GGUF 模型，默认 `qwen3-5-4b`
- **零网络请求**：对话内容、文档内容均不上传，断网可用
- **响应速度**：CPU 模式约 3-8 字/秒；GPU（Vulkan）模式约 10-30 字/秒
- **上下文窗口**：v0.9.7 起支持动态 `num_ctx`（按硬件自动推荐），默认 `--ctx-size 8192`

### 2.2 可用工具

离线模式不跑完整 Agent 循环，但支持以下本地工具与能力：

| 工具 / 能力 | 说明 |
|-------------|------|
| `search_kb` | 检索本地知识库 |
| `read_workspace` / `read_workspace_chunk` | 读取工作区文件 |
| `write_workspace` | 写工作区文件 |
| `set_doc_status` | 生成可下载产物（.docx / .html / .ppt.html） |
| `calculator` | 算术计算 |
| `get_current_time` | 查询当前时间 |
| `format_convert` | 文件格式转换（md/docx/txt 互转、pdf 提取） |
| `table_ops` | Excel 表格读写 |

> 离线模式**不支持**联网搜索（`search_web` / `fetch_url`）和完整 Agent 多轮工具链。

### 2.3 硬件要求

| 配置档 | CPU | 内存 | GPU | 体验 |
|--------|-----|------|-----|------|
| 最低 | 4 核 | 8 GB | 无（纯 CPU） | 可用，3-8 字/秒 |
| 推荐 | 8 核 | 16 GB | Vulkan 4GB+ | 流畅，10-30 字/秒 |
| 高配 | 16 核 | 32 GB | Vulkan 8GB+ | 多模型切换流畅 |

模型越大（如 Qwen 7B/14B）对内存/显存要求越高。设置页「模型管理」可下载不同规格的 GGUF 模型。

### 2.4 适用场景

- 涉及**敏感信息**（财务、医疗、法律、内部资料）
- **无网络**或弱网环境
- **快速问答**（短问题、KB 已有相关资料）
- 对隐私合规有硬性要求（数据不得出本机）

---

## 3. 在线模式详解

### 3.1 能力

- **云端 API 调用**：OpenAI 兼容协议，支持 GPT / Claude / DeepSeek / 通义千问等主流云端模型
- **联网搜索**：通过 `search_web` 搜索互联网，`fetch_url` 抓取网页正文
- **Agent 多轮工具链**：AI 自主判断调用工具，最多 **20 轮**，完成检索→阅读→写作全流程
- **响应速度**：受网络与云端服务限制
- **上下文窗口**：取决于所选模型（Claude 200K / GPT-4o 128K / DeepSeek 64K 等）

### 3.2 Agent 工具链

在线模式（Action=agent）下，AI 自主使用以下工具：

| 工具 | 用途 |
|------|------|
| `search_web` | 联网搜索互联网（Bing） |
| `fetch_url` | 抓取指定网页正文 |
| `search_kb` | 检索本地知识库（受 `kb_permission` 控制） |
| `write_workspace` | 写工作区文件 |
| `set_doc_status` | 生成可下载产物 |
| `deep_read` | 深度阅读长文档，返回结构化分析 |
| `read_workspace` / `read_workspace_chunk` | 读取工作区文件 |
| `list_workspace` / `list_docs` | 列出工作区文件 / 已完成文档 |
| `calculator` | 算术计算 |
| `get_current_time` | 查询时间 |
| `format_convert` / `table_ops` | 格式转换 / 表格读写 |

工具调用约束见 [v0.9.7-工具调用使用指南](v0.9.7-工具调用使用指南.md)。

### 3.3 联网搜索示例

> 「帮我查一下 2026 年最新的新能源汽车销量数据」

AI 会：`search_web` 搜索 → `fetch_url` 抓取相关网页 → 综合信息给出带来源的回答。

### 3.4 前置配置

1. 设置 Tab → 云端 AI
2. 填写 **Base URL**（接口地址）、**API Key**、**Model**（模型名称）
3. 点击「保存」，系统自动验证模型是否可用
4. 配置成功后即可切换到「在线」模式

### 3.5 隐私注意

- **对话内容会发送到云端服务商**，遵循所选云厂商的隐私政策
- **KB 文档是否发送**取决于 `kb_permission` 配置（见 [v0.9.7-知识库使用指南](v0.9.7-知识库使用指南.md)）
- **私密文档**默认对云端屏蔽，本地 AI 不受限制
- 本地工作区文件不会自动发送，仅当 AI 主动 `read_workspace` 并你已切换在线模式时才会上传

### 3.6 适用场景

- 需要**联网搜索**最新信息（新闻、数据、行情）
- **复杂推理**（数学、代码、跨领域分析）
- **大上下文**长对话（受模型窗口限制）
- KB 中**没有**相关资料，需要通用知识
- 需要 Agent **多步完成**复杂任务（调研→分析→写报告）

## 4. 并行模式详解

### 4.1 双线协作流程

并行模式 = **本地列（KB 检索）+ 云端列（通用推理）+ 本地融合**，两路独立工作：

```
用户提问
   ├── 本地列：检索本地 KB → 本地 LLM 基于 KB 内容生成回答
   ├── 云端列：基于用户问题 + 通用知识独立生成回答
   └── 融合：本地模型综合两路信息，流式输出最终回答
```

| 阶段 | 耗时 | 产出 |
|------|------|------|
| 检索 | ~0.5s | KB top-k chunk 列表 |
| 本地生成 | 3-10s | 本地 LLM 基于 KB 的回答 |
| 云端补充 | 3-15s | 云端 LLM 基于通用知识的回答 |
| 融合 | ~1s | 综合两路生成最终回答 |

前端 AgentTimeline 实时展示四步进度，历史消息持久化可回放。

### 4.2 隐私保证

> **KB 原文永不离开本机。**

- 本地列：KB chunk 原文只在本地处理
- 云端列：只看到本地模型提炼的摘要（`memory_local`，≤200 字），拿不到文档 chunk 原文
- 摘要由本地 LLM 提炼，不包含敏感原文

即便 `kb_permission=full`，并行模式下云端看到的也只是本地摘要，不是 KB 全文。

### 4.3 双线记忆

并行模式维护两套独立记忆，互不干扰：

| 字段 | 含义 |
|------|------|
| `memory_local` | 本地列回答摘要（≤200 字） |
| `memory_cloud` | 云端列回答摘要（≤300 字） |

切换到「离线」只读 `memory_local`；切换到「在线」只读 `memory_cloud`。

### 4.5 适用场景

- KB 中**有**相关资料，但本地模型答得不够全面
- 需要**云端广度知识**补充本地深度
- 不能把 KB 全文给云端（隐私 / 合规）
- 想用 KB 的同时**利用最新云端知识**
- 想**双保险**（本地列验证云端列准确性）

> 并行模式闲聊（如「你好」）会自动跳过 KB 检索，直接给正常回复，不会答非所问。

## 5. 模式切换操作

### 5.1 触发切换

点击顶栏三段按钮中的任一非当前模式 → 弹出确认弹窗。

### 5.2 切换确认弹窗

| 字段 | 内容 |
|------|------|
| 标题 | 「切换到 {目标模式}？」 |
| 说明 | 目标模式的功能描述 |
| 风险 | 数据流向 + 隐私边界提醒 |
| 按钮 | 「确认切换」/「取消」 |

### 5.3 切换后行为

- 当前对话消息**保留**（历史可读）
- 后续消息按新模式生成
- 上下文指示器（Token 条）按新模式容量重置
- 已有 AgentTimeline 状态保留

### 5.4 阻断条件

- 切「在线」/「并行」**未配置 API Key** → 弹窗阻止切换
- 三模式间任意切换**不丢失历史**

## 6. 推荐场景速查表

| 你的需求 | 推荐模式 | 理由 |
|----------|----------|------|
| 涉及财务/医疗/法律等敏感数据 | **离线** | 数据零外发 |
| 无网络环境（出差、内网） | **离线** | 断网可用 |
| KB 有资料、快速问答 | **离线** | 本地检索+生成即可 |
| 查最新新闻、行情、数据 | **在线** | 联网搜索 |
| 复杂推理、数学、代码 | **在线** | 云端大模型强 |
| KB 没有相关资料 | **在线** | 通用知识补充 |
| Agent 多步调研→写报告 | **在线** | 完整工具链 |
| KB 有资料但要云端广度补充 | **并行** | 本地深度 + 云端广度 |
| KB 资料不能给云端 | **并行** | 原文不出本机 |
| 想要双保险交叉验证 | **并行** | 两路独立回答 |

### 模式对比总表

| 维度 | 离线 | 在线 | 并行 |
|------|------|------|------|
| 数据流向 | 本地 | 云端 | 本地 KB + 云端 |
| 需要 API Key | 否 | 是 | 是 |
| 需要联网 | 否 | 是 | 是 |
| 联网搜索 | 否 | 是 | 否（KB 优先） |
| Agent 工具链 | 受限 | 完整 | 云端列完整 |
| 响应速度 | 中（受本地硬件） | 中（受网络） | 较慢（四步） |
| 知识广度 | 受限于本地 LLM | 最广 | KB 深度 + 云端广度 |
| 隐私性 | 最高 | 最低 | 中（仅摘要外发） |
| 写文档 | 支持 | 支持 | 支持 |

## 7. 常见问题

### Q1：切换模式后之前的对话会丢吗？
不会。历史消息保留，按当前模式读取对应记忆（`memory_local` 或 `memory_cloud`）。

### Q2：并行模式下云端能看到我的 KB 文档吗？
不能。云端只能看到本地生成的摘要（≤200 字），KB chunk 原文留在本机。

### Q3：三种模式哪个回答质量最高？
- 知识类（KB 内有）：**并行** 最高
- 通用类（KB 外）：**在线** 最高
- 隐私类：**离线** 最高（即便牺牲质量）

### Q4：v0.9.7 换了 llama.cpp 底座，对我使用有影响吗？
功能层面无影响，三种模式行为不变。llama.cpp 减少了中间层开销，推理参数（num_ctx / threads / gpu_layers）更可控，本地推理体验更稳定。
