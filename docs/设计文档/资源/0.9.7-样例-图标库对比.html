对比项 lucide heroicons 当前自绘
风格几何、利落、清晰圆润、柔和、现代简单、有点稚拙
描边粗细2px（醒目）1.5px（精致）1.1-1.3px（偏细）
图标数量1500+~30024 个
引入体积~500KB（全量）
按需加载 ~5KB/个		~100KB（全量）0（已内联）
适配 Sidemate✅ 深蓝科技感 + 利落几何 = 贴合⚠️ 偏 web app、偏消费级现状不统一
维护方式复制 SVG 到 utils.js同左继续手画

💡 引入方式：两个库都不需要 npm 安装。直接把用到的 SVG path 复制到 utils.js 的 iconSvg() 字典里就行——跟现在自绘的方式一模一样，只是换了一套更专业的"画法"。
