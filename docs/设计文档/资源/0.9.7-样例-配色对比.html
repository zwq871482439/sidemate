📊 深蓝 vs 琥珀 — 怎么选？

对比维度 方案 A · 深蓝（现状） 方案 B · 琥珀（文档定义）
气质 冷色 · 科技感 · 专业 · 工具感
像 Linear、Notion、VS Code		 暖色 · 亲和 · 有温度 · 陪伴感
像 Stripe、Headspace、Calm
与"桌伴"定位 偏"工具"——用户觉得是高效 AI 助手 偏"陪伴"——用户觉得是有温度的助手
当前 Logo 匹配 ⚠️ Logo 是暖色调（橙黄米白），主色冷蓝 → 有点割裂 ✅ Logo 暖色调与琥珀主色 → 视觉统一
代码改动量 零改动（现状就是深蓝） 需改 --accent-color、按钮、链接、chip 等约 15-20 处 CSS 变量
暗色模式适配 深蓝在暗色背景下对比度天然好 琥珀在暗色背景下需调亮（已验证 #c9976c → #deb893 可行）
文档一致性 ⚠️ 需改 Design-Tokens.md（文档说琥珀是主色） ✅ 跟 Design-Tokens.md 一致
长期风险 深蓝科技感，但市面上太多同类产品用蓝（同质化） 琥珀较独特，辨识度高，但暖色易显"廉价"需小心调
💡 第三种可能 · 双色并存
其实你现在的色系已经是"深蓝(主) + 琥珀(强调)"并存。问题不是"选哪个当主色"，而是 把琥珀真正用起来——让 CTA 按钮（导出/生成）用琥珀，让导航和文字链保持深蓝。 这样既有科技感（蓝），又有温度（琥珀点缀），还跟 Logo 统一。这种"主蓝 + 点缀琥珀"方案， 代码改动比"全换琥珀"小得多。
