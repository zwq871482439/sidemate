# 知识库模块测试用例

> 测试日期：2026-05-20
> 测试环境：本地AI助手 v0.8 patch6，KB模块 bge-base-zh-v1.5 + bge-reranker-base
> 测试文档来源：D:\ 盘中医养生文档

## 前置条件

- [ ] 服务已启动（`python server.py`）
- [ ] KB 模块已激活（设置页 → 知识库 → 一键激活）
- [ ] 8B 模型已加载（文档处理需要模型）

## 一、文档上传与处理

### TC-01：单个文档上传
**步骤**：
1. 进入「问答」Tab
2. 点击「上传文档」按钮
3. 选择 D1（刮五指，42KB）
4. 等待处理完成

**预期**：
- [ ] 上传后显示"处理中"状态
- [ ] 进度条正常推进（0% → 100%）
- [ ] 处理完成后状态变为"就绪"
- [ ] 文档列表显示文件名、大小、状态

### TC-02：批量上传（5个文档连续上传）
**步骤**：
1. 依次上传 D1 → D2 → D3 → D4 → D5
2. 观察处理状态

**预期**：
- [ ] 每个文档都能正常上传
- [ ] 处理队列正常排队（不崩溃）
- [ ] 所有文档最终都变为"就绪"状态
- [ ] 上传过程中不影响已有文档

### TC-03：上传空文件
**步骤**：
1. 创建一个空的 .txt 文件（0字节）
2. 尝试上传

**预期**：
- [ ] 提示"文件内容为空"或类似错误
- [ ] 不崩溃

### TC-04：重复上传同一文档
**步骤**：
1. 上传 D2
2. 等处理完后再次上传 D2

**预期**：
- [ ] 第二次上传正常（允许重复）
- [ ] 文档列表显示两条记录

## 二、知识库问答

> 以下每个问题都应在「问答」Tab 中用 KB 模式提问

### TC-10：精确匹配检索
**问题**：`刮五指对应哪些脏腑？`
**预期**：
- [ ] 返回包含五指对应脏腑的内容（D1 文档内容）
- [ ] 引用来源标注正确
- [ ] 回答内容准确（不是编造的）

### TC-11：语义理解检索（同义词）
**问题**：`手指和内脏有什么关系？`
**预期**：
- [ ] 能匹配到 D1 的内容（虽然没说"刮五指"）
- [ ] 说明向量检索的语义理解有效

### TC-12：列表型内容精确提取
**问题**：`常见的错误养生方法有哪些？举3个例子`
**预期**：
- [ ] 从 D4 中提取具体的错误养生法
- [ ] 内容准确，不是模型自己编的
- [ ] 引用来源标注为 D4

### TC-13：跨文档检索
**问题**：`运动对大脑有什么好处？`
**预期**：
- [ ] 主要内容来自 D3（健脑运动）
- [ ] 可能辅助引用 D4 或 D5（如果也有相关内容）
- [ ] 多个来源引用标注

### TC-14：专有名词检索
**问题**：`中医有哪些主要流派？`
**预期**：
- [ ] 准确从 D2 中提取流派信息
- [ ] 流派名称准确（不是编造的）
- [ ] 来源标注为 D2

### TC-15：超出知识库范围的问题
**问题**：`量子力学的基本原理是什么？`
**预期**：
- [ ] 明确回答"知识库中未找到相关信息"
- [ ] 不编造答案
- [ ] 不用训练知识补充

### TC-16：模糊问题
**问题**：`养生`
**预期**：
- [ ] 能返回多个文档的相关内容
- [ ] 不崩溃、不超时

### TC-17：长问题 / 多条件
**问题**：`中医流派中，哪个流派最注重药物治疗？它和其它流派的区别是什么？`
**预期**：
- [ ] 从 D2 中提取流派对比信息
- [ ] 回答有结构，不是简单复制粘贴

## 三、文档管理

### TC-20：删除单个文档
**步骤**：
1. 在文档列表中删除 D5
2. 再问一个 D5 相关的问题：`养生就是玩是什么意思？`

**预期**：
- [ ] 删除成功，列表不再显示 D5
- [ ] 删除后再问 D5 的内容，不应返回 D5 的引用
- [ ] 磁盘空间正确释放

### TC-21：删除后重新上传
**步骤**：
1. 删除 D3
2. 重新上传 D3
3. 问 D3 相关问题验证

**预期**：
- [ ] 重新上传正常
- [ ] 新上传的文档能正常检索到

### TC-22：文档数上限
**步骤**：
1. 检查当前文档数和上限
2. 如果接近上限，尝试上传新文档

**预期**：
- [ ] 达到上限时提示"知识库已满"
- [ ] 不崩溃

## 四、稳定性测试

### TC-30：快速连续提问
**步骤**：
1. 快速连续发送 3 个问题（不等回答完成就发下一个）
2. `刮五指有什么好处？` → `中医流派有哪些？` → `错误养生法有哪些？`

**预期**：
- [ ] 每个问题都有正确回答
- [ ] 不崩溃、不卡死
- [ ] 不会串回答（问A答B）

### TC-31：长文本问答
**步骤**：
1. 问一个需要综合多文档的长问题：`请详细总结知识库中关于运动和养生的所有建议`
2. 等待完整回答

**预期**：
- [ ] 回答完整，不截断
- [ ] 综合了多个文档的信息
- [ ] 来源引用正确

### TC-32：KB 激活/停用循环
**步骤**：
1. 停用 KB 模块
2. 重新激活
3. 问之前测试过的问题

**预期**：
- [ ] 停用后问答不可用（或走普通对话模式）
- [ ] 重新激活后之前上传的文档还在
- [ ] 问答恢复正常

## 五、反幻觉验证

> 这是最关键的测试 — 验证 KB 回答确实基于文档内容，不是模型编造

### TC-40：与原文核对
**步骤**：
1. 问：`刮大拇指对应什么？有什么效果？`
2. 用 Word 打开 D1 原文件，核对回答内容

**预期**：
- [ ] 回答内容与原文一致
- [ ] 没有原文没有的"额外建议"
- [ ] 专有名词、穴位名称准确

### TC-41：诱导性问题
**步骤**：
1. 问：`中医流派中，火神派是不是最重视针灸？`（假设火神派实际重视的是附子/温阳）

**预期**：
- [ ] 如果 D2 中有相关内容，按 D2 纠正
- [ ] 如果 D2 中没有明确说明，回答"知识库中未找到该信息"
- [ ] 不顺着用户的错误前提编造

### TC-42：数字精确性
**步骤**：
1. 问：`错误养生法一共列举了多少条？`

**预期**：
- [ ] 回答的数量与 D4 文件中的实际数量一致
- [ ] 不是模型估算的
