## 用例 1：代码生成（核心能力）

**输入：**
```
帮我写一个命令行的简单井字棋，使用py代码
```

**评分维度：**
| 维度 | 权重 | 评分(1-5) | 备注 |
|------|------|-----------|------|
| 代码可运行 | 40% | | 直接跑能否不报错 |
| 功能完整 | 30% | | 有开始/下棋/判断胜负/平局 |
| 无幻觉 | 20% | | 无中文变量名/中文字符混入代码 |
| 输出完整 | 10% | | 未截断 |

**期望产出：** 可直接运行的 Python 井字棋（~40-60 行）

## 用例 4：摘要（办公核心场景）

**输入：**
```
帮我用3句话总结以下内容：

在当今快速发展的技术环境中，企业面临着前所未有的数字化转型压力。根据最新调研数据，超过78%的企业已经启动了某种形式的数字化转型项目，但其中只有不到30%的项目被认为取得了显著成效。成功的企业通常具备以下特征：首先，他们有明确的数字化战略，并且这一战略与企业的整体业务目标紧密对齐；其次，他们注重人才培养，确保员工具备必要的数字技能；第三，他们采用敏捷的开发方法，能够快速迭代和适应变化。相比之下，失败的项目往往缺乏清晰的目标，或者过于追求技术而忽视了业务价值。专家建议，企业在启动数字化转型之前，应该先进行全面的现状评估，明确痛点和机会，然后制定分阶段的实施路线图。
```

**评分维度：**
| 维度 | 权重 | 评分(1-5) | 备注 |
|------|------|-----------|------|
| 3句话约束 | 30% | | 不是2句或4句 |
| 要点覆盖 | 40% | | 覆盖现状/成功特征/建议 |
| 简洁度 | 20% | | 无冗余 |
| 无废话 | 10% | | 直入主题 |

## 快速测试脚本

如果需要自动化测试，可以用以下脚本逐条发送到本地 API：

```python
"""快速基准测试 - 逐条发送测试用例到本地 AI"""
import requests, json, time

API = "http://127.0.0.1:8976"

TESTS = [
    {"name": "1-代码生成", "msg": "帮我写一个命令行的简单井字棋，使用py代码"},
    {"name": "3-翻译", "msg": "把下面这段翻译成英文：\n人工智能正在改变我们的工作方式。从自动化重复性任务到辅助创意决策，AI工具正在成为职场中不可或缺的伙伴。然而，如何在提升效率的同时保护数据隐私，仍然是企业需要面对的重要挑战。"},
    {"name": "4-摘要", "msg": "帮我用3句话总结以下内容：\n在当今快速发展的技术环境中，企业面临着前所未有的数字化转型压力。根据最新调研数据，超过78%的企业已经启动了某种形式的数字化转型项目，但其中只有不到30%的项目被认为取得了显著成效。成功的企业通常具备以下特征：首先，他们有明确的数字化战略，并且这一战略与企业的整体业务目标紧密对齐；其次，他们注重人才培养，确保员工具备必要的数字技能；第三，他们采用敏捷的开发方法，能够快速迭代和适应变化。相比之下，失败的项目往往缺乏清晰的目标，或者过于追求技术而忽视了业务价值。专家建议，企业在启动数字化转型之前，应该先进行全面的现状评估，明确痛点和机会，然后制定分阶段的实施路线图。"},
    {"name": "5-数学", "msg": "一个水池有两个进水管和一个出水管。A管单独注满需要6小时，B管单独注满需要8小时，出水管单独放完需要12小时。如果三管同时打开，多少小时能注满水池？"},
    {"name": "8-指令遵从", "msg": "用Python写一个快速排序函数，要求：\n1. 只输出代码，不要任何解释\n2. 变量名用英文\n3. 不要写main函数\n4. 不要写注释"},
]

def run_benchmark():
    results = []
    for t in TESTS:
        print(f"\n{'='*40}")
        print(f"测试: {t['name']}")
        print(f"输入: {t['msg'][:50]}...")
        t0 = time.time()
        try:
            r = requests.post(f"{API}/api/chat", json={"message": t["msg"]}, timeout=120)
            data = r.json()
            elapsed = time.time() - t0
            resp = data.get("response", "")
            print(f"回复 ({len(resp)}字, {elapsed:.1f}s, {data.get('speed',0):.0f}字/s):")
            print(resp[:200] + ("..." if len(resp) > 200 else ""))
            results.append({"name": t["name"], "chars": len(resp), "time": elapsed, "speed": data.get("speed",0)})
        except Exception as e:
            print(f"错误: {e}")
            results.append({"name": t["name"], "error": str(e)})
    
    print(f"\n{'='*40}")
    print("汇总:")
    for r in results:
        if "error" in r:
            print(f"  {r['name']}: 错误 - {r['error']}")
        else:
            print(f"  {r['name']}: {r['chars']}字, {r['time']:.1f}s, {r['speed']:.0f}字/s")

if __name__ == "__main__":
    run_benchmark()
```

使用：`python benchmark.py`（服务启动后运行）
