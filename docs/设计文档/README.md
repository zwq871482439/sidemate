# 桌伴 · Sidemate

> 本地优先的 AI 桌面助手 — 数据不出本机，云端按需连接

## 项目简介

**桌伴 Sidemate** 是一款面向 Windows 桌面的 AI 助手，核心设计理念是**本地优先、隐私可控**。内置本地 LLM（基于 llama.cpp），支持完全离线使用；同时提供云端 AI 模式，用户可按需配置 API Key 连接云端大模型。

### 核心特性

| 特性 | 说明 |
|------|------|
| 🔒 **本地优先** | 所有数据存放在本机，不上传。基于 llama.cpp + Qwen3.5 的本地推理引擎 |
| ☁️ **云端扩展** | 支持配置 OpenAI 兼容 API（DeepSeek、通义千问、GPT 等），用户自选 |
| 📚 **知识库** | 上传文档，AI 基于文档内容回答。支持向量检索 + 语义重排序 |
| ⚡ **三种模式** | 离线（100%本地）/ 在线（云端大模型）/ 并行（本地检索+云端推理） |
| 📊 **报告生成** | 一键生成 Word 文档、HTML 可视化报告、PPT 演示文稿 |
| 🛠️ **工具调用** | AI 自主联网搜索、读网页、查知识库、写文档 |
| 📦 **模型下载** | 内置模型下载页，从 ModelScope 一键下载 LLM 和知识库模型 |
| 🌙 **深色模式** | 完整的深色/浅色主题切换 |

## 技术栈

| 层 | 技术 |
|----|------|
| **后端** | Python 3.14（嵌入式）+ FastAPI + Uvicorn |
| **推理引擎** | llama.cpp（llama-server）+ Qwen3.5 GGUF（0.8B/2B/4B） |
| **云端** | OpenAI 兼容 API（用户自配） |
| **知识库** | bge-m3（embedding）+ bge-reranker-v2-m3（重排序） |
| **前端** | 原生 HTML/CSS/JS，CSS 变量主题系统 |
| **打包** | Inno Setup + Go Launcher (Sidemate.exe) |
| **协议** | Apache-2.0 开源 |

## 项目结构

```
Sidemate/
├── Sidemate.exe              ← Go Launcher，管理生命周期
├── python/                   ← 嵌入式 Python 3.14
├── server/                   ← FastAPI 后端
│   ├── server.py             ← 入口
│   ├── config.py             ← 全局配置
│   ├── core/                 ← AI 引擎核心
│   │   ├── llamacpp_backend/ ← llama.cpp 推理（manager/registry/client）
│   │   ├── cloud_engine.py   ← 云端 API
│   │   ├── download_engine.py← 模型下载
│   │   ├── agent_loop.py     ← Agent 工具循环
│   │   └── ...
│   ├── pipelines/            ← SSE 管道（离线/在线/并行）
│   ├── routers/              ← API 路由
│   ├── knowledge/            ← 知识库（检索/分块/向量化）
│   └── static/               ← 前端
├── launcher/                 ← Go Launcher 源码
├── models/                   ← AI 模型文件（GGUF + embedding + reranker）
├── lib/                      ← llama-server.exe 等运行时
└── data/                     ← 运行时数据
    ├── chats/                ← 对话历史
    ├── kb/                   ← 知识库数据
    └── logs/                 ← 日志
```

## 快速开始

1. 下载安装包，一键安装
2. 启动后进入 **设置 → 模型下载**
3. 下载 LLM 模型（推荐 4B）和知识库模型
4. 开始对话或知识库问答
