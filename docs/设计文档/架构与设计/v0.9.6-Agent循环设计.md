## 1. 什么是 AgentLoop

AgentLoop 是 Sidemate **在线模式**（`ai_mode=cloud`）下驱动云端 LLM 多轮推理 + 工具调用的核心循环。它实现标准的 **ReAct 范式**：

```
Reason（推理） → Act（调工具） → Observe（看结果） → Reason → ...
```

每个 AgentLoop 调用 = 完成一个完整的「用户请求」任务。

---

## 2. 核心循环流程

`server/core/agent_loop.py::_run_agent_loop()`

```python
def _run_agent_loop(messages, tools, ...):
    rounds = 0
    _round_incremented = False

    while rounds < MAX_ROUNDS:  # 默认 20
        # 1. 检测用户终止
        # 2. 工具硬限制（移除已达上限的工具）
        # 3. 调 CloudEngine.run_with_tools(messages, tools)
        #    LLM 返回:
        #    - tool_calls: [调工具]
        #    - text: 给用户的文本
        # 4. 如果有 tool_calls:
        #    for tc in tool_calls:
        #        result = execute(tool_name, args)
        #        rounds += 1  # 仅 expensive 工具
        #        messages.append(tool_result)
        # 5. 如果 LLM 没调工具 → break（对话自然结束）

    # 6. 达 MAX_ROUNDS → 强制收尾
    if rounds >= MAX_ROUNDS:
        # 注入"必须直接回答"指令
        # 追加一轮纯对话调用（不带 tools）
        # 兜底文案
```

## 3. 工具分类（v0.9.6 起）

### 3.1 Cheap 工具

```python
CHEEP_TOOLS = {
    "read_workspace", "read_workspace_chunk",
    "list_workspace", "list_docs",
    "summarize_history",
    "get_current_time", "calculator",
    "format_convert", "table_ops",
}
```

**特性**：
- 本地操作（不调外部 API）
- 不消耗 token 预算
- **不增加 rounds 计数**

**解决的问题**：v0.9.5 时代，LLM 反复 read_workspace 同一文件 19 次就触发 20 轮上限，导致 60 秒静默退出。

### 3.2 Expensive 工具

剩余所有工具，包括：
- `search_web` / `search_kb` / `fetch_url`（调外部服务）
- `write_workspace` / `set_doc_status`（写文件，触发文件 IO）

**特性**：每调一次 `rounds += 1`，达 MAX_ROUNDS 触发收尾。

### 3.3 单工具硬限制

```python
TOOL_LIMITS = {
    "search_web": 3,
    "search_kb": 5,
    "fetch_url": 5,
}
```

**机制**：
- 每次循环开头检查：超过限制的工具从 `tools` 列表移除
- LLM 调用超限工具 → 收到结构化错误 → 自动调整

### 3.4 rounds 计数逻辑

```python
_round_incremented = False  # per-round 标志

for tc in tool_calls:
    tool_counts[tool_name] += 1
    if not _round_incremented and tool_name not in CHEEP_TOOLS:
        rounds += 1
        _round_incremented = True
```

**关键点**：**一轮里多次工具调用只计 1 次**——避免 LLM 一次返回 5 个 read 算 5 轮。

## 4. MAX_ROUNDS 收尾（v0.9.6 新增）

### 4.1 之前的问题

达到 20 轮后，AgentLoop 直接退出。LLM 对最后工具调用的反馈（"让我检查一下报告的内容..."）变成"最后一句话"，用户误以为这是答案。

### 4.2 现在的行为

```python
if rounds >= MAX_ROUNDS:
    yield ("agent_status", {"status": "budget_exceeded"})
    if not final_text.strip():
        # 注入指令
        messages.append({
            "role": "system",
            "content": "你已用完工具调用预算。**禁止再调用任何工具**。请基于已有信息直接给用户完整回答..."
        })
        # 追加一轮纯对话调用
        for phase, content in cloud_engine.run_with_tools(messages, tools=None):
            if phase == "text":
                yield ("text", content)
            elif phase == "error":
                # API 拒绝时降级
                break
        # 兜底文案
        if not final_text:
            yield ("text", "\n\n⚠️ 工具调用已用完预算（20 轮），无法继续。")
```

**注意点**：
- 只在 `final_text` 为空时才追加（避免重复）
- API 可能拒绝（tool_calls 历史 + 无 tools 的兼容性问题）—— 用 `phase == "error"` 降级
- 兜底文案保证用户至少看到**一些东西**

## 6. 错误处理

### 6.1 工具异常

```python
try:
    result = get_thread_pool().run_blocking(self._execute_tool, tool_name, args, stats)
except Exception as e:
    log.error("[AGENT] 工具执行异常 %s: %s", tool_name, str(e)[:200])
    result = {"error": "工具执行失败: " + str(e)[:200], "tool": tool_name, "success": False}
```

**关键**：异常被转为 `success=False` 的 result，**不中断循环**。LLM 拿到错误信息自己调整。

### 6.2 友好错误翻译

```python
err_lower = err.lower()
if "getaddrinfo" in err_lower or "enotfound" in err_lower:
    friendly = "网络连接失败，无法解析服务器地址。"
elif "timed out" in err_lower:
    friendly = "网络请求超时，请检查网络或稍后重试。"
```

### 6.3 status 事件透传

`_make_done_status` 把后端错误原因（reason / filename）传给前端：

```python
if not result.get("success"):
    _reason = result.get("error") or result.get("message") or ""
    return {"status": "error", "tool": tool_name, "reason": _reason, "filename": ...}
```

前端 chat.js 据此显示：
- "文件不存在：xxx.docx（文件可能在远程而非工作区）"
- "路径不安全，已拒绝"
- "操作受限：xxx"

## 7. 用户中断（P6）

```python
if getattr(self.cloud_engine._mm, '_stop_generation', False):
    yield ("agent_status", {"status": "user_stopped"})
    break
```

**机制**：用户点「停止」→ `mgr._stop_generation = True` → 每轮循环开头检测，立即退出。
