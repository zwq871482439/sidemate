## 1. 设计理念

### 1.1 为什么需要明盒

旧气泡模式（ChatGPT 风格圆角气泡）存在三个问题：

- **视觉扁平**：所有消息同质化，无法快速识别消息类型
- **信息隐藏**：AgentTimeline、词元统计、KB 来源等结构化数据淹没在文本中
- **模式区分弱**：离线/在线/并行三种模式共用一套渲染，用户难以感知当前模式

**ClearBox = 透明盒子**：每类信息都有独立容器，像实验室器皿一样透明可见。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **左色条** | 3px 宽色条标识消息角色（蓝=用户，紫=AI），替代圆角气泡 |
| **折叠优先** | AgentTimeline、词元统计默认折叠，需要时展开 |
| **渐进披露** | 思考→回答 Morph 过渡，不闪屏 |
| **卡片容器** | 每条结构化信息独立卡片（KB 来源、文档注入、推理单元） |

## 2. 组件体系

### 2.1 基础气泡

```
┌────────────────────────────────────┐
│▌ 用户消息                           │  ← 蓝色左色条
└────────────────────────────────────┘

┌────────────────────────────────────┐
│▌ AI 回答内容                        │  ← 紫色左色条
│  ┌─ 离线 AI · qwen3-5-4b ────────┐ │
│  │ 78字 · 5.7s · 14字/s          │ │  ← 折叠统计
│  └────────────────────────────────┘ │
└────────────────────────────────────┘
```

### 2.2 KB 来源卡片

并行模式或离线 KB 问答中，AI 引用的文库文档以卡片形式展示：

- 文档标题 + 词元统计
- 折叠后可展开查看完整 chunk 内容
- 左色条用知识库 Indigo 色 (#534AB7)

### 2.3 推理单元卡片

在线 Agent 每轮工具调用打包为可折叠卡片：

- 折叠态：工具名称 + 耗时
- 展开态：完整 think 过程 + 工具调用结果

## 3. 新旧渲染器并存策略

| 渲染器 | 使用场景 | 状态 |
|--------|---------|------|
| **旧气泡渲染器** | 离线单轮简单对话 | 保留 |
| **CardRenderer** | 并行模式、在线 Agent、KB 问答 | 新渲染器 |

两套渲染器通过 SSE 事件类型自动路由，前端无需手动切换。

### 3.1 切换逻辑

```javascript
// chat.js SSE 分发
if (CardRenderer.shouldHandle(eventType)) {
    CardRenderer.handleEvent(d);  // → 明盒
} else {
    // 旧渲染器处理
}
```

## 4. CSS 体系

### 4.1 左色条

```css
.msg::before {
    content: '';
    position: absolute;
    left: 0; top: 0; bottom: 0;
    width: 3px;
    border-radius: 8px 0 0 8px;
}
.msg.user::before { background: var(--accent-color); }
.msg.ai::before   { background: #534AB7; }
```

### 4.2 暗色主题

暗色模式下左色条透明度降低，卡片背景加深。
