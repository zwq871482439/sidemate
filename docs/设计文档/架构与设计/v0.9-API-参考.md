## 1. Chat — 对话与会话管理

> 路由文件：`routers/chat.py`

### 1.1 对话端点

#### `POST /api/chat`

非流式对话。

**请求体** (`ChatRequest`)：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `message` | string | 否 | 用户消息内容 |
| `model` | string | 否 | 指定模型（默认使用当前加载模型） |
| `max_tokens` | int | 否 | 最大输出 token 数 |
| `history` | list | 否 | 历史消息列表 |
| `chat_file` | string | 否 | 对话文件路径 |
| `mode` | string | 否 | 模式 |
| `action_mode` | string | 否 | `"chat"` / `"kb"` / `"doc"` / 扩展ID |
| `file_path` | string | 否 | 附加文件路径或 KB doc_id |
| `doc_continue` | string | 否 | 用户确认的提纲内容 |

**返回**：`{"response": "...", "error": "..."}`

---

#### `POST /api/chat/stream`

SSE 流式对话（核心端点）。

**请求体**：同 `ChatRequest`，额外字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `kb_query` | string | KB 检索查询 |
| `override_task_type` | string | 覆盖任务类型 |
| `kb_compare` | bool | 云端知识对比开关 |

**SSE 事件类型**：

| type | 说明 |
|------|------|
| `token` | 正文 token 流 |
| `think` | 思考过程内容 |
| `fold` | 思考折叠事件 |
| `status` | 状态通知（如"正在检索…"） |
| `error` | 错误消息 |
| `sources` | KB 检索来源列表 |
| `[DONE]` | 流结束标记 |

---

### 1.2 会话管理

#### `GET /api/chats`

列出所有对话。

**返回**：
```json
{
  "chats": [
    {"name": "...", "path": "...", "current": true, ...}
  ],
  "current": "当前对话路径"
}
```

---

#### `POST /api/chats/new`

创建新对话。

**返回**：`{"path": "文件路径", "name": "文件名"}`

---

#### `POST /api/chats/switch`

切换对话。

**请求体**：`{"path": "对话文件路径"}`

**返回**：`{"path": "...", "messages": [...]}`

---

#### `DELETE /api/chats/{chat_name}`

删除对话。支持文件夹和 `.json` 格式。

**路径参数**：`chat_name` — 对话名称

**返回**：`{"ok": true, "deleted": "文件路径"}`

---

#### `POST /api/chats/{chat_name}/rename`

重命名对话。

**请求体**：`{"new_name": "新名称"}`

**返回**：`{"ok": true, "new_file": "新路径"}`

---

#### `GET /api/chats/{chat_name}/messages`

获取对话消息历史。

**返回**：`{"messages": [...]}`

---

#### `POST /api/chats/{chat_name}/append`

追加消息到对话文件。

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `role` | string | 是 | `"user"` / `"assistant"` / `"system"` |
| `content` | string | 否 | 消息内容 |
| `ts` | string | 否 | 时间戳 |
| `_file_tag` | string | 否 | 文件标签 |
| `think` | string | 否 | 思考内容 |
| `model` | string | 否 | 模型名 |
| `chars` | int | 否 | 字符数 |
| `token_stats` | object | 否 | Token 统计 |
| `kb_sources` | list | 否 | KB 来源 |
| `agent_timeline` | object | 否 | Agent 时间线 |
| `_aborted` | bool | 否 | 是否中止 |
| `action_mode` | string | 否 | 动作模式 |
| `task_type` | string | 否 | 任务类型 |

**返回**：`{"ok": true, "msg_count": 数量}`

---

#### `POST /api/chats/{chat_name}/enrich`

回写前端补充字段到最近的 assistant 消息（流式完成后调用）。

**请求体**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `agent_timeline` | object | Agent 执行时间线 |
| `agent_summary` | string | Agent 执行摘要 |
| `token_stats` | object | Token 统计 |
| `kb_sources` | list | KB 来源 |
| `doc_url` | string | 文档下载 URL |
| `doc_filename` | string | 文档文件名 |

**返回**：`{"ok": true, "updated": true, "fields": ["..."]}`

---

### 1.3 问答 Tab

#### `POST /api/qa/upload`

问答 Tab 文件上传，解析文本内容。支持 `.txt`、`.md`、`.csv`、`.docx`、`.xlsx`、`.pdf`。

**请求**：`multipart/form-data`，字段 `file`

**返回**：`{"ok": true, "content": "文本内容", "filename": "...", "size": 字节数}`

---

#### `POST /api/qa/ask`

基于上传文件内容回答问题。

**请求体**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | string | 问题 |
| `file_content` | string | 文件文本内容 |
| `file_name` | string | 文件名 |

**返回**：`{"answer": "回答内容"}`

---

### 1.4 文件上传

#### `POST /api/file_upload`

上传文件到临时目录。

**请求**：`multipart/form-data`，字段 `file`（最大 50MB）

**返回**：`{"path": "保存路径", "filename": "...", "size": 字节数}`

---

### 1.5 文档下载

#### `GET /api/doc/download/{filename}`

下载 AI 生成的 `.docx` 文档。

**路径参数**：`filename` — 仅允许 `.docx` 后缀

**返回**：文件流（`application/vnd.openxmlformats-officedocument.wordprocessingml.document`）

---

### 1.6 上下文使用量

#### `GET /api/context/usage`

获取当前会话的上下文使用量。

**查询参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `chat_file` | string | 可选，指定对话文件 |

**返回**：
```json
{
  "used_tokens": 1234,
  "total_tokens": 16384,
  "percentage": 7.5,
  "level": "normal"   // "normal"(<60%) | "warning"(60-85%) | "critical"(>85%)
}
```

---

### 1.7 调度器

#### `POST /api/scheduler/cancel`

取消排队中的任务（LLM Scheduler）。

**请求体**：`{"ticket_id": "排队号"}`

**返回**：`{"ok": true, "ticket_id": "..."}`

## 2. Settings — 系统设置与模型管理

> 路由文件：`routers/settings.py`

### 2.1 系统信息

#### `GET /api/info`

返回版本和模块信息。

**返回**：
```json
{
  "version": "0.9.3",
  "version_display": "v0.9 patch 3",
  "modules": { "模块名": "版本号" }
}
```

---

#### `GET /api/status`

模型状态信息。

**返回**：版本号 + 各模型状态

---

#### `GET /api/health`

健康检查端点（适合外部监控）。

**返回**：
```json
{
  "status": "ok",
  "model_loaded": true,
  "loaded_models": ["qwen3-5-4b"],
  "device": "cuda:0",
  "version": "v0.9.3"
}
```

---

### 2.2 模型管理

#### `GET /api/models`

返回可用 LLM 模型列表、当前状态和 profile 参数。

**返回**：
```json
{
  "available": ["qwen3-5-4b"],
  "available_display": ["Qwen3-5-4B"],
  "loaded": ["qwen3-5-4b"],
  "current": "qwen3-5-4b",
  "device": "cuda:0",
  "profile": {
    "model_size": "4B",
    "max_history_chars": 12000,
    "default_max_tokens": 4096,
    "max_rounds": 6,
    "temperature": 0.7,
    "max_prompt_tokens": 16384,
    "device": "cuda:0"
  }
}
```

---

#### `POST /api/load/{model_name}`

加载模型。会进行内存预算检查。

**返回**：加载结果

---

#### `POST /api/unload/{model_name}`

卸载指定模型。

**返回**：卸载结果

---

#### `POST /api/model/unload`

卸载当前加载的 LLM 模型（释放 Ollama 内存）。

**返回**：`{"ok": true, "model": "...", "freed_mb": 数值}`

---

#### `DELETE /api/model/delete`

删除已安装的 LLM 模型（从 Ollama 移除，释放磁盘空间）。

**请求体**：`{"model": "模型名"}`

---

#### `GET /api/load-progress`

查询模型加载进度（SSE）。

---

#### `POST /api/warmup`

预热模型：向 Ollama 发送简短请求，让模型加载到内存。

**返回**：`{"ok": true, "loading": true, "model": "..."}`

---

### 2.3 设备管理

#### `GET /api/devices`

返回可用设备列表 + 当前选中设备。

---

#### `POST /api/device/switch`

切换推理设备（会卸载当前 LLM）。

**请求体**：`{"device": "cuda:0"}`

---

### 2.4 环境检查

#### `GET /api/env/check`

返回完整环境报告（CUDA、GPU、驱动版本等）。

---

### 2.5 系统操作

#### `POST /api/stop`

停止当前生成。同步等待设备释放完成。

**返回**：`{"ok": true, "auto_reload": true}`

---

#### `POST /api/rescan`

重新扫描模型目录。

**返回**：
```json
{
  "available": ["模型列表"],
  "added": ["新增模型"],
  "removed": ["移除模型"],
  "total": 数量
}
```

### 2.6 模型导入

{
  "base_url": "https://api.openai.com/v1",
  "api_key_set": true,

### 2.12 扩展包管理

#### `POST /api/extensions/upload`

上传 `.sidemate` 扩展包。SSE 返回安装进度。

支持类型：`model`、`knowledge`、`extension-knowledge`、`extension-recorder`、`llm`

**SSE 事件**：
- `{"type": "progress", "percent": 50, "stage": "安装模型..."}` — 进度通知
- `{"type": "done", "result": {...}}` — 安装完成
- `{"type": "error", "error": "..."}` — 安装失败

---

#### `GET /api/extensions/install-progress/{task_id}`

查询扩展安装进度（SSE）。

---

#### `GET /api/extensions/list`

列出已安装扩展。

---

#### `DELETE /api/extensions/uninstall/{ext_type}/{ext_name}`

卸载扩展。

---

#### `DELETE /api/extensions/{ext_type}/{ext_name}`

卸载扩展（替代路径）。

## 3. KB — 文库管理

> 路由文件：`routers/kb.py`

### 3.1 统计与状态

#### `GET /api/kb/stats`

文库统计信息。

**返回**：
```json
{
  "total_documents": 5,
  "ready_documents": 4,
  "processing_documents": 1,
  "max_documents": 50,
  "total_chunks": 120,
  "extension_installed": true
}
```

---

#### `GET /api/kb/module-status`

KB 模块安装状态（二态：installed + ready）。包含模型信息、内存信息、依赖检查。

---

#### `GET /api/kb/memory-info`

内存余量详情。

---

### 3.2 模块管理

#### `POST /api/kb/install-module`

接收 ZIP 安装包，执行安装。安装成功后自动加载模型。

**请求**：`multipart/form-data`，字段 `file`（最大 2GB）

---

#### `POST /api/kb/uninstall-module`

卸载 KB 模块。先取消所有进行中处理，再卸载模型和删除文件。

---

#### `POST /api/kb/load-models`

重新加载文库嵌入模型和 Reranker（后台异步）。会检查内存预算。

**返回**：`{"ok": true, "loading": true}` 或 `{"ok": true, "loading": false}`

---

#### `POST /api/kb/unload-models`

卸载文库嵌入模型和 Reranker。

---

### 3.3 文档管理

#### `GET /api/kb/documents`

列出所有文库文档。

---

#### `POST /api/kb/upload`

上传文件到文库。支持 `.txt`、`.md`、`.csv`、`.docx`、`.xlsx`、`.pdf`（最大 50MB）。异步处理 + 进度。

**请求**：`multipart/form-data`，字段 `file`

**返回**：
```json
{
  "ok": true,
  "doc_id": "...",
  "filename": "...",
  "size": 12345,
  "chars": 8000,
  "status": "processing"
}
```

---

#### `GET /api/kb/documents/{doc_id}/status`

查询文档处理进度。

---

#### `DELETE /api/kb/documents/{doc_id}`

删除文库文档。

---

#### `POST /api/kb/documents/{doc_id}/pause`

暂停文档处理。

---

#### `POST /api/kb/documents/{doc_id}/resume`

恢复文档处理。

---

#### `POST /api/kb/documents/{doc_id}/cancel`

取消文档处理。

---

#### `GET /api/kb/tagging-status`

查询文档打标状态。

**查询参数**：`doc_id`

---

### 3.4 KB 问答与检索

#### `POST /api/kb/ask`

基于文库问答 — SSE 流式返回。

**请求体**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | string | 问题内容 |
| `session_id` | string | 会话 ID（默认 `"default"`） |

**SSE 事件**：同 `/api/chat/stream`，额外包含 `sources` 事件返回检索来源。

---

#### `POST /api/kb/search`

文库检索（仅返回结果，不调用 LLM）。

**请求体**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `query` | string | 查询文本 |
| `top_k` | int | 返回数量（默认 5） |

---

#### `POST /api/kb/import_text`

直接导入文本到文库。

**请求体**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `filename` | string | 文件名 |
| `text` | string | 文本内容 |
| `source` | string | 来源标识（默认 `"transcript"`） |

---

### 3.5 KB 会话管理

#### `POST /api/kb/new_session`

新建 KB 问答会话。

**请求体**：`{"session_id": "会话ID"}`

---

#### `POST /api/kb/session/export`

导出当前 KB 会话为纯文本文件。

**请求体**：`{"session_id": "会话ID"}`

**返回**：纯文本文件下载

---

#### `POST /api/kb/session/clear`

清空当前 KB 会话历史。

**请求体**：`{"session_id": "会话ID"}`

---

#### `GET /api/kb/session/context`

KB 会话独立上下文使用量。

**查询参数**：`session_id`（默认 `"default"`）

**返回**：
```json
{
  "used_tokens": 500,
  "total_tokens": 16384,
  "percentage": 3.1,
  "level": "normal",
  "turns": 3
}
```

**level 等级**：`"normal"`(<60%) / `"warning"`(60-80%) / `"critical"`(80-95%) / `"full"`(>95%)

#### `GET /api/recorder/whisper/status`

## 6. Backup — 备份与恢复

> 路由文件：`routers/backup.py`

#### `POST /api/backup/export`

导出备份：将聊天记录、设置、文库元数据打包为 ZIP 流式返回。

**ZIP 结构**：
```
chats/               — 所有聊天 .json 文件
settings.json        — 全局设置
kb_meta/             — 文库元数据（如有）
backup_meta.json     — 备份元信息（版本、时间、聊天数）
```

**返回**：ZIP 文件流

---

#### `POST /api/backup/import`

导入备份：从 ZIP 文件恢复。

**安全措施**：
- 验证 ZIP 格式
- 防路径穿越
- 设置采用合并不覆盖策略

**请求**：`multipart/form-data`，字段 `file`

**返回**：
```json
{
  "ok": true,
  "restored": {
    "chats": 5,
    "settings": true,
    "kb_meta": true
  }
}
```

## 附录：通用错误码

| HTTP 状态码 | 说明 |
|-------------|------|
| `400` | 请求参数错误 |
| `403` | 权限不足/非法路径 |
| `404` | 资源不存在 |
| `409` | 资源冲突（如文档正在处理中无法卸载模型） |
| `410` | 端点已废弃 |
| `500` | 服务器内部错误 |
| `503` | 服务不可用（模型未加载、扩展未安装、内存预算不足） |
