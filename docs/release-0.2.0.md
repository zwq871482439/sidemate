# 桌伴 0.2.0

桌伴贴在屏幕顶上，平时只露一双眼睛。把范本和材料拖给它，说一句要写什么，它照范本的格式写一份新文件，你的原件一个字都不动。

这是桌伴在这里发的第一个版本，只有 Windows 版，需要你自己的 DeepSeek API key。

## 能做什么

- **照范本写新文件**：给一份旧的周报、总结或汇报当范本，再给几份材料，它按范本的字体、层级、段距写出一份新的 Word。
- **每句标出处**：从材料里写进来的话，在 Word 批注里标出是哪个文件第几页。只给一份稿子让它扩写、润色时，不挂批注，字体照原稿。
- **写得像样**：自带「写作」和「写 Word」两个技能。先定文种、列提纲，再成段写，最后换成读者的角度通读一遍；材料里没有的承诺（人员、时限、考核、保密这类）不会悄悄写进正文，会在回话里单列出来请你确认。
- **原件不动**：它先把文件拷一份到自己的工作区再干活，产出放进「桌伴输出」文件夹。

## 怎么用

- 小岛贴在屏幕顶边，左右拖动能换位置。鼠标停在上面会冒一行字；有事时眼睛会变：干活时往下看稿子，做完了是笑眼，等你回话时睁大眼睛、亮一个红点。
- 点一下小岛，任务窗从它下面垂下来；再点一下就收起，活接着干。
- 文件可以拖到小岛上，也可以拖进任务窗：放在左边当范本，放在右边当材料。
- 设置里能看这个月用了多少，以及最近 10 个任务各用了多少，数字跟 DeepSeek 后台记的一致。
- 右键小岛可以选「保持在最前」。放全屏 PPT 或看视频时，小岛会收成一条细线。

## 安装

1. 下载下面的 `sidemate-setup-0.2.0.exe`，双击安装。安装包没有签名，Windows 弹出提示时，点「更多信息」，再点「仍要运行」。
2. 第一次打开时贴上你的 DeepSeek API key，点「测一下」，显示「通了」就可以用了。

## 已知问题

- 只在 Windows 10 / 11 上测过，多块屏幕还没在真机上试过。
- 联网搜索的次数单独记，不算进用量，所以设置里的用量会比 DeepSeek 后台略少一点。

## 隐私

桌伴不用注册账号，也没有我们自己的服务器。你的 key 加密存在这台电脑上，任务内容由程序直接发给 DeepSeek。详见 [PRIVACY.md](../PRIVACY.md)。
