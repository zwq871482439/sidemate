# 安装向导素材

## 需要的文件

| 文件 | 尺寸 | 格式 | 用途 |
|------|------|------|------|
| `wizard_image.bmp` | 164×314 px | BMP 24-bit | 安装向导左侧大图 |
| `wizard_small.bmp` | 55×55 px | BMP 24-bit | 安装向导右上角小图标 |
| `setup.ico` | 256×256 px | ICO | 安装程序图标 |

## 设计要求
- 品牌色: 琥珀色 (#D4A54A) + 暗色背景
- 风格: 简洁、专业、温暖
- 品牌图准备就绪后，取消 setup.iss 中 WizardImageFile 和 WizardSmallImageFile 的注释
