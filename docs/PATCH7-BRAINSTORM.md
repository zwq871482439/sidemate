## 一、定位

P7 是**纯视觉/品牌层**的精修，不涉及功能改动。属于"代码够用之后，让产品看起来更专业"的阶段。

P5 已经做了基础 Splash + logo.svg。P7 的任务是把这些"够用但粗糙"的素材升级到"专业级"。

## 二、核心任务

### 2.1 Logo 精修

| 任务 | 说明 |
|------|------|
| Logo 矢量精修 | 现有 logo.svg 是 AI 草稿，找设计师重做 |
| Logo 变体 | 横版/竖版/单色/反白/图标-only 五种 |
| Logo 使用规范 | 间距/最小尺寸/不可用场景 文档 |

### 2.2 图标系统

| 任务 | 说明 |
|------|------|
| favicon 全套 | 16/32/48/180/192/512 多尺寸 |
| 应用图标 | .ico（Windows）/ .icns（macOS，若上 mac）|
| 内部图标 | 侧边栏/工具栏所有 icon 统一风格（lucide/heroicons 选一套）|

### 2.3 Splash 启动画面精修

P5 已做基础 Splash（4段进度条+5小节跳动）。P7 升级：
- 启动画面背景图（设计师插画或几何图形）
- Logo 进入动画（淡入+轻微缩放）
- 进度条样式精修（圆角/渐变/光泽）
- 字体（替换为中文字体，避免默认黑体）

### 2.4 字体系统

| 用途 | 候选 |
|------|------|
| 中文标题 | 思源黑体 / 阿里巴巴普惠体 / OPPO Sans |
| 中文正文 | 同上 |
| 英文/数字 | Inter / SF Pro / Roboto |
| 等宽（代码）| JetBrains Mono / Fira Code |

**字体策略**：
- 内嵌字体（离线可用）vs 系统字体（体积小但样式不统一）
- 推荐：标题用系统字体（Win11 默认有"微软雅黑"够用），代码块用 Web Font（JetBrains Mono woff2，~50KB）

### 2.5 配色系统规范化

P5 当前用 CSS 变量做主题切换。P7 任务：
- 重新校准主色调（当前蓝色 #185FA5 偏冷，可考虑更暖一点）
- 暗色模式精修（当前只是反色，对比度不够）
- 状态色（success/warning/error/info）统一规范

### 2.7 官网/营销物料（可选）

## 三、实施路径选择

### 路径 A：找专业设计师
- **成本**：¥3000-8000（按项目计，看设计师水平）
- **时长**：2-3 周（含沟通/修改/交付）
- **质量**：高
- **风险**：沟通成本高，可能要改多轮

### 路径 B：AI 生成 + 自修
- **成本**：~¥0（用 Midjourney/Recraft）
- **时长**：3-5 天
- **质量**：中（够用但缺少专业 polish）
- **风险**：版权问题（AI 生成的 Logo 不能注册商标）

### 路径 C：开源设计系统套用
- **成本**：~¥0
- **时长**：1-2 天
- **质量**：中（统一但缺个性）
- **风险**：跟其他产品撞脸

**推荐**：路径 B 起步（先有再好），后续 P8 再升级到路径 A。
