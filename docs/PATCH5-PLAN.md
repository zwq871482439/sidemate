### 📦 批次 B：功能增强

> 目标：补齐用户感知最强的功能缺口

| 任务 | 说明 | 复杂度 | 依赖 |
|------|------|--------|------|
| **B1 多选 KB Token 估算** | 多选时显示"已选 N 篇 · 约 12K tokens · 占用低(18%)" | 低 | 无 |
| **B2 文件类型扩展** | epub/html/srt/rtf 等新格式解析器 | 低-中 | 新增依赖包 |
| **B3 权限系统升级** | KB 权限（3档）+ 工具开关（每个工具 toggle）| 中 | 后端 action_mode 改造 |
| **B4 KB 文档去重检测** | 导入时 L1(filename+size) + L2(内容相似度≥95%) | 低 | difflib 标准库 |

**详细规格**：

#### B1 多选 KB Token 估算
- 等级：< 10% 极低(绿) / < 20% 低(绿) / ~50% 中(黄) / ~70% 高(橙) / > 80% 极高(红)
- 估算公式：`total_chars / 1.5`（中文）或 `total_chars / 4`（英文）
- 切换在线/本地模式时提示当前上下文窗口（云端 1M vs 本地 16K）

#### B2 文件类型扩展（按优先级）
| 格式 | 扩展名 | 依赖包 | 优先级 |
|------|--------|--------|--------|
| 电子书 | .epub | ebooklib | P0 |
| 网页存档 | .html/.htm | beautifulsoup4（已有）| P0 |
| 字幕 | .srt/.vtt | 无（纯文本解析）| P1 |
| 富文本 | .rtf | striprtf | P1 |
| LaTeX | .tex | 无（正则去标记）| P2 |
| 邮件 | .eml | email（标准库）| P2 |

#### B3 权限系统
- 第一层 KB 权限：完全访问 / 仅引用 / 关闭
- 第二层工具开关：search_web / fetch_url / search_kb / write_workspace 等独立 toggle
- 预设模式：完全信任 / 谨慎模式 / 纯离线

#### B4 去重检测
- L1：filename + file_size 完全相同 → 直接提示覆盖
- L2：内容前 2000 字相似度 ≥ 95%（difflib）→ 提示三选一（保留两版/替换/取消）（slow补充：要考虑批量导入批量冲突的情况！！）

**工作量估计**：4-6 天
